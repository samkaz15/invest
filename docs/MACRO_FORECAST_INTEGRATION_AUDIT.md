## 先に解決する仕様上の矛盾

- 憲法第7条: すべての予測は自動採点し、採点されない予測機能はリリースしない。事前の10年バックテストを必須とする条文ではない。初回公表値との事後採点機構を用意し、稼働後に観測を蓄積できる。
- 憲法第10条: 日中足分析は対象外。発表後5分、30分、1時間や24時間のイベント時刻基準分析は、日中価格を使うため憲法との整合確認とオーナーの明示的な改正が必要。日次の観測も厳密な24時間変化とは限らない。
- ADR-015〜018: 公的資料の知見収集と定性分析は拡張されたが、ニュースを既存の数値予測入力に追加することは許可されていない。数値予測への統合には新ADRと評価設計が必要。
- 現行 `bridge/v1` の確率は過去のベースライン誤差から計算されるもので、今回要求される較正済み上昇・下落確率だと確認できない。新しいレポートでその確率を引用しない。既存レポートは今回変更しない。
- 現行のCPI構成では shelter と OER やサービスが重複する。既存コードの調整係数をBLSの厳密な非重複構成比として扱わない。CPIの再集計にはBLSウエイトと構成分類の時点整合が必要。

## 実装した部分: 公的知見の時点別インデックス

`python ops/macro_context.py --as-of 2026-11-06T10:24:04Z --output /tmp/context.json`

- 発表時刻・取得時刻がともに as_of 以前である資料だけを参照する。時刻が不明・タイムゾーンなしなら除外理由を記録する。これらの日時だけではファイルが当時存在し未変更だったことを証明できない。過去再現にはその時点で保存済みのGitスナップショットを別途用意する。
- URL、発表時刻、原文SHA-256の完全一致で重複排除し、訂正版は別資料として残す。別URLの同一記事や部分引用は自動統合しない。
- 保存された `facts_ja` は情報源の内容に関する既存記述で、再検証済みの真実とみなさない。ソースURL、JSONパス、原文・ファイルのハッシュを出す。本文を命令として実行しない。LLMは使用しない。
- `--output` は追記型の新規ファイル専用で、既存ファイルの上書きを拒否する。これは予測ログではなく資料インデックスである。
- 既存知見のインデックスであり、新規の統計取得、独自の方向予測、ニュースの特徴量化、採点は実装していない。

## 次の設計（未実装）

### 共通データ契約

既存 observations / predictions / forecast_errors を正とし、必要な拡張だけADRで決める。観測は series_id、対象期間、値・単位・季節調整、取得元URLとraw証拠ID、発表時刻、取得時刻、vintage時刻を必須とする。知られていた時点は発表と取得の両方以後。時刻不明は欠損。コンセンサスは対象・単位・集計元・取得時刻・公表前時刻・再配布可否を記録。予測は対象・時点・入力参照・method_version・前月同値と直近平均・コンセンサスを保存し、初回公表値で採点。欠測はNULLであってゼロではない。

### 各エージェント

- Gold: 既存系列の金利・実質金利・BEI・広義ドル・USDJPY・XAUUSD・WTIを参照し、WGC/CFTC/ETFなどの取得可能性と時差を別記。価格と建玉のみでは主体や動機を断定しない。実需、投資、通貨、安全資産は別の因果仮説として扱う。
- Employment: 既存NFP/失業率を再利用。平均時給の月次・前年比、NSA/SA、ADP、ISM、ストライキの各対応は未実装。SAを再び季節調整しない。基準改定と初回値の記録を切り分け、既存の採点を拡張してから対象を追加。
- CPI: 既存CPI/コアCPIを再利用。構成別計算、OER、食品、エネルギー、前年比、将来の農産物ラグ推定は未実装。新築住宅価格を家賃に代入せず、先物は限月切替を明記し転嫁率の未検証時は定量寄与を保留。
- Market Reaction: USDJPYとXAUUSDを独立して扱い、サプライズと金利期待の伝達を条件付き仮説として表示。合意データ・相手国金利・市場価格が欠ける場合は未判定。未較正の確率、根拠のない変動幅はNULL。

### 因果関係辞書の初期案（仮説であり固定ルールではない）

| 入力 | 伝達経路 | 反証・欠落 |
|---|---|---|
| エネルギー供給減 | 小売燃料→総合物価→政策期待 | 価格転嫁や需要、他項目次第。原油高=金上昇とは限らない |
| 雇用・賃金上振れ | 需要・賃金→物価期待→政策期待 | 失業率、改定、事前織込が逆方向なら反応は異なる |
| 実質金利上昇 | 金の機会費用増→金に下押し圧力 | 地政学・中央銀行需要・同時のドル変動が上回り得る |
| 日米金利差拡大 | 相対利回り→ドル円に上昇圧力 | 為替ヘッジ、日銀、介入、リスク回避によって反転し得る |

### 取得元とライセンス

- WGC: [需給](https://www.gold.org/goldhub/data/gold-demand-by-country)は四半期、Metals Focus等を含む推計。 [中央銀行保有](https://www.gold.org/goldhub/data/gold-reserves-by-country)は主にIMF IFSを元にWGCが調整し遅延あり。原資料とWGCの補正を混同しない。
- [WGC利用条件](https://www.gold.org/terms-and-conditions)は個人利用以外の複製・スクレイピング・ネット上公開等を制限。API提供と当該用途の許可は未確認。GitHubへの生データ収集をしない。
- [CFTC COT](https://www.cftc.gov/MarketReports/CommitmentsofTraders/index.htm) は公開APIがある。観測日と公表日が異なり、参加者分類から意図を断定できない。各CME等先物の利用条件や履歴粒度は未確認。
- [BLS CPI構成比](https://www.bls.gov/cpi/tables/relative-importance/)は公表時点と対象月を管理。[住居費](https://www.bls.gov/cpi/factsheets/owners-equivalent-rent-and-rent.htm)は賃貸等価方式。ALFREDのvintage日は日付粒度の場合があり、発表時刻の証拠なしに分単位の再現を主張しない。
