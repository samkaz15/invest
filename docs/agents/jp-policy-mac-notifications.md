# 日銀資料のMac通知

日銀や財務省など日本の公的資料のうち金利・国債・金・ドルに関係する記録を data/knowledge/jp/ に保存し、Macでバナー表示します。通知時に相場方向は断定しません。

1. [通知スクリプト](../../ops/watch_jp_policy_mac.js)を開き、全文をコピー。
2. Macのスクリプトエディタで新規書類を開き、言語を「JavaScript」にして貼り付けます。
3. 「ファイル」→「書き出す」でファイル形式「アプリケーション」を選び、「実行ハンドラの後に起動したままにする」にチェックして保存します。
4. 保存したアプリを起動し、macOSの通知を許可します。起動中は60秒ごとにGitHubを確認し、新規文書を通知します。初回は最新1件を通知し、それ以前を既読にします。日本経路の既読記録は米国経路とは別です。
5. 終了すると監視は止まります。Macのログイン項目に追加すればログイン時に起動できます。スリープ中・オフライン時は通知が遅れます。

確認頻度はMac上のGitHub確認間隔です。資料取得自体の頻度ではなく、発表直後の通知は保証されません。日本銀行PDFは別途ページ単位で読み、欠けたページは記録します。監視に失敗した場合は次回再試行し、取得できなかった情報を新着なしと断定しません。
