# ADR-019: 経済指標発表前後の限定的な短期観測

採択: 2026-11-06。所有者が指標発表後の5分・30分・1時間・24時間の観測を明示承認。憲法第10条に例外を追加する。

## 決定

雇用統計・CPIなどの経済指標の発表を起点に、USD/JPYとXAU/USDの時点別価格変化を別々に記録する。発表時刻、参照月、初回値、予想、情報源、取得時刻、タイムゾーン、銘柄、計算方法、欠測を保持。現時点ではDB復旧を待たずに、公開が許されたファイルを読み取り、上書きしないJSONを生成できる。

`ops/employment_research.py` は、時刻付き5分足の発表時刻足の始値を基準に、指定時点直前に閉じる5分足の終値との差を算出する。これらはブローカーや実行時点により異なり、発表直前のティック値や実際の約定価格ではない。足が欠ける場合はNULL。5分足は収集未接続で、初期研究の全価格変化は未取得。

BLS初回値とReuters予想を後日資料から集めた標本は、実際に予想を事前取得して保存したvintageではない。時点を遡った入力には使えない。季節調整済み値を二重調整しない。

## 制約

- 高頻度取引、自動売買、発注は禁止。値動きから売買主体・因果を断定しない。
- 既存予測モデルやその数値入力を変更しない（ADR-018）。新たな予測には第7条に沿う採点と保存が必要。
- CSVの利用権と再配布の可否を確認する。TradingView Basicの5,000バー表示制限を回避しない。
- 過去1年の価格の観測、確率較正、当初の3予測エージェントは未完了。研究用の事後集計は予測精度の実証ではない。
