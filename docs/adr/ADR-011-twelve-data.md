# ADR-011: FX / コモディティ / 株価指数のソースは Twelve Data

- 状態：採択（2026-09-12、オーナー判断）
- 文脈：USDJPY・DXY・Gold・株価指数は公的統計に存在しない、または日次終値しか得られない。
  FREDのみでは Gold と株価指数がカバーできず、Stooq/Yahoo は自動収集の規約が曖昧だった。

## 決定

Twelve Data（`https://api.twelvedata.com`）を FX・コモディティ・株価指数の
一次ソースとする。API キーは `${TWELVEDATA_API_KEY}` として環境から注入する。

## 理由

1. **既存の `http_json` アダプタでそのまま扱える。** 新しい adapter kind が不要で、
   ソース追加がYAML 1枚で済む設計（P10）を崩さない。
2. FX・コモディティ・指数を単一プロバイダで統一でき、
   タイムスタンプ規約・欠測表現の差異に悩まされない。
3. API キーが明示的に必要＝利用規約への同意が明確であり、
   規約が曖昧なスクレイピングを避けられる。

## 結果・トレードオフ

- **Tier 2 として扱う**（一次データの機械的集計・配信）。
  金利・経済指標は引き続き Tier 1（FRED/BLS/BEA/Treasury/日銀）を正とし、
  Twelve Data は価格系にのみ使う。両者が同じ系列を持つ場合は Tier 1 を優先する。
- 無料枠にはレート制限がある。`SourceSpec.min_interval_seconds` と既存の
  `RateLimiter` / `CircuitBreaker` で吸収し、**制限に当たった場合は欠損として記録する**
  （推測値で埋めない。指示書 §26-2/9/10）。
- 制限値・エンドポイント仕様・シンボル表記は Phase 3 の実装時に
  公式ドキュメントで実測確認する（本ADR執筆環境からは外部到達不可のため未検証）。
- プロバイダは必ず死ぬ（憲法第8条4項）。価格系は将来 FRED（DEXJPUS / DTWEXBGS）へ
  フォールバックできるよう、series マスタ側で source を差し替え可能にしておく。
