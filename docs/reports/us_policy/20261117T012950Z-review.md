# 米国政策調査 2026年11月17日10:29 JST

EIAは11月16日付の[世界エネルギー安全保障データ](https://www.eia.gov/outlooks/steo/report/energysecurity/article.php)で、ホルムズ海峡を通る原油・石油液体の輸送量を2026年第2四半期に日量510万バレル、第3四半期に910万バレルと推計しました。これは推計であり、EIAは船舶追跡信号の欠落や頻繁なデータ改定に留意するよう示しています。公表時刻は不明、取得は11月17日10:29 JST。[原文と部分訳](https://github.com/samkaz15/invest/blob/main/data/knowledge/us/eia-global-energy-security-20261116.json)。他の表と注記・方法論は未収録・未翻訳、民間データの再利用権は未確認です。

推論：輸送制約が続き代替供給が不足すれば、原油需給、物価、景気、政策金利に波及し得ます。代替輸送や生産が回復する場合、需要が低下する場合、推計値が改定される場合は仮説を見直します。日・週・月で輸送量、在庫、代替供給、物価と政策を確認します。金とドル円など通貨ペアは各国の金利・景気と織込みが不足しており判断保留です。
