# BIOS リスク・ガバナンス設計書（追加提案）

> **本書はオーナー指示の5文書に含まれないが追加提案するもの。** 理由：「買うべきか」を毎朝出力するシステムは、分析システムであると同時に**資金を失わせ得るシステム**である。ヘッジファンドが運用部門と独立したリスク管理を持つのと同じ構造を、個人規模でも最初から持つべきである。

---

## 1. 行動判断の定義とリスクポリシー

Decision Agentの3アクションに、曖昧さのない運用定義を与える：

| Action | 定義 | 付随情報（必須） |
|---|---|---|
| BUY | 新規買い・買い増しの検討に値する | 想定サイズ（後述の上限内）/ 想定保有期間 / 無効化条件 |
| WAIT | 何もしない（新規も利確もしない） | 何が変われば動くか（両方向のトリガー） |
| TAKE_PROFIT | 保有分の一部/全部の利益確定検討 | 対象割合の目安 / 残す理由・売る理由 |

**ポジションサイジングはBIOSが決めない。** BIOSは判断と確信度を出し、金額はオーナーが本書のポリシー（例：1回の追加投資は総資産のX%以内、BTC総エクスポージャ上限Y%）に従って決める。ポリシー数値はオーナーが本書承認時に確定する。

## 2. 自動売買の段階制（最重要ガバナンス）

| 段階 | 内容 | 昇格条件 |
|---|---|---|
| G0（開始時） | **提案のみ**。発注機能はコードベースに存在しない | — |
| G1 | ペーパートレード（仮想執行の自動記録） | Journal採点が2四半期安定 |
| G2 | 半自動（BIOSが注文案を作成、オーナーが都度承認して初めて発注） | G1でキャリブレーション良好 + オーナー明示承認 |
| G3 | 上限付き自動執行 | **本設計では計画しない**。G2の実績を見てから憲法改正として議論 |

段階を飛ばす昇格は禁止。**昇格は必ずオーナーの文書承認**（このファイルへの追記）による。

## 3. システミックリスク（BIOS自身が誤る形）

| リスク | 内容 | 対策 |
|---|---|---|
| ハルシネーション連鎖 | 誤Factが分析・判断へ伝播 | 多層防御（AGENT仕様§4）+ magnitude大のEventは人間確認必須 |
| 過学習した物語 | 「過去のパターン」への過剰な当てはめ | 基準率N<5で統計主張禁止 / Criticの「今回は特別」逆検査 / レジーム条件付け |
| 自己確証ループ | 過去の自分の判断に引きずられ転換が遅れる | 無効化条件の機械チェック（裁量でなく条件で転換）/ Criticの独立コンテキスト実行 |
| データ汚染 | 誤報・操作された情報の混入 | Tier制度 / magnitude4以上はTier1-2裏付け必須 / 訂正Event機構 |
| オーナーへの迎合 | 対話でオーナーの希望に判断を寄せる | 迎合禁止規約（AGENT仕様§5）/ オーナー反論もJournal記録し事後検証 |
| 沈黙の故障 | 収集が止まったのに正常風のブリーフィングが出る | 欠損の明示義務 / ソース死活監視 |

## 4. セキュリティ

- **秘密情報**：APIキーは環境変数/シークレットストア管理、リポジトリに置かない。G2以前は取引所の**読み取り専用キーすら不要**（市場データは公開APIで足りる）。
- **出金権限のあるキーは、いかなる段階でもBIOSに渡さない**（G2でも発注専用・出金無効のキーに限定）。
- プロンプトインジェクション：収集した記事・SNS本文は「データ」であり「指示」ではない。Extractorに対し、入力文書内の指示文を実行しない規約＋Auditorの検査対象とする。
- バックアップの暗号化とオフサイト保管（判断履歴は個人の投資行動記録であり機微情報）。

## 5. 継続性

- **Bus factor対策**：全設計書＋運用手順（RUNBOOK、Phase 2で作成）をリポジトリに常置。オーナーが3ヶ月触らなくても、収集・蓄積は自走し、再開時にキャッチアップブリーフィングを生成する。
- **撤退基準**：2四半期連続でL3判断品質がベンチマーク（コイン投げ）を下回る、または運用負担が便益を上回るとオーナーが判断した場合、判断機能を停止し「イベントDB＋ブリーフィング」の情報システムとして存続させる（データ資産は判断機能と独立して価値を持つ設計だから可能）。

## 6. 法的位置づけ

- BIOSはオーナー個人の私的分析ツールである。出力を第三者に投資助言として提供しない（提供する場合は各国の投資助言業規制の検討が必要になるため、スコープ外と明記）。
