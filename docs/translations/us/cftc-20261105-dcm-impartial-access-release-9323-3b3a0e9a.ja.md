# CFTCの公平なアクセス要件に関する11月5日付発表

出典: https://www.cftc.gov/PressRoom/PressReleases/9323-26

翻訳状態: complete

米商品先物取引委員会（CFTC）は本日、委員会規則38.151(b)に基づき、指定契約市場（DCM）がその会員と取引権限を持つ者に競争的で、開かれ、公正かつ公平なアクセスを提供すべき要件の解釈を公表した。

マイケル・S・セリグ委員長は、商品取引所法が掲げる目的の達成にはデリバティブ市場が全国規模で統一的に運営される必要があり、所在地を理由とするアクセス制限はその目的および同法の公平なアクセス要件に整合しないと述べた。

DCMは公平なアクセス要件に違反する米国内の地理的制限を30日以内に停止するか、遵守できない理由を市場監督部門に提出しなければならない。また30日以内に、自らの市場にアクセスする仲介業者がDCMの公平なアクセス要件を妨げず、遵守していることを確認するか、遵守できない理由を同部門に提出することが求められる。委員会は対応を検討する際に個別案件の事実と状況を考慮する。
