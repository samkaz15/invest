# ナフトガス、ドニプロペトロウシク州の施設で火災と設備損傷を発表

出典: https://www.naftogaz.com/en/news/russia-attacked-a-naftogaz-facility-in-dnipropetrovsk-oblast

翻訳状態: complete

ロシア軍は夜間、ジェット推進型の無人機でドニプロペトロウシク州にあるナフトガス・グループの施設を攻撃した。

攻撃により大規模な火災が起き、施設の設備が損傷した。

ナフトガスのセルヒー・フェドレンコ最高経営責任者代行は「従業員は攻撃時に避難しており、負傷者はいなかった。ウクライナ国家非常事態庁の隊員はすぐに現場に到着した。迅速で専門的な対応に感謝する」と述べた。

ナフトガス・グループの専門担当者は被害を調査し、今後の対応を地元当局と調整している。
