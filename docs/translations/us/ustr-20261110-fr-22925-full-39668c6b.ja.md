# 米通商代表部の対中301条関税の品目別除外178件の延長（正式官報）

出典: https://www.federalregister.gov/documents/2026/11/10/2026-22925/notice-of-product-exclusion-extensions-chinas-acts-policies-and-practices-related-to-technology

翻訳状態: partial

## 正式官報 PDF 1頁

米国通商代表部

中国の技術移転、知的財産およびイノベーションに関する行為、政策、慣行を対象とする品目別適用除外の延長通知

機関　米国通商代表部（USTR）。
措置　通知。
概要　米国通商代表は従前の通知で、中国の技術移転、知的財産、イノベーションに関する行為、政策および慣行の301条調査における措置を変更し、中国の一部製品を追加関税の対象から除外した。大半の適用除外は過去に失効したが、一部は引き続き有効である。本通知は、現行178件すべてをさらに延長する通商代表の決定を公表する。
日程　本通知の附属書で公表する変更により、適用除外を米東部時間2027年1月9日午後11時59分までさらに延長する。
問い合わせ　本通知の一般的な質問は監視・執行担当の米通商代表補代理へ。税関分類や適用除外の実施に関する個別の質問は米税関・国境警備局へ。［連絡先の氏名・電話・メールアドレスを省略］

補足情報

A　背景

本調査において、通商代表は中国製品への追加関税を4段階で課した。83 FR 28719（2018年6月20日）参照。

83 FR 40823（2018年8月16日）、83 FR 47974（2018年9月21日、83 FR 49153〈2018年9月28日〉で変更）、84 FR 43304（2019年8月20日、84 FR 69447〈2019年12月18日〉および85 FR 3741〈2020年1月22日〉で変更）も参照。また、通商代表は米国の利害関係者が対象品目の一時的な除外を申請できる手続を設けた。少数の例外を除き、大半は2019年と2020年に失効した。

2023年12月29日、USTRは、過去に復活させた352件の適用除外と新型コロナ関連77件を延長するかについて意見を募集した。88 FR 90225（2023年12月29日）参照。2024年5月30日、USTRはそのうち164件を2025年5月31日まで延長すると発表した。89 FR 46948（2024年5月30日。同日付官報通知）参照。本調査に基づく措置の4年目レビューに関連し、2024年9月18日、USTRは一部の太陽光製造設備に適用される14件の除外を発表した。89 FR 76581（2024年9月18日。同日付官報通知）参照。14件は2024年1月1日から2025年5月31日まで有効だった。2025年5月31日、USTRは2024年5月に延長した164件と2024年9月に認めた14件を2025年8月31日までさらに延長すると発表した。90 FR 23987（2025年6月5日）参照。USTRはこれら178件を90日間、2025年11月29日までさらに延長すると発表した。90 FR 42500（2025年9月2日）参照。

2025年9月16日、USTRは現行178件のうち2025年11月29日を超える延長が妥当なものがあるかについて意見を募集した。90 FR 44749（2025年9月16日。同日付官報通知）参照。考慮要素として、同通知は、さらなる延長が

政権の優先事項と整合するか、また追加延長が米国の利益に及ぼす影響について、301条調査の対象となった中国の行為、政策および慣行の撤廃を実現するという目標に対する除外の全体的な影響を含め、USTRが検討すると定めていた。

2025年11月1日、ホワイトハウスはトランプ大統領と中国の習近平国家主席の間で成立した歴史的な経済・貿易合意を公表した。［1］この合意に従い、米国は2025年11月29日に失効予定だった178件を2026年11月10日までさらに延長することとなった。中国は、他の措置とともに適用除外手続を継続し、既存の適用除外を2026年12月31日までさらに延長して、米国製品の購入を促進することとなった。

2025年11月26日、USTRは現行178件すべてを2026年11月9日まで延長し、適切に応じさらなる延長や追加変更を検討し得ると発表した。90 FR 55232（2025年12月1日）参照。

B　適用除外延長の決定

改正1974年通商法第301条から第308条（19 U.S.C. 2411–2418）は、調査で講じられている措置を変更する権限を通商代表に与える。特に第307条(a)(1)は、大統領の具体的な指示があればそれに従い、第301条に基づく措置を変更または終了する権限を通商代表に与える。措置の対象となる行為、政策および慣行による米国通商への負担や制限が

［1］ホワイトハウス資料「トランプ大統領、中国との経済・貿易関係について合意」（2025年11月1日）。https://www.whitehouse.gov/fact-sheets/2025/11/fact-sheet-president-donald-j-trump-strikes-deal-on-economic-and-trade-relations-with-china/

増減した場合、または第301条(b)に基づく措置がもはや適切でない場合が該当する。

中国との協議が継続していることを踏まえ、通商代表は現行178件すべてを2027年1月10日までさらに延長することが適切と判断した。

178件の延長決定に当たり、2025年9月16日付官報通知への意見、以前に寄せられた意見、諮問委員会の助言および省庁横断の301条委員会の助言を考慮した。

2024年5月30日と9月18日付の官報通知で示したとおり、本通知の附属書による延長は、適用除外の製品記述に該当するすべての品目が利用できる。各適用除外の範囲は、米国関税率表（HTSUS）第99類第III節の米国注20(vvv)(i)、20(vvv)(ii)、20(vvv)(iii)、20(vvv)(iv)および20(www)に規定する10桁の統計報告番号と製品記述の範囲による。

米税関・国境警備局は、輸入申告と実施に関する指示を発出する。

通商代表は、適宜、追加延長やさらなる変更を引き続き検討することがある。

附属書A通商代表は、HTSUS第99類第III節の項9903.88.69および米国注20(vvv)(i)、20(vvv)(ii)、20(vvv)(iii)、20(vvv)(iv)に基づく適用除外すべてを延長すると決定した。89 FR 46948（2024年5月30日）、90 FR 23987（2025年6月5日）、90 FR 42500（2025年9月2日）、90 FR 55232（2025年12月1日）参照。延長は、米東部時間2026年11月10日午前0時01分以降かつ2027年1月9日午後11時59分より前に消費用として輸入申告された、または消費用として保税倉庫から引き取られた物品に適用する。2026年11月10日付で、HTSUSの項9903.88.69の品目記述中の「2026年11月9日」を削除し、「2027年1月9日」に改める。

通商代表は、HTSUS第99類第III節の項9903.88.70および米国注20(www)に基づく適用除外すべてを延長すると決定した。89 FR 76581（2024年9月18日）、90 FR 23987（2025年6月5日）、90 FR 42500（2025年9月2日）、90 FR 55232（2025年12月1日）参照。延長は、米東部時間2026年11月10日午前0時01分以降かつ2027年1月9日午後11時59分より前に消費用として輸入申告された、または消費用として保税倉庫から引き取られた物品に適用する。2026年11月10日付で、HTSUSの項9903.88.70の品目記述中の「2026年11月9日」を削除し、「2027年1月9日」に改める。
