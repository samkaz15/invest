# 米EIA週次石油報告の概要（11月20日終了週）

出典：https://www.eia.gov/petroleum/supply/weekly/archive/2026/2026_11_25/download/summary.txt

2026年11月20日までの週、米国の製油所の原油処理量は日量1,730万バレルで、前週比42.8万バレル増加し、稼働率は97.5％だった。ガソリン生産量は日量平均970万バレル、留出油生産量は日量520万バレルに減少した。

原油輸入は日量67.3万バレル増の620万バレルで、４週平均の620万バレルは前年同期比5.8％増だった。ガソリン輸入は日量平均31.4万バレル、留出油輸入は日量平均10.3万バレルだった。

戦略石油備蓄を除く商業原油在庫は110万バレル増の４億1,890万バレルとなり、５年平均を３％下回った。ガソリン在庫は170万バレル増で５年平均を３％上回った。留出油在庫は70万バレル増で５年平均を６％下回った。プロパン・プロピレン在庫は100万バレル減で５年平均を11％上回った。商業石油在庫全体は同週240万バレル減少した。

過去４週の石油製品供給量は日量平均2,080万バレルで、前年同期比2.2％増だった。ガソリン供給量の４週平均は日量880万バレルで前年同期比0.2％減、留出油供給量の４週平均は日量390万バレルで同3.9％増だった。ジェット燃料供給量の４週平均は前年同期比5.2％増だった。
