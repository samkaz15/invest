# OFAC、イラン関連の制裁対象リスト更新とキューバ関連FAQを発表

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/43397e4

翻訳状態: complete（メール通知本文）

米財務省外国資産管理局（OFAC）の特別指定国民・資産封鎖対象者リストの更新およびキューバに関するよくある質問の発出。
OFACは、キューバ関連の新たなFAQ 1277および1278を発出した。
また、OFACは特別指定国民・資産封鎖対象者（SDN）リストを更新した。最新のリストと今回の更新の詳細は、それぞれ公式ページを参照。
