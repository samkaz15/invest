# サウジ・エネルギー省、リヤドのアラムコ事務棟に限定的な被害と発表

出典: https://www.spa.gov.sa/ar/w2720650

翻訳状態: partial

サウジアラビア・エネルギー省の担当者は、2026年11月8日（日）、リヤド市にあるサウジアラムコの事務棟の一つを狙った攻撃の試みがあり、建物に破片が落下して限定的な被害が出たと発表した。死傷者はいなかったとしている。担当者は、関係当局が事案への対応に着手し、必要な措置を取ったと説明した。
