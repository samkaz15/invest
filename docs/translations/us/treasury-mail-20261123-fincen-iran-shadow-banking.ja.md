# 米財務省、イラン関連の影の銀行取引の可能性を分析

米財務省、イランの影の銀行取引に関連する可能性のある約150億ドルを特定

ワシントン発――米財務省金融犯罪取締ネットワーク（FinCEN）は新たな金融動向分析において、2025年1月から2026年8月までの金融活動約147億ドルが、イランの影の銀行取引に関連する可能性があると特定しました。米国の金融機関は法令順守義務の一環として疑わしい取引をFinCENに報告し、FinCENはその情報を法執行機関や国家安全保障機関が利用できるようにしています。

スコット・ベッセント財務長官は「金融機関は、イラン政権に関連する資金が米国経済に流入するのを防ぐ第一線に立つことが多い。財務省は、政権が軍事・兵器計画や代理勢力への資金提供に利用する資金経路を引き続き遮断する」と述べました。

イランの影の銀行取引の可能性に関連する傾向と手法は、2026年を通じて比較的一貫していました。その可能性があるネットワークは大陸をまたいでつながり、特にアラブ首長国連邦（UAE）、香港、シンガポールとの結び付きが目立ちます。また、石油、海運、投資、技術調達などの産業とも関連しています。

【主な調査結果】
金融機関が疑わしいものとして報告した資金の主な経路は、中国本土の銀行からUAEの銀行への約26億ドル、シンガポールの銀行からUAEの銀行への約9億8100万ドル、英国の銀行からUAEの銀行への約9億2200万ドルでした。

マーシャル諸島および英領バージン諸島に登記された会社が利用される可能性が懸念事項として浮上しました。こうした会社の所在地は、通常、法人登記機関に関連しています。イランとの関連が疑われる企業は、海運、貿易、石油など多様な事業に関与していました。

【イラン関連の疑わしい活動の報告】
金融機関の銀行秘密法に基づく報告を支援するため、FinCENは以前、イラン関連の主体に関する警戒指標を示す複数の資料を公表しています。

・イラン政権による違法な石油密輸、影の銀行ネットワークおよび兵器調達の取り組みに関するFinCEN勧告（2025年6月）。
・イラン革命防衛隊による制裁回避と収益の資金洗浄を目的としたフロント企業、金融仲介者およびデジタル資産基盤の利用に関するFinCEN警報（2026年5月）。
・イランの民間航空産業向け調達への対策に関するFinCEN警報（2026年9月）。
・イランによる宗教慈善団体ネットワークの悪用への対策に関するFinCEN警報（2026年10月）。

FinCENは内部告発者報奨制度を通じて、イラン関連の違法金融に関する情報提供を受け付けています。米国内外にいる人が制裁違反の情報を提供し、その情報により100万ドルを超える制裁金を伴う摘発が成功した場合、報奨金の対象となる可能性があります。FinCENの最近の広報資料が強調しているように、これには、イラン国外で活動するイランの代理人や仲介者の利用が関与する可能性がある、銀行秘密法またはOFAC所管の制裁制度への違反に関する情報も含まれます。
