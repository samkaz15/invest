# 弾劾条項へのヘグセス長官の反論とホルムズ海峡に関する発言

出典: https://www.whitehouse.gov/releases/2026/11/secretary-hegseth-torches-baseless-impeachment-stunt-this-is-not-patriotism-this-is-sabotage/

翻訳状態: partial

ホワイトハウスによると、ヘグセス長官は、弾劾の8条項が対象とする作戦はいずれも合法で、最高司令官の命令に基づき、議会に適切に通知され、兵士が実行して決定的な成果を上げたと述べた。

長官発言。「各条項について言えば、イラン、カルテル、マドゥロ、イエメンのいずれも、最高司令官が命令し、それを受けて私が命令し、議会に通知し、任務を果たした米国の兵士が実行した合法的な作戦だった。」

長官発言。「エピック・フューリー作戦で、どの尺度から見ても歴史的な軍事的勝利を収めた。……われわれはホルムズ海峡を支配している。テヘランの狂信的なイスラム主義者が核兵器を保有することは決してない。勇気ある最高司令官がいて初めて可能となった歴史的な取り組みだ。」（省略記号はホワイトハウスの掲載文。）
