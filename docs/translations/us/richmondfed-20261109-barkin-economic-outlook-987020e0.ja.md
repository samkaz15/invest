# リッチモンド連銀総裁の企業・家計需要と物価に関する講演

出典: https://www.richmondfed.org/press_room/speeches/thomas_i_barkin/2026/barkin_speech_20261109

翻訳状態: partial

講演本文を確認した。以下は政策判断の箇所からの訳と講演の要約。

引用の訳。「経済が現在の経路をたどり続けるなら、私たちの二つの責務のうち、リスクはインフレ側にある。」

講演者は企業利益、雇用と資産価値が投資・消費を支えたと説明した。企業からは保険、燃料、輸送、メモリー半導体、金利、関税などの費用上昇が広がり、企業がこれまで吸収した費用も価格に転嫁しようとしているとの声を聞いたという。所得の低い家計は廉価品への切替や修理によって支出を維持する一方、資産を持つ家計の消費は価格への反応が相対的に小さいとした。

AI投資が期待を下回れば投資・資産価格・消費が弱まり、逆に期待を上回って雇用を代替すれば消費が弱まると指摘。こうした場合には最大雇用の責務が重くなり得るため、政策は慎重に進めるべきだとした。総裁個人の見解として述べた。
