# ロシア大統領府が米特使らの会談発言を追記

出典: https://kremlin.ru/events/president/news/81246

翻訳状態: partial

クレムリンで、ウラジーミル・プーチン大統領が、米国大統領特使スティーブ・ウィトコフ氏と実業家ジャレッド・クシュナー氏に会った。

ロシア側からは、ユーリー・ウシャコフ大統領補佐官、ウラジーミル・メジンスキー大統領補佐官、対外投資・経済協力担当の大統領特別代表でロシア直接投資基金総裁のキリル・ドミトリエフ氏が出席した。

**プーチン大統領の発言**

ウィトコフ氏、クシュナー氏、お会いできて大変うれしく思います。

まず、お二人に感謝します。ウクライナ側との接触を取りまとめたトランプ大統領にも感謝をお伝えください。少なくとも人道面では、双方の拘束者の交換という前向きな成果があり、この分野でさらに大きな一歩が計画されていると承知しています。

ヘルソン州アリョーシキ市をめぐる人道上の問題の解決に積極的に関わった、米国のファーストレディー、トランプ夫人にも感謝をお伝えください。

トランプ大統領のチーム全体、国務省や国防総省、現在そちらで呼ばれている名称では戦争省、その他の機関の支援と、お二人の関与がなければ、これは実現しなかったとよく承知しています。

ロシアとウクライナ双方の人権担当官の代表を加え、この取り組みを続けてはどうかという案も出ました。

今回アブダビで何が起きたか、ロシアとウクライナの交渉の性質や今後の接触の見通しについて、お二人の評価を聞くことが重要です。

現地では欧州側の代表とも接触されたと承知しています。外交官の言う欧州の視点から、この問題をどう見ているかについても、私たちは重視しています。

### ウィトコフ米大統領特使（ロシア側掲載の通訳文から）

大統領、本日はお迎えくださりありがとうございます。私たちにとって非常に重要な会合です。三者形式での作業を再開したと発表できることをうれしく思います。トランプ大統領は、きょうお伝えすることを支持しています。同大統領は、この紛争をできるだけ早く終わらせることが重要だと考え、そうお伝えするよう私たちに求めました。双方にとって非常に難しい紛争であり、私たちとしても終結に必要なことを行っています。

解決に多くの人が取り組んでいます。ルビオ国務長官や、解決に重要な貢献をしている私たちのチームの多くの人が含まれます。先ほどアラブ首長国連邦で開かれた会合は非常に前向きな雰囲気で進んだと評価しています。ロシア側、ウクライナ側とも積極的に作業し、同じテーブルで個別の問題とその解決を協議しました。私たちのチームも含め、多くの人が事態の打開に向けて懸命に取り組んでいます。

ジャレッドと私は協議を前向きに評価しています。その一つが準備中の捕虜交換です。両国間で行われる最大規模の交換の一つになります。紛争解決に向けた進展を示すものだと思います。アブダビに出席し、当初から数年にわたりこの紛争の解決に取り組んできたメジンスキー氏に、打開策を見いだすための尽力を感謝します。今朝ウシャコフ氏と有意義な会談をしました。ドミトリエフ氏にもお会いしました。この分野で重要な役割を果たしてくださり、ありがとうございます。

欧州の代表はアブダビで同じ国に滞在していました。交渉のテーブルには着いていませんでしたが、私たちは協議の経過や結果を伝え、欧州側も関わりました。アブダビで良好な実務関係を築きました。

会談後、アイルランドに向かい、ゼレンスキー大統領がウクライナへ帰国する前に会う予定です。重要な会談であり、本日の会談で得られた結果を伝えます。また、きょうの会談終了直後にも、次の三者協議の日程調整について公式に発表できることを期待しています。

### クシュナー氏（ロシア側掲載の通訳文から）

アブダビでロシア、ウクライナ、欧州の各代表が、武力紛争の終結を望むと表明しました。終結に必要な全ての手順については、まだ詰め切れていません。きょうの会談で、紛争の終結に向けたアプローチや可能性、進み得る道筋を議論できることを期待しています。

会談後にゼレンスキー大統領と会い、得られた結果を伝え、紛争の終結に向けて選んだ道筋の一つを進む必要があると説得を試みます。欧州側にも動きが見られます。交渉への参加と紛争の終結を望んでいます。欧州をこの多国間の枠組みに参加させることができれば、紛争を終結させられると期待します。

欧州には紛争を終わらせたいという強い意向があります。その後に長期の平和が訪れることも確かめたいと考えています。このため、ロシア、ウクライナ、欧州と協力して紛争を終結させたい。ロシア、ウクライナ、欧州大陸に関わり、現在の紛争を終結させるとともに新たな紛争を防ぐ安全保障の枠組みをどうするかについても、すでに話し始めています。

プーチン氏「領土問題と密接に関係していると理解しています。」

クシュナー氏「領土問題と、その他の問題です。きょう話し合い、解決を見いだせればと思います。」

### プーチン大統領の応答

すぐに取りかかりましょう。平和の持続性、確かさ、信頼性について、私たちも永続する平和を望んでいます。領土の問題を双方で異なって理解していることは承知しています。私たちには、そこに住む人々、その伝統、文化、自らの規則と伝統的価値観に沿って暮らす権利がより重要です。

ウクライナ側がいわゆる「グレーゾーン」の問題を提起していることも承知しています。以前に述べたように、これは常に争いの種になります。私たちにとって明確な区分線は国境線だけです。どこからがそちらで、どこからがこちらかが明確になるためです。「グレーゾーン」を論じると理解が分かれ、争いと合意の不安定さが生じ、持続的な平和がなくなります。キーウ当局から、自分たちがある地域を支配し、私たちは別の地域を支配していない、といった主張を今も聞きます。現代の兵器が使われている状況で現地を訪れて確認することは容易でなく、この論争はいつまでも続き得ます。

先ほど挙げたアリョーシキでの人道協力には良い経験がありました。この共同作業を続けましょう。ウクライナが戦略的防衛線と位置付けるドンバスにコンスタンティノフカという町があり、なお400～500人ほどの民間人がいます。アリョーシキと同じように、米国を含む外国報道機関とロシア報道機関を招き、双方の人権担当官に任せましょう。ウクライナ当局が町を支配していると主張するなら、安全を確保してもらえばよい。私の見方ではロシア軍が支配しており、ロシア側は安全を確保します。町への経路の地雷除去に5日間が必要です。ウクライナ側が支配しているなら同様の措置を取ってもらいましょう。米国、欧州、ウクライナ、ロシアなどの報道機関と双方の人権担当者を招き、残る数百人の民間人を退避させ、誰が町を支配しているかも確認することを提案します。

目的は、領土問題も含め、この紛争の終結に向けてどのような結果が最も受け入れやすいかを把握することです。「グレーゾーン」の問題は決着せず、明確な線は国境線だけだと考えます。私たちは欧州との対話に反対したことも、対話を中断したこともありません。ロシアとの対話を中断したのは欧州側です。

私たちは現在の戦闘地域での平和、ロシアとウクライナの間の平和を望むと述べています。お二人の言うように、それは持続的であるべきで、私は永続してほしいと考えます。ウクライナ領内にいかなる外国軍が駐留することも、ロシアの安全を脅かすと考え、当初から受け入れられないと伝えています。基本的に全員が同意していた、少なくともイスタンブール交渉ではそうで、その後も異議はなかったように思います。欧州側はこれを承知しながら、和平の成立直後に部隊をウクライナに入れると言っています。私たちにとってそれは攻撃対象となり、直ちに戦争が再開します。

私の理解では、米政権のトランプ大統領は欧州全体の安全を確保する手段について合意しようと提案しています。欧州側はウクライナの和平後に限ると述べ、その後にウクライナに部隊を入れようとしています。それでは戦争が続き、堂々巡りになります。

これに似た古い冗談があります。特定の場所の話ではありませんが、今日に合わせて言うと、キーウ近郊に別荘を建てた詐欺師が捜査当局、例えば国家汚職対策局に呼ばれ、「金はどこから」と尋ねられる。「戸棚です」「誰が入れた」「妻です」「妻はどこから」「私が渡しました」「あなたはどこから」「戸棚です」となり、堂々巡りです。

欧州側も同じです。変わった問いかけかもしれませんが、お二人と米政権には、欧州の同盟国がウクライナで平和と戦争のどちらを望むか、最終的に態度を明確にするよう働きかけていただきたい。私たちは当然、欧州側と協力する用意があります。
