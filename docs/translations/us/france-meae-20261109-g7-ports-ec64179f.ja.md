# 仏外務省の国際麻薬対策行動計画とG7プラス港湾協力

出典: https://www.diplomatie.gouv.fr/en/presse-et-ressources/decouvrir-et-informer/actualites/la-france-lance-son-plan-d-action-international-de-lutte-contre-le-narcotrafic

翻訳状態: complete

麻薬取引の拡大を受け、フランス欧州・外務省は関係省庁と協力し、社会をむしばむこの問題に対処する国際行動計画を策定した。麻薬取引は地域社会の結束と安全、国民の健康への大きな脅威であり、大都市から農村、海外領土に至るフランス全域に影響している。フランス国内の麻薬取引の売上は海外領土を除き70億ユーロ超、関与者は20万人、2025年の押収量は109トン超。計画は国民の安全と健康のため、国際協力と国外での対応を三つの柱で強化する。

1. 主な生産地・通過地・中継地で生産と密輸を抑える。中南米・カリブ海では出発地で流れを阻止する港湾・空港の安全対策、西バルカンでは合成薬物と前駆物質の地域対策、西アフリカでは海洋安全保障と司法共助の新協定、北アフリカでは法執行協力の新協定、アジアでは前駆物質と大麻への対策、中東では合成薬物工場の摘発と法務・刑事協力を進める。内務・海外領土担当省と連携し、カリブ海、インド洋、太平洋の密輸経路上のフランス海外領土を重点的に保護する。フランスはG7議長国として2026年7月2～3日にマルティニークで地域安全保障会議を開き、麻薬・銃器の流入に対する政治・実務協力を強化する「マルティニークの呼びかけ」を採択した。

2. 麻薬取引を支える違法な物資と資金の流れを抑える。海上密輸対策と港湾施設の安全強化を続け、国際物流網の安全対策を強化する。同省によれば欧州に入る薬物の70％は海上・港湾経由であり、フランスはG7議長国として、欧州港湾同盟などと連携し、G7諸国、ブラジルや韓国などのパートナー、その主要港間の協力を進めるG7プラス港湾ネットワークを設けた。バロ外相は、世界的な問題には国際的な対応が必要で、麻薬取引対策をG7議長国の優先事項にすると述べた。外務省は1988年国連麻薬・向精神薬不正取引防止条約第17条の国内担当機関として、公海上で疑わしい船を検査し必要な措置をとるため旗国に許可を求める。2025年は約20件の乗船申請を処理し、ほぼすべてがコカインである40トン超を押収した。違法資金と資金洗浄の対策ではFATFの活用を強める。FATFは1989年のパリG7首脳会合で設立され、資金洗浄とテロ資金供与への対策基準・戦略を推進する。国外に逃れた容疑者の引き渡し、現地での法的手続き、犯罪資産の押収に向け司法協力も強める。フランスは2025年に国内で1億4,600万ユーロ超の犯罪資産を押収し、この取り組みを強化する方針。

3. 予防を強化し、違法薬物の新たな動向に備える。WHO、UNODC、UNAIDS、Unitaidなどの国際機関と予防・公衆衛生政策を強める。中南米のコカ栽培を他の作物に転換するため政府開発援助の一部を活用するなど、原因と影響に対処する包摂的で持続可能な投資を進める。イタリアと2025年に欧州政治共同体の枠内で立ち上げた欧州薬物対策連合の加盟国との協力も強め、新種の麻薬の流入に対処し、予防策を改善する。
