# 米マサチューセッツ州ベッドフォードの外国貿易地域27Uの承認

商務省
外国貿易地域委員会
案件S-425-2026

外国貿易地域27、マサチューセッツ州ベッドフォードのPersimmon Technologies Corporationのサブゾーン指定承認

2026年8月28日、外国貿易地域（FTZ）委員会の事務局長は、FTZ 27の指定を受けたマサチューセッツ港湾局が同州ベッドフォードのPersimmon Technologies Corporationのために提出した、FTZ 27の既存の稼働面積上限内でのサブゾーン指定申請を受理し登録した。

申請は、官報での意見募集（91 FR 56424、2026年9月2日）を含め、FTZ法と規則に従って処理した。FTZの審査担当者は、申請が承認基準を満たすと判断した。FTZ委員会事務局長に委任された権限（15 CFR 400.36(f)）に従い、FTZ法および委員会規則（第400.13節を含む）、ならびにFTZ 27の稼働面積上限129エーカーを条件に、2026年11月2日、サブゾーン27Uの設置申請を承認した。
