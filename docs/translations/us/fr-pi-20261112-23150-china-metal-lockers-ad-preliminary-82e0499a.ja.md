# 中国産金属ロッカーの反ダンピング行政審査の暫定結果

出典: https://public-inspection.federalregister.gov/2026-23150.pdf

翻訳状態: partial

## PDF 1ページ

米商務省は、2024年8月1日から2025年7月31日までの期間について、中国のXingyi Metalworking Technology (Zhejiang) Co., Ltd.が一部の金属ロッカー及び部品を正常価格未満で販売したと暫定判断した。10社に関する審査を一部打ち切り、利害関係者から意見を求める。適用日は官報掲載日の記入欄。

## PDF 4ページ

暫定結果表。輸出業者はXingyi Metalworking Technology (Zhejiang) Co., Ltd.。推定加重平均ダンピング率は64.36％。中国全体の税率311.71％は今回の審査の対象外で、変更されない。
