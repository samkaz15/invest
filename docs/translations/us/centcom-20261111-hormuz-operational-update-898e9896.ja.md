# 米中央軍、ホルムズ海峡の通航・原油輸送と対イラン封鎖の集計を公表

出典: https://x.com/CENTCOM/status/2120578655655014848

翻訳状態: partial

米軍は商船がホルムズ海峡を通航できるよう昼夜を問わず取り組み、対イラン海上封鎖を厳格に執行し続けている。イラン革命防衛隊（IRGC）が陸路やカスピ海を使って先進兵器システム、軍民両用技術、制裁対象物資や違法な資金を移動させるのを阻止するため、米政府の関係機関とも連携している。

### 添付動画の画面文言（米中央軍の説明）

**作戦の状況更新**

**ホルムズ海峡**  
区域。最も狭い地点で幅21海里の国際海上航路。  
任務。商船の保護を調整する。  
状況。米国の支援を受けて約4,000隻が海峡を通過した。夏以降、米国の保護を受けて原油17億バレルが輸送された。主要な通航経路には引き続き機雷がない。

**海上封鎖**  
区域。イランのすべての港湾および沿岸区域。  
任務。米国の許可なくイランの港湾に出入りする船舶を認めない。  
状況。米軍は対イラン海上封鎖を引き続き厳格に執行している。7月以降、封鎖違反を試みた船舶約150隻の進路を変更させ、5隻を航行不能にした。封鎖によってIRGCが推計300億ドル超の原油を輸出するのを阻止した。

**アイアン・ゲート任務部隊**  
区域。イランの国境とカスピ海。  
任務。先進兵器システム、軍民両用技術、制裁対象物資、違法な資金の移動の阻止に向けた活動の調整を支援する。  
状況。2026年11月7日設置。フロリダ州タンパを拠点とする米中央軍の文民・軍人20人で構成する。米政府の関係機関と連携するための部隊である。
