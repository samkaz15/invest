# アルメニア大統領、米国とのTRIPP協定の批准法に署名

出典: https://www.president.am/en/signed-laws/item/2026/11/10/President-Vahagn-Khachaturyan-signed-laws/

翻訳状態: partial

原文抜粋の訳。「国際平和と繁栄のためのトランプ・ルート」（TRIPP）事業に関する戦略協力の枠組み協定を批准する。

公表内容。アルメニアのヴァハグン・ハチャトゥリャン大統領は11月10日、TRIPP協定を批准する法律、平和評議会憲章を批准する法律、居住国の外で働く労働者の業務上事故の調査手続に関する1994年協定を改正する議定書を批准する法律、UAEとのサービス貿易・投資協定を批准する法律、アルメニアの祝祭日・記念日に関する法律を補足する法律に署名した。
