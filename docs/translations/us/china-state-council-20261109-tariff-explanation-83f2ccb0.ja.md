# 中国の対米追加関税措置に関する公式解説

出典: https://gss.mof.gov.cn/gzdt/zhengcejiedu/202611/t20261109_4004261.htm

翻訳状態: complete

国務院関税税則委員会が米国原産の輸入品への追加関税措置の調整を公告
2026年11月9日　出典 国務院関税税則委員会弁公室

米中両国首脳のワシントン会談で得られた合意を実施するため、中華人民共和国関税法、中華人民共和国税関法、中華人民共和国対外貿易法などの法令および国際法の基本原則に基づき、国務院の承認を得て、国務院関税税則委員会は公告を発表した。2026年11月10日13時01分から、国務院関税税則委員会の「米国原産の輸入品への追加関税措置に関する公告」（税則委員会公告2025年第4号）所定の追加関税措置を調整する。対米追加関税率24％の適用停止を2カ月間継続し、対米追加関税率10％を維持する。

中国側は、判決によって失効した国際緊急経済権限法（IEEPA）に基づく関税を301条関税で代替する考えを米国側が繰り返し示していることに留意している。中国側は米国側の今後の措置を引き続き注視し、状況に応じて適時に関連の対抗関税措置を調整する。

今回、中国が一部の対米追加関税の停止を継続することは、双方の企業間協力に比較的安定し予測可能な政策環境を提供し、米中の経済・貿易関係が安定的に改善を続けることを促す。
