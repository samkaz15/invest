# 米財務省、ヒズボラ関連の金・現金網などを制裁対象に指定

出典: https://home.treasury.gov/news/press-releases/sb0692/

財務省発表の時刻不明。受信: 2026-11-19T03:02:32+09:00。

「経済的排除作戦」、イランの代理勢力ネットワークを標的に
対象にはヒズボラ関連の慈善団体、金・現金の密輸網を含む。

ワシントン発。米財務省外国資産管理局（OFAC）は、人道支援を装ってヒズボラの活動を隠れみのにしているとするヒズボラ関連の慈善団体Wa Ta’awanu Association（以下Wa Ta’awanu）を制裁対象に指定した。また、ヒズボラとイラン革命防衛隊コッズ部隊（IRGC-QF）が運営する、レバノンとトルコを拠点とした金・現金の密輸網の構成員も指定した。

スコット・ベッセント財務長官は「ヒズボラのようなテロ代理勢力を通じてレバノンの主権を侵害しようとするイラン政権の試みは容認されない。米政府は、地域への影響力を行使し代理勢力に資金を提供しようとするイランの試みを引き続き妨害する」と述べた。

今回の措置は、ヒズボラが民間の慈善団体を引き続き利用し、自らを人道支援の提供者として見せようとしていることを明らかにすると、財務省は述べた。またヒズボラが武装解除を求める声と国際的圧力への抵抗を図るなか、その違法な資金調達網への圧力を強めるとしている。

今回の措置は、改正後の大統領令13224号という米国の対テロ権限に基づく。米国務省は、米国民の安全や米国の国家安全保障、外交政策、経済を脅かすテロ行為を行った、または行う重大なリスクがあるとして、2001年10月31日に同大統領令に基づきヒズボラを特別指定国際テロリストに指定した。それ以前の1997年10月8日には移民国籍法219条に基づき外国テロ組織に指定していた。OFACはさらに2026年8月20日、IRGC-QFによって所有、支配、指揮されているか、直接または間接にそのために、またはその代理として行動した、もしくは行動を装ったとして、改正後の大統領令13224号に基づきヒズボラを指定した。

【慈善部門の利用】
財務省によると、レバノンを拠点とするヒズボラ関連団体Wa Ta’awanuは、レバノン南部で緊急救援を提供する一方、外部寄付者の資金をヒズボラのテロ活動へ流している。2026年6月26日の米国・レバノン・イスラエルの三者枠組みの一環として、同年7月にレバノン軍は、以前イスラエル軍が保持した地域へ進出し、安全を確保してヒズボラの戦闘員や武器がない状態を確保しようとした。しかしWa Ta’awanuは試行地域におけるヒズボラの武装活動の口実を与え、武装解除を妨げ、同地域を守るレバノン政府の取り組みを阻害している、と同省は主張した。創設者Afif Abdel Rida Choumanは団体を率い、ヒズボラの指示で活動を調整しているという。

Wa Ta’awanuとChoumanは、ヒズボラを実質的に援助・支援し、財政上、物的または技術上の支援、もしくは物品・サービスを提供したとして、改正後の大統領令13224号に基づき指定された。

【金・現金のネットワーク】
財務省は、レバノンの実業家・両替商Hassan Khechenと兄弟のIbrahim Khechenが、ヒズボラの財務担当者と連携し、活動を通じてIRGC-QFからヒズボラのために多額の資金をレバノンへ送金してきたと主張した。Hassan KhechenはレバノンのGold Global Companyを所有し、ヒズボラ向け資金を複数の中継国からレバノンに移すために同社を利用しているという。このネットワークは現金を国境越しに運ぶ運び手も雇っている。Ibrahim Khechenも現金密輸網に参加し、2025年2月にベイルート空港で手荷物に250万ドルを所持して逮捕された関係者とつながりがあるとする。トルコに拠点を置き、ヒズボラに関連し、Hassan Khechenが支配するSankari Gold Kuyumculuk Ticaret Limited Sirketiも、アフリカから金地金と現金を移すGold Global Companyを支援していると同省は述べた。

HassanとIbrahim Khechenは、ヒズボラに実質的な援助、財政・物的・技術的支援または物品・サービスを提供したとして、改正後の大統領令13224号に基づき指定された。Gold Global CompanyとSankari Goldは、Hassan Khechenに所有、支配、指揮されているか、直接または間接にそのために、もしくは代理として行動した、または行動を装ったとして同命令に基づき指定された。

【制裁の影響】
この措置により、米国内にある、または米国人の保有・管理下にある上記の指定・封鎖対象者の財産および財産上の権益はすべて封鎖され、OFACへの報告が必要となる。1人以上の封鎖対象者が直接・間接に、個別または合算で50％以上を所有する事業体も封鎖される。OFACが発行する一般許可・個別許可により認められる場合や適用除外の場合を除き、米国人による取引、または米国内もしくは米国を経由する取引のうち、指定・封鎖対象者の財産や権益に関係するものは原則禁止される。

米国制裁への違反は、米国人・外国人に対する民事または刑事罰につながる可能性がある。OFACは、制裁違反に対して無過失責任を基礎に民事罰を科すことができる。経済制裁執行ガイドラインは、米国の経済制裁の執行についてさらに説明している。また金融機関やその他の者は、指定・封鎖対象者が関係する一定の取引や活動に従事すると制裁を受けるリスクがある。禁止事項には、指定・封鎖対象者による、その対象者への、またはその利益のための資金、物品、サービスの寄付・提供や、その対象者からの受領が含まれる。米国以外の者も、米国人に故意または知らないうちに米国制裁を違反させること、その共謀、制裁を回避する行為を禁じられる。FinCENの内部告発者報奨制度に制裁違反情報を提供し、それが100万ドルを超える金銭的制裁を伴う執行の成功につながった場合、米国内外の個人は報奨の対象となり得る。

さらに今回指定された者との一定の取引に従事すると、参加する外国金融機関に二次制裁が課されるリスクがある。該当する権限に基づく指定対象者のために重要な取引を知りながら実行・支援した外国金融機関について、OFACは米国内のコルレス口座またはペイアブル・スルー口座の開設・維持を禁止し、または厳しい条件を付けることができる。

OFAC制裁の効力と信頼性は、対象者をSDNリストに指定・追加する能力だけでなく、関連法や権限に整合する場合にリストから除外する意思にも由来する。制裁の目的の一つは行動を前向きに変えることにある。十分な事情の変化に当たるかは、宣言された国家緊急事態に関係する米国の安全保障や外交上の利益に影響する広い地政学的状況を含め、文脈によって異なる。OFACによる指定・解除の判断は、政権の外交・国家安全保障政策と優先事項に整合して行われる。SDNリストを含むOFACリストからの解除手続きや申請方法は、OFACの案内を参照する。今回の指定の詳細はOFACの公表ページを参照。
