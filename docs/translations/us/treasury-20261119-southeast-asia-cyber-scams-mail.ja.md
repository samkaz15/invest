# 米財務省、東南アジアのサイバー詐欺関連者を制裁対象に指定

出典: https://ofac.treasury.gov/recent-actions/20261119

翻訳状態: partial（冒頭部分のみ）

米財務省外国資産管理局（OFAC）は、東南アジアのサイバー詐欺拠点の運営や支援に関与したとする3人と、関連する2社を制裁対象に指定した。財務省によると、対象には暗号資産投資詐欺で米国人を狙う拠点の運営者と、拠点のネットワークに保護や支援を提供する武装集団の関係者が含まれる。
