# 米政府発表：オレシュキ限定停戦を受け露・ウクライナ代表が会合

出典: https://www.whitehouse.gov/briefings-statements/2026/11/first-lady-melania-trump-unites-russia-and-ukraine-at-the-white-house-following-historic-ceasefire/

翻訳状態: partial

以下はホワイトハウスが2026年11月5日に発表した説明の訳であり、戦況・避難人数を独立確認したものではない。

メラニア・トランプ大統領夫人は本日、ロシアとウクライナの指導者らをホワイトハウスに招いた。発表によれば、交戦中の2か国の代表を大統領夫人が自ら外交のためホワイトハウスへ招いたのは米国史上初と考えられる。この会合にはオレシュキでの停戦成立に重要な役割を果たした両国の関係者が集まった。

夫人は「オレシュキに向けた勇気を、無実の人々の苦しみを共に案じることで共通の基盤を見いだすために使わなければならない。協力すれば一時的な停戦より長く続くものを築ける。暗い世界の火花としてオレシュキを捉え、人間の最善を照らし、世界に見える力強い平和の炎を築こう。希望に火をともして協力を育み、持続的な平和への道を明るくしよう」と述べた。

夫人は、停戦、人道支援物資の搬入、約800人の安全な避難を実現する独占的仲介者としての役割を説明した。「ロシアとウクライナの双方が作成・署名した書面合意に私の仲介者としての役割が記された。計画の全段階に関わり、地雷除去計画や航空画像を確認し、道路状況を評価して避難経路、病院へのアクセス、車両、医療資源を協議し、望ましい実施日時の説明を受けた」と述べた。

夫人は、プーチン大統領とゼレンスキー大統領の協力なしにオレシュキ停戦は実現せず、この協力が地域全体の平和を進める重要な先例になると述べた。

発表によれば、ウクライナ代表は夫人にゼレンスキー大統領からのオリハ公妃勲章1等を授与した。これは800人の避難を可能にした停戦への貢献を認めるものという。

夫人は出席した最高位の代表者に両大統領への手紙を託し、演説後に平和の象徴として自ら選んだホワイトハウス所蔵品2点を紹介した。1点目は米英戦争で英国軍がホワイトハウスを焼いた後に運び出された18世紀末の薬箱で、かつて敵対した米英が強い同盟を築いたことを示す。もう1点は米西戦争終結に向けたフランスの仲介を認め、1899年にフランス大使ジュール・カンボンへ贈られた記念杯である。
