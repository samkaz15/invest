# MEXC Global関連の資金移動を禁止する特別措置の正式掲載

出典: https://www.federalregister.gov/documents/2026/11/10/2026-22962/imposition-of-special-measure-prohibiting-the-transmittal-of-funds-involving-mexc-global

翻訳状態: partial

B．MEXC Globalに関係する資金移動の禁止。対象金融機関がMEXC Globalから、またはMEXC Globalへの資金移動に関与することを禁止する。C．命令期間。2026年12月10日発効。終了日は定めない。
