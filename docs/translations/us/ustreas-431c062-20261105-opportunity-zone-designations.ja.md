# 財務省とIRS、全米6,576地域の適格オポチュニティ・ゾーン指定を発表

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/431c062

翻訳状態: unverified

米財務省・広報室
プレスリリース：2026年11月5日

財務省とIRS、全米6,500超の地域のオポチュニティ・ゾーン指定を発表
「働く家庭のための減税」が、これまで見過ごされてきた地域へより多くの資本を振り向けるための恒久的な州の手続きを創設

ワシントン：米財務省と内国歳入庁（IRS）は本日、全50州、準州・領土、コロンビア特別区の適格オポチュニティ・ゾーン（QOZ）の指定を発表した。

トランプ大統領の「働く家庭のための減税（Working Families Tax Cuts）」により、オポチュニティ・ゾーンの税制優遇は恒久的に更新され、適格な農村地域への投資に対する優遇の拡充が加わり、10年ごとに区域を再指定する手続きが設けられた。新たなQOZ指定は2027年1月1日に発効し、10年間維持される。

スコット・ベッセント財務長官は、「トランプ大統領の指導の下、この減税はオポチュニティ・ゾーンを恒久的に更新・強化し、投資家、起業家、地域の指導者が、長く見過ごされてきた地域へ資本を投じるために必要な長期的な確実性を与えた。本日の新規指定の発表は、最も恩恵を受け得る地域へ民間投資を振り向け、全米のこうした地域で経済的機会を拡大し、雇用創出を支え、長期成長を実現することに役立つ」と述べた。

IRS最高経営責任者フランク・J・ビシニャーノは、「トランプ大統領の指導力により、この減税によって適格オポチュニティ・ゾーンは恒久的に延長・拡充され、州は、十分な支援を受けていない地域、農村地域、経済的に困窮する地域へ長期投資を呼び込む機会を得た。数千の新たな適格オポチュニティ・ゾーンを指定することで、IRSと財務省は、最も必要とされる地域で的を絞った投資と成長を可能にしている」と述べた。

【背景】

トランプ大統領の「働く家庭のための減税」によるオポチュニティ・ゾーン税制優遇の恒久的な更新は、適格な農村地域への投資優遇の拡充を含め、米国で最も困窮する地域の一部への民間投資を引き続き促進する。この取り組みは、2017年の減税・雇用法により税制優遇が設けられて以来、1,100億ドルを超える民間投資が行われた実績を土台としている。

https://www.cdfifund.gov/opportunity-zones

4月6日、財務省とIRSは、推薦対象となり得る全米25,332の適格な国勢調査区の一覧を公表した。このうち8,334は、この減税による拡充された優遇の対象となり得る農村地域にある。7月1日、財務省とIRSは、各州知事とコロンビア特別区市長から適格な国勢調査区の推薦の受け付けを開始した。法定期間中に、追加の適格な国勢調査区130区が推薦され、そのうち28区は農村地域にあった。

法定期間の終了までに、合計6,576の適格な国勢調査区が推薦され、そのうち2,594区が農村地域にある。この6,576区すべてが、2027年1月1日発効のQOZに指定された。QOZへの指定は、全米のこれら6,576地域が新たな投資を呼び込み、雇用を生み出し、経済成長を促し、住民に実質的な機会を提供することに役立ち得る。

推薦手続きに関する追加情報は、各州知事とコロンビア特別区市長へ直接送付された。適格な国勢調査区の一覧、および各調査区の貧困率と世帯所得中央値は、次のページで確認できる。
