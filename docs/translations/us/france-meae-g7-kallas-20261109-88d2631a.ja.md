# G7外相会合でのバロ仏外相とカラスEU上級代表の会談

出典: https://www.diplomatie.gouv.fr/fr/presse-et-ressources/decouvrir-et-informer/actualites/ministerielle-g7-affaires-etrangeres-entretien-du-ministre-avec-mme-kaja-kallas-haute-representante

翻訳状態: complete

フランスのジャンノエル・バロ欧州・外務相は2026年11月9日、パリで開かれたG7外相会合の際に、EU外務・安全保障政策上級代表兼欧州委員会副委員長のカヤ・カラス氏と会談した。

両者は11月16日のEU外務理事会を前に、EUの対外活動と加盟国の取り組みについて中間点検を行った。主な議題は中東とウクライナ、そして近ごろフランスなど欧州諸国を標的としたサイバー攻撃への対応を含む制裁に関する取り組みだった。
