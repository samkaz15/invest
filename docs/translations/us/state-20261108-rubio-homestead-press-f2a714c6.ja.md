# ルビオ米国務長官のG7出発前記者応答

出典: https://www.pubt.io/view/22DBE216077D13CE2D4097B6097AC115C4158BFF

翻訳状態: partial

2026年11月8日、フロリダ州ホームステッド空軍予備基地。ルビオ米国務長官の記者応答。以下は外交・通商監視に関連する発言の部分訳。

**米国の行動と航行。** 長官は、米国は防御的に行動し、現地の米軍に脅威があれば対処する、船舶の航行に脅威があれば防護してきたと述べた。船舶や現地の米軍への明白で差し迫った脅威があれば自衛する権利があり、対応は脅威の程度や攻撃の可能性によると述べた。

**ウクライナ。** ロシアとウクライナをめぐる協議で繰り返し提起されてきたのは、ウクライナと欧州全体の戦後の安全保障の枠組みをどうするかという問題だと説明した。紛争後の枠組みの構想には進展があったとしつつ、まず紛争を乗り越える必要があり、何も最終決定されていないとした。先週木曜か金曜に初期案が大統領に説明されたと考えていると述べ、クシュナー氏とウィトコフ氏が参加するアブダビ協議で進展する可能性に触れた。

**イラン。** 外交面で報告できる進展はなく、複数の国が異なる案を携えてイランとの接触を続けているが、突破口が近いとは言えないと述べた。大統領は外交による解決を常に望み、可能性があれば探るとしたうえで、イラン側の要求は受け入れられず、場合によっては非現実的だという米側の評価を示した。

**国際刑事裁判所（ICC）。** 条約非締約国の国民をICCの管轄下に置くとの立場を米国は受け入れないと述べた。措置を避けたいのであれば、米国の軍人や指導者にICCの管轄権が及ばないことを明確にするよう同盟国がICCを説得すべきだと主張した。
