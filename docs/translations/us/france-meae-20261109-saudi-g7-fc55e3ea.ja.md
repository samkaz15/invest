# G7会合でのフランス・サウジアラビア外相会談

出典: https://www.diplomatie.gouv.fr/fr/presse-et-ressources/decouvrir-et-informer/actualites/ministerielle-g7-affaires-etrangeres-entretien-du-ministre-avec-son-altesse-faycal-ben-farhan-al

翻訳状態: complete

フランスのジャンノエル・バロ欧州・外務相は2026年11月9日、パリで開かれたG7プラス外相会合の際に、サウジアラビアのファイサル・ビン・ファルハーン外相と会談した。

両外相は中東情勢を協議した。バロ外相は、フランスがフーシ派によるサウジアラビアへの攻撃を強く非難し、領土を防衛するサウジアラビアに全面的な連帯を示すと述べた。イランがもたらす脅威全般に対処できる外交的な危機解決をフランスが支持すると再確認した。ホルムズ海峡の航行の自由を回復する必要を指摘し、条件が整えば、独立した厳格に防御目的の多国籍軍事任務の枠組みで、パートナーとともに貢献する用意があると述べた。

両外相はレバノン情勢と、レバノンの主権および安定を強化する必要性も協議した。二国家解決への関与を再確認し、スーダンの紛争終結の重要性を強調した。

両外相は、地域の安定と進行中の外交努力に貢献するため、緊密な連携を続けることで一致した。

また、2026年8月23〜24日のサウジアラビアのムハンマド皇太子兼首相の訪仏と、10月21日のフランス大統領のサウジアラビア訪問を踏まえ、あらゆる分野で両国の戦略的パートナーシップを深める意向を改めて示した。
