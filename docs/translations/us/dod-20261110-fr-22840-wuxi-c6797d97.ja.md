# 米国防総省によるWuXi AppTecの中国軍関連企業リストからの除外

出典: https://www.federalregister.gov/documents/2026/11/10/2026-22840/notice-of-removal-of-designated-chinese-military-company

翻訳状態: partial

米国防総省・長官室。案件番号DOD-2026-OS-2410。所管は取得・維持担当の国防次官室。

米国内で事業を行う中国軍関連企業の第1260H条リストから企業を除外する公告。国防副長官は、補足情報欄に掲げる企業の除外を決定した。追加または補足の根拠に基づき再掲載する余地がある。

改正後の2021会計年度国防権限法第1260H条は、国防長官に2030年12月31日まで毎年、中国軍関連企業を特定・公表し、少なくとも年1回追加・削除を行うことを求める。同条(b)(2)はリストの非機密部分を官報に掲載するよう求める。

国防副長官は、同条に基づき、WuXi AppTec Co., Ltd.を除外する。追加または補足の根拠があれば再掲載できる。コロンビア特別区の米連邦地裁は2026年8月7日、同社の仮差止め申立てを認め、同社を第1260H条上の中国軍関連企業とした指定の執行・実施その他の効力付与を差し止めた。同命令に従い、2026年6月10日付官報に掲載された最新リストから同社を除外する。

除外企業の中国語表記を含む公告は、規則公開サイトで案件番号DOD-2026-OS-2410を検索し、関連資料の欄で閲覧できる。

署名日2026年11月5日。国防長官室の官報連絡担当代理。官報番号2026-22840。公衆閲覧提出は11月9日午前8時45分。連絡先・個人識別情報は除外。
