# 背景資料：11月3日の国債売却は運営準備の演習

出典: https://www.newyorkfed.org/markets/opolicy/operating_policy_261030

翻訳状態: complete

国債の小額演習についての声明。2026年10月30日。

NY連銀は、FOMCの現行および潜在的な政策指令を実施する運営準備を試すため、一部の小額公開市場取引を行う。FOMCは公開市場操作に関する承認・継続指令において、公開市場デスクにこれらの演習を承認・指示している。

この指令に基づき、デスクは2026年11月3日火曜日、米東部時間9:00頃から9:20まで、小額の国債売却オペを行う予定。額面上限は5,000万ドルで、対象はオペ日から残存1.5～3年の名目利付国債に限る。

結果はオペ完了後にNY連銀サイトへ掲載され、証券と落札額・応募額の合計を含む。
