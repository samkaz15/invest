# ウクライナ大統領のデンマーク議会演説とFREYJA

出典: https://www.president.gov.ua/news/zvernennya-prezidenta-u-folketingu-daniyi-107257

翻訳状態: partial

【短い引用の訳】計画にはすでに11か国が参加しています。各国は自国の資源、経験、投資をもって参加できます。

【演説の詳細要約】デンマークの超党派の支援と、2024年に同国が始めたウクライナ国内での武器生産への資金拠出方式に謝意を示した。無人機、電子戦、AIによって戦争の性質が変わったとし、欧州の防衛能力と調達基盤を強化するよう訴えた。ホルムズ海峡の混乱に伴うエネルギー価格の上昇や黒海封鎖の域外影響に触れ、米国による対イラン攻撃再開が物価と防空装備の供給に波及することを懸念した。パトリオット迎撃弾が中東に向かい、ウクライナで不足していると主張した。11月10〜11日のアブダビで米・ウクライナ・ロシアの協議が行われたと説明し、欧州の安全保障に関する交渉に欧州が参加すべきだと述べた。FREYJAでは、欧州で迅速・低費用かつ大量生産できる弾道ミサイル迎撃能力を目指し、ノルウェーとコペンハーゲンの事務所開設準備を整えたと説明した。開設・生産・契約は要確認。
