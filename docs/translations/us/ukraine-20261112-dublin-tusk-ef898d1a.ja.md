# ウクライナとポーランドの冬季燃料輸送協議

出典: https://www.president.gov.ua/en/news/volodimir-zelenskij-obgovoriv-iz-donaldom-tuskom-situaciyu-z-107289

翻訳状態: partial

ウクライナ大統領府によると、ゼレンスキー大統領はポーランドのトゥスク首相と会談し、外交、前線、ウクライナの都市・地域への攻撃を議題とした。ポーランドによる冬季支援と、燃料供給を中心とする両国間の輸送網拡大の可能性を協議した。EU加盟の加速策も協議し、ポーランドで始まった有志国の軍事訓練に謝意を表した。記事には燃料の輸送量、開始日、契約や実績の記載はない。
