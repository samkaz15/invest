# ウクライナ大統領府のデンマーク防衛・エネルギー支援発表

出典: https://www.president.gov.ua/en/news/daniya-vidilila-novij-oboronnij-paket-dlya-ukrayini-na-645-m-107233

翻訳状態: partial

コペンハーゲンでウクライナ大統領とデンマーク首相が会談した。ウクライナ大統領府によれば、デンマークは攻撃・迎撃用ドローン、F-16用弾薬、PURLなどに6億4,500万ユーロの防衛支援を配分し、ヘルソン州に2,000万ユーロのエネルギー支援を配分した。首脳は追加人道支援、ドローンの共同生産と弾道ミサイル対策計画も協議した。大統領府は年内の別のドローン・武器調達枠についても1億ドルと説明した。会談での攻撃に関する発言は大統領の主張として扱う。
