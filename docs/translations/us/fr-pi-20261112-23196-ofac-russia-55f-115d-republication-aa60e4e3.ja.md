# ロシア関連一般許可55F・115Dの官報再掲

出典: https://public-inspection.federalregister.gov/2026-23196.pdf

翻訳状態: partial

## PDF 1ページ

OFACは6月11日発行のロシア関連一般許可55Fと115Dを官報に掲載する。どちらも発行時にウェブで公表された。

## PDF 2ページ

両許可は12月18日失効予定で、それぞれ55Eと115Cに取って代わった。55Fはサハリン2の特定サービスを許可する。サハリン2由来副産物の海上輸送に係る特定の禁止サービスは、日本への輸入のためだけである場合に限り、12月18日午前0時1分（米東部標準時）まで許可する。サハリン2に関する特定の取引・石油サービスにも同じ期限がある。

## PDF 4ページ

115Dの期限は12月18日午前0時1分（米東部標準時）。対象プロジェクトと許可範囲は本文参照。
