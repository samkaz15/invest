# 中国産の一部シャーシの反ダンピング・相殺関税命令の継続

出典: https://public-inspection.federalregister.gov/2026-23177.pdf

翻訳状態: partial

## PDF 1ページ

商務省と米国際貿易委員会は、中国産の一部シャーシ・部分組立品に対する命令を撤回すると、ダンピング、相殺可能な補助金、米産業への実質的損害が続くか再発し得ると判断した。商務省は両命令の継続を公告する。2026年11月2日適用。

## PDF 4ページ

対象シャーシの関税分類例は8716.39.0090、8716.90.5060。8716.90.5010で輸入される場合もある。対象範囲は品目番号に優先して原文の記述で判断する。商務省は通関当局に、対象輸入品の搬入時点で適用される税率で現金保証金を徴収し続けるよう指示する。
