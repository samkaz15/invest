# カナダ対ロシア制裁改正規則 SOR/2026-233（抜粋）

出典: https://www.international.gc.ca/world-monde/international_relations-relations_internationales/sanctions/russia_regulations-reglement_russie5.aspx?lang=eng

翻訳状態: partial

第1条。対ロシア特別経済措置規則第3.04条第2項の後に第3項を加える。附表1.1掲載船舶の所有者、運航者または管理者が、規則に定める禁止措置の適用についてカナダで法律サービスを受けるために必要な金融サービスには、第2項を適用しない。

第2条。フランス語版第3.13条第3項(a)を、人道目的、人権遵守の監視または防護のみに使用する非致死性の軍用装備ならびに対応する技術支援と訓練に差し替える。
