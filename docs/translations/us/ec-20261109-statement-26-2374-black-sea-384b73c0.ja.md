# 欧州委員長、黒海の航行の自由と食料・エネルギー施設を対象とする停戦を支持

出典: https://ec.europa.eu/commission/presscorner/api/files/document/print/en/statement_26_2374/STATEMENT_26_2374_EN.pdf

翻訳状態: partial

欧州委員会声明。ゼレンスキー大統領との電話協議後、ルーマニア・ブルガリアの黒海地域訪問を前にしたフォンデアライエン委員長の声明。ブリュッセル、2026年11月9日。STATEMENT/26/2374。

本日、私は黒海地域への訪問を始めます。同地域では安全保障上の脅威が強まり、攻撃が増え、罪のない人々の命が失われています。

ルーマニアとブルガリアでは各国首脳と会い、現地の状況と欧州が対応をどう強化できるかを協議します。

訪問に先立ち、ウクライナのウォロディミル・ゼレンスキー大統領と有意義な電話協議を行いました。

黒海の航行の自由を回復し、維持しなければなりません。

食料・エネルギーのインフラを対象とする停戦を求める同大統領の呼びかけを、改めて支持しました。

進行中の和平努力と、今週アブダビで行われる協議についても話し合いました。EUはパートナーとともに同協議に参加します。

今週後半にダブリンでゼレンスキー大統領と会い、他の首脳と和平に向けた次の段階を話し合うことを楽しみにしています。
