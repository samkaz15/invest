# イラン革命防衛隊海軍、前夜のタンカー2隻の機雷衝突を主張

出典: https://sepahnews.ir/fa/news/41503/%D9%85%DB%8C%D9%86-%D9%87%D8%A7%DB%8C-%D8%AF%D8%B1%DB%8C%D8%A7%DB%8C%DB%8C-%D8%AF%D9%88-%D9%86%D9%81%D8%AA%DA%A9%D8%B4-%D9%85%D8%AA%D8%AE%D9%84%D9%81-%D8%AF%DB%8C%DA%AF%D8%B1-%D8%B1%D8%A7-%D8%AF%D8%B1-%D8%AA%D9%86%DA%AF%D9%87-%D9%87%D8%B1%D9%85%D8%B2-%D9%85%D9%86%D9%81%D8%AC%D8%B1-%DA%A9%D8%B1%D8%AF%D9%86%D8%AF

翻訳状態: partial

昨夜、略奪と侵略を行う米軍の戦闘機の支援を受けて、ホルムズ海峡の無許可で危険な航路からひそかに出ようとしたタンカー2隻が、機雷に衝突して激しく爆発した。米軍の協力者による消火の試みにもかかわらず、現在も激しく燃えており、放置されている。

違反した船舶は航法・識別装置を切り、侵略を行う米軍の将校の誘導でホルムズ海峡の無許可航路を通ろうとした。機雷によってこの密輸は阻まれ、米中央軍司令官ブラッド・クーパーの負の経歴に新たな一頁が加わった。

米軍当局は、自らの虚偽を証明するために海峡の外でヘリコプターに乗って報道向けの演出をする必要はない。ホルムズ海峡の航空写真が全容を検閲なしに示している。
