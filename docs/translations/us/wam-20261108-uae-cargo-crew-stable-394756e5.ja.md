# UAE国営通信、オマーン湾の貨物船から救助の22人は容体安定と報道

出典: https://www.wam.ae/en/article/17ijsjm-national-guard-says-rescued-from-cargo-ship-fire

翻訳状態: partial

UAE国家警備隊の沿岸警備部門は、オマーン湾で火災が発生した貨物船から救助したアラブ諸国籍の乗組員22人全員について、容体は安定していると発表した。沿岸警備部門は乗組員から船上火災の通報を受け、専門チームが直ちに出動して船の位置を突き止め、22人全員を救助した。救助した乗組員に応急処置を施し、関係当局に引き渡した。同隊は、海上の緊急事態への対応態勢を示す活動だったと説明した。
