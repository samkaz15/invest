FATFイラン声明の補助資料要約
FATFはイランの制度上の不備を指摘し、銀行・仮想資産業者の拠点設置、取引、新規コルレス関係の制限と既存関係のリスク審査を求める。人道支援・食料・医療・外交費・個人送金はリスクに応じ適切に扱うよう求める。イランの核・テロ資金供与に関する記述はFATFの評価であり、戦況の独立検証ではない。10月30日付資料の補完。
