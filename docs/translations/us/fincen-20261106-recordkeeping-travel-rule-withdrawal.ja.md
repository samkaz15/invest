# FinCEN・FRBが記録保存・トラベルルール改正案の撤回を発表

出典: https://www.fincen.gov/news/news-releases/fincen-announces-withdrawal-proposed-rule-related-recordkeeping-and-travel-rule

翻訳状態: complete

金融犯罪取締ネットワーク（FinCEN）は、交換可能な仮想通貨に関する記録保存ルールおよびトラベルルールを改正する規則制定案の告示を撤回します。この案は、米国外を起点または終点とする資金移転・送金に適用する基準額も引き下げるものでした。この案は、連邦準備制度理事会と共同で撤回されます。
