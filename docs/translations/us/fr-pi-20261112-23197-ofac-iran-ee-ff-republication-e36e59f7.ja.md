# イラン関連一般許可EE・FFの官報再掲

出典: https://public-inspection.federalregister.gov/2026-23197.pdf

翻訳状態: partial

## PDF 1ページ

OFACは10月8日発行のイラン関連一般許可EEと、10月15日発行のFFを官報に掲載する。両許可は発行時にウェブで公開した。

## PDF 2ページ

EEの取引縮小許可は2026年10月23日午前0時1分（米東部夏時間）まで。遮断対象者への支払は米国内の利息付き凍結口座に入れる条件。

## PDF 3ページ

FFは指定された銀行及び一定の保有先が関与する取引の縮小に通常付随し必要な取引を、期限・例外・支払の凍結口座条件付きで許可する。
