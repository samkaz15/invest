# フランス外務省、サイバー攻撃をイランに帰属させる声明

出典: https://www.diplomatie.gouv.fr/fr/presse-et-ressources/decouvrir-et-informer/actualites/declaration-d-attribution-a-l-iran-de-cyberattaques-visant-la-france

翻訳状態: complete

フランスは、イラン・イスラム共和国がフランス領内でフランスの利益に対して実行したとする容認できないサイバー攻撃を、最も強い言葉で非難する。

10月11日から12日にかけての夜、フランス国内の大手小売業の700を超える拠点に設置されたスーパーマーケットの冷蔵制御装置が、一連のサイバー攻撃の標的となった。物的な損害や火災の発生があり、食品の損失は数千万ユーロと推定される。フランスの国益と国民の安全に対する重大な侵害である。

規模と攻撃性で前例のない事案で、フランス領内で純粋に破壊工作を目的に行われた初の攻撃的サイバー活動だと位置づける。

調査の結果、フランスはこれらの破壊行為をイランに帰属させる。実行したのは、イラン革命防衛隊の電子・サイバー部門に属する攻撃部隊SHAHID KAVEHだとする。同部隊はフランスの重要インフラに対する継続的な脅威である。

これらの破壊的な攻撃は正当化も容認もできず、国際法に反する。イラン・イスラム共和国も支持した、サイバー空間における国家の責任ある行動に関する国連の規範の原則にも反する。

フランスの利益に対するイランのサイバー上の脅威は以前からある。イランは2023年の週刊誌シャルリー・エブドや2024年パリ五輪の運営などを標的とする不安定化行為をすでに行ってきた。EUは2026年3月、これらの攻撃の実行に関与したイランの団体Emmenet Pasargadに対する制裁を採択した。

フランスは2026年の国家サイバーセキュリティ戦略に従い、EUの枠内や欧州・国際パートナーとともに、利用できるあらゆる対応手段を用いて、フランスを狙う不安定化・破壊行為を予見し、防止し、抑止し、対応する決意である。

フランスは駐仏イラン大使を召喚し、これらの攻撃を強く非難する意向を示す。

フランスは、今回の攻撃やその他の悪意あるサイバー活動に関与したイランの団体・個人に対する新たな制裁の採択を、欧州のパートナーに提案する方針である。

フランスは、必要かつ均衡が取れていると判断する場合、公表・非公表を問わず追加措置を取る権利を留保する。

サイバー危機調整センター（C4）の技術部門は、国家情報システム安全庁、対外治安総局、国内治安総局、装備総局、サイバー防衛司令部で構成される。同センターの攻撃帰属に関する調査を踏まえ、イラン革命防衛隊と関係するイランの主体がフランスの利益を狙って行ったとする攻撃活動について、共同報告を同時に公表する。
