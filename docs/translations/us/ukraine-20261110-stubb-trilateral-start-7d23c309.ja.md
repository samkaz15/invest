# ウクライナ大統領とフィンランド大統領の電話会談

出典: https://www.president.gov.ua/en/news/prezident-ukrayini-proviv-telefonnu-rozmovu-z-prezidentom-fi-107229

翻訳状態: partial

ゼレンスキー大統領はフィンランドのストゥブ大統領との電話会談で、米国・ロシアを含むアブダビでの三者協議が始まり、欧州代表との会合も行われたと説明した。ウクライナと関係国は緊張緩和や実効的な安全の保証を協議し、ロシアにも同様の姿勢を求めている。両首脳は調整を続けることで一致した。ゼレンスキー大統領は同日中に交渉団と関係国から対ロ協議の詳しい報告を受ける見込みだと述べ、支援に謝意を示した。
