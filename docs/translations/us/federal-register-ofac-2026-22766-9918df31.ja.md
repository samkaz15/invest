# 米官報のOFAC制裁告示 2026-22766（個人識別情報を除く抜粋）

出典: https://www.govinfo.gov/content/pkg/FR-2026-11-09/html/2026-22766.htm

翻訳状態: partial

財務省外国資産管理局（OFAC）。制裁措置の告示。OFACが特別指定国民および資産凍結対象者リストに追加した対象を公表する。

OFACは該当する法的要件を一つ以上満たしたと判断した。米国の管轄下にある対象者のすべての財産および財産上の利益は凍結され、米国人による取引は原則禁止される。措置日は2026年11月4日。SDNリストや制裁プログラムの追加情報はOFACのサイトで入手できる。OFACは11月4日、列挙した対象の米国管轄下の財産・財産上の利益を関連権限により凍結すると判断した。

権限は大統領令13902。財務省外国資産管理局長名。官報文書2026-22766は11月6日午前8時45分に提出。請求コード4810-AL-P。
