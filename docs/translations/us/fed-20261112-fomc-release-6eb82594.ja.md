# FRBが2027年FOMC暫定日程の改訂を発表

発表: 2026-11-12T12:45:00-05:00 / 取得: 2026-11-13T05:42:24.226Z

出典: https://www.federalreserve.gov/newsevents/pressreleases/monetary20261112a.htm

FRBは木曜日、2027年の連邦公開市場委員会（FOMC）会合について改訂した暫定日程を公表した。
委員会は以下の日程で金融政策を協議する予定で、10月26〜27日の会合を除き、通常どおり会合2日目に政策決定を発表する。10月の会合は幅広い金融政策戦略の議論に専念する。
2027年1月26〜27日、3月16〜17日、4月27〜28日、6月8〜9日、7月27〜28日、9月14〜15日、10月26〜27日、11月16〜17日。2028年1月25〜26日。日付は米国現地時間。
