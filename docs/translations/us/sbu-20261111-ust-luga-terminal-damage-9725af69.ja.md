# ウクライナ保安庁、ウスチルガ港の石油設備などへの攻撃と被害状況を公表

出典: https://ssu.gov.ua/novyny/sbu-spilno-z-inshymy-skladovymy-syl-oborony-urazyla-portovu-ta-naftovu-infrastrukturu-rf-v-ustluzi-a-takozh-raketnyi-korabel-buianm

翻訳状態: complete

11月11日未明、ウクライナ保安庁（SBU）は他の防衛部隊と共同で、ロシア・レニングラード州ウスチルガ港の主要な港湾、石油精製、輸送インフラを攻撃した。

暫定情報によると、ノバテク・ウスチルガのターミナルでは、特殊作戦センター「アルファ」の無人機が、容量各3万トンの複数のタンクなどの設備を攻撃した。石油製品の流出も起きた。

ウスチルガ・オイルのターミナルでは複数の石油製品タンクが損傷し、大規模な火災が続いている。ファクトル社のターミナルとルジスカヤ鉄道駅でも火災が確認された。

主な損傷箇所はタンク群、ポンプ設備、パイプライン、原油・石油製品の積み替え設備だった。各施設では消火・救助作業が続いている。

SBUは特殊作戦の一環として、ブヤンM級小型ミサイル艦ナロ・フォミンスクへの攻撃も計画し実施した。同艦は巡航ミサイルのカリブルとオーニクスを搭載する。進水は2022年だった。

ロシア軍の攻撃ヘリコプターを破壊したとの情報についても確認を進めている。

SBUは、ウクライナとの戦争で使うミサイル、無人機、その他の兵器の製造を賄うロシア政府の歳入を減らすため、ロシアの石油インフラを継続的に機能停止に追い込んでいる。ロシアの後方地域は安全ではいられない。ウクライナの都市や民間インフラへの攻撃に対し、ロシアは自国領内で報復を受けている。
