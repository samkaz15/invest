# イエメン外務省による対イラン声明と紅海航行への言及

出典: https://www.mofa-ye.org/Pages/41483/

翻訳状態: complete

### イエメンはイラン政権に民兵への武器供与をやめ、イエメン人の血を政治利用するのをやめるよう求める

2026年11月9日（外務省英語版）　報道発表
アデン、サバ通信

外務・在外イエメン人省は、イエメンについてイラン外務省が発表した声明を強く非難する。同声明は誤解を招く主張を行い、イエメン共和国の内政に公然と干渉している。テロ組織フーシ派に政治・報道面での援護を与え、戦争を長期化させ、イエメン国民の人道上の悲劇を深めたイラン政権の責任を否定しようとする意図は明らかである。

同省は、このイランの声明が、政権転覆を図った民兵の主張をテヘランが公然と採用し、その行為を正当化していることを示すとする。イエメンの管轄機関も、イランの関与が資金提供、武器供与、訓練から、作戦の計画・運営への直接参加に発展したと判断している。

同省は、現地での軍事支援と国際会議における外交的援護の組合せが、イエメン国家を弱体化させ、地域とその水路の安全を脅かすイランの役割の実態をさらに示すとみている。

同省は、タイズ県アルワジイヤ地区のスーク・アルハダラでの事件その他の地域の犠牲者の血をイラン政権が利用し、イエメン管轄当局の発表に反する非難を広めることを拒絶する。イエメン当局の発表には、フーシ派による人権・国際法違反の独立調査を求める内容が含まれる。

同省は、内務省が、イラン革命防衛隊の14人とヒズボラの7人を含む外国人専門家21人がフーシ派のために活動していると発表したことを想起する。任務は指揮・統制と作戦運営、弾道ミサイル・無人機・電子戦、軍用部品の密輸、標的とする商船の選定を含む海上作戦の調整に及ぶ。訓練を超えて作戦の監督、計画、指揮を担う参謀組織を構成しており、イエメン人は命、安全、生計で代償を払っているとする。

同省は、テヘランがフーシ派に武器と専門家を供与することで、イエメン国内での民間人の拉致、殺害、威嚇、都市・民間施設への砲撃、住民の包囲や飢餓に加え、サウジアラビア領内、商業船舶、紅海・バブ・エル・マンデブ海峡の航行に対する攻撃を繰り返せるようにしていると強調する。

この干渉は、武力の行使や戦争・和平の決定に関する各国政府の専権に異議を唱える非正規武装組織に資金を提供し、地域諸国の安全を損なうという、イラン政権の長年の行動を体現する。

同省は、決議2216に基づき課され、決議2624でフーシ派という組織全体に拡大された武器禁輸には、武器、装備、軍事活動に関連する技術支援、訓練、資金提供が含まれることを想起する。

同省は、イラン自身の利益と安全および将来の地域関係のために、諸国の主権を尊重し、共通の利益と内政不干渉に基づく善隣関係を築き、傘下の破壊活動組織に武器を供与する政策を放棄する必要があるとする。

同省は、武器や密輸網、地域の不安定化に国の資源と富を浪費するよりも、イラン人の生活を改善し、開発、公共サービス、雇用の需要を満たすために用いる方が、イラン政権にとってはるかに有益だと強調する。

同省は、イランの後ろ盾を得てフーシ派が始めた戦争の12年間に、イラン政権がイエメン国民に提供したのはミサイル、自爆型無人機、爆発物を積んだ船、破壊活動の専門家だけだと述べる。一方、サウジアラビアの同胞は、救援・人道・開発の各分野で貴重な援助を行い、イエメン出身者の就労と送金が何百万人もの生活を支えられるよう、多くの便宜を図ってきたとする。

外務省は、イエメンの主権を尊重する第一歩は、民兵への武器供与を止め、専門家を撤収させ、イエメンの国家的意思決定への干渉をやめることだとする。また、テヘランがイエメン人の生命を気遣うと言うのであれば、まず苦しみを長引かせ、破壊を深める手段を使うのをやめる必要があると表明する。
