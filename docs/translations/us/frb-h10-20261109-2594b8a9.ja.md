# FRB外国為替レート週報（11月9日公表）

出典: https://www.federalreserve.gov/releases/h10/20261109/

翻訳状態: complete

11月9日の週にデータ・ダウンロード・プログラム（DDP）の「独自パッケージ作成」機能を、将来のDDP廃止に向けて削除する。データと拡充されたダウンロード機能はセントルイス連銀のFREDで利用できる。データはXML形式でも利用できる。

2019年6月24日から、FRBスタッフは日次の広義・先進国・新興国ドル指数の指数化方法を変更する。詳細は技術Q&A参照。
