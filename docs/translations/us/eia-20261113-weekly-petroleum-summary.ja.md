# 米国週間石油需給報告の要約：11月13日終了週

一次資料：https://ir.eia.gov/wpsr/summary.txt  
公表日時不明。取得：2026-11-22T09:35:54+09:00

2026年11月13日終了週の米製油所の原油処理量は日量1690万バレルで、前週から同12万9000バレル減少し、設備稼働率は95.7％でした。ガソリン生産は平均日量940万バレル、留出油生産は同520万バレルに増加しました。

原油輸入は日量110万バレル減の同560万バレルでしたが、4週間平均の同630万バレルは前年同期を13.0％上回りました。ガソリン輸入は平均日量53万3000バレル、留出油輸入は同13万3000バレルでした。

戦略石油備蓄を除く商業原油在庫は340万バレル増の4億1780万バレルで、5年平均を3％下回りました。ガソリン在庫は520万バレル増え5年平均を3％上回り、留出油在庫は160万バレル増え5年平均を7％下回りました。プロパン・プロピレン在庫は横ばいで、5年平均を12％上回りました。商業石油在庫全体は週中に920万バレル増加しました。

過去4週間の石油製品供給量全体は平均日量2060万バレルで前年同期比0.3％減でした。ガソリンの4週間平均供給量は前年同期比1.8％減の日量870万バレル、留出油は同4.3％増の日量400万バレルでした。ジェット燃料の4週間平均供給量は前年同期比0.3％増でした。

※ EIAの要約文全体の訳です。週報全体の表・脚注・PDFは別途未取得です。
