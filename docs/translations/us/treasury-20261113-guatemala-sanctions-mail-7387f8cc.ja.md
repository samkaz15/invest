# 米財務省、メキシコのカルテルを支援するグアテマラの麻薬密売組織に制裁

公表：米国11月13日付、時刻不明。受信：2026-11-14T02:03:08+09:00（日本時間）。

米財務省 広報局　2026年11月13日付発表

# メキシコの麻薬テロ組織を支援するグアテマラの麻薬密売組織に対する制裁

ワシントン発。本日、財務省外国資産管理局（OFAC）は、ロス・メンドーサ麻薬密売組織とロス・ウイスタス麻薬密売組織に制裁を科した。両組織はメキシコ最大の麻薬テロ組織であるシナロア・カルテルとハリスコ新世代カルテル（CJNG）を支援しており、トランプ政権は昨年、このメキシコの2組織を外国テロ組織（FTO）と特別指定グローバルテロリスト（SDGT）の両方に指定した。グアテマラを拠点とするロス・メンドーサとロス・ウイスタスは、ホンジュラスおよびメキシコとの国境沿いの戦略的な密輸経路を支配し、シナロアとCJNGに欠かせない物流上の協力組織となっている。

ベッセント財務長官は「本日の措置は、グアテマラで政治的影響力を持つ犯罪組織と、致死性の高い麻薬の米国流入を助けるメキシコの外国テロ組織とのつながりを明らかにするものだ。トランプ大統領の米国第一の方針の下、財務省は、シナロア・カルテルやCJNGなどの暴力的組織による国境を越えた麻薬密輸を可能にし、米国民の安全を脅かす犯罪ネットワークを引き続き標的とする」と述べた。

ロス・メンドーサとロス・ウイスタスは、米国その他の国際市場向けの麻薬の受け取り、保管、警護、国境を越える移動を助けている。シナロアとCJNGは中南米にまたがる長年の提携を通じて犯罪活動を拡大し、高度な越境密輸網を築き、違法薬物の供給網の重要部分に対する支配を固めてきた。OFACはこれらの主要な協力組織を標的とすることで、地域全体のフェンタニル、コカイン、メタンフェタミンその他の違法薬物の密売を可能にする供給網の要所を遮断している。

この措置は、違法薬物とその製造手段の国際的拡散を対象とする大統領令14059号と、テロリストとその支援者を対象とする大統領令13224号（大統領令13886号による改正後。以下、改正後の13224号）に基づく。

この措置は、西半球を不安定化させる麻薬テロ組織に対処する国務省と連携して行われた。国務省も同時に、移民国籍法219条に基づいてロス・ロレンサナスをFTOに、改正後の13224号に基づいてSDGTに指定する。

## シナロアとCJNGがグアテマラの提携先を使って麻薬密売を促進

OFACは本日、シナロア・カルテルに実質的な支援を提供したロス・メンドーサに対し、大統領令14059号および改正後の13224号に基づき制裁を科す。さらに、シナロアとCJNGに実質的な支援を提供したロス・ウイスタスに対し、改正後の13224号に基づき制裁を科す。両組織はグアテマラのホンジュラス・メキシコ国境沿いの戦略的な密輸経路を支配し、麻薬密売活動を助ける重要な役割を担っている。シナロアとCJNGは両組織など現地の犯罪組織と協力して、麻薬の受け取り、保管、越境輸送など主要な物流業務を管理し、米国やその他の国際市場での流通に向けて麻薬をメキシコに運び込む。

シナロアとCJNGはメキシコで最も強力なカルテルで、米国に密輸される致死性の高い薬物の相当部分を担っている。フェンタニル、メタンフェタミン、コカインその他の違法薬物の米国への密輸に加え、広範な暴力や、燃料窃盗、タイムシェア詐欺などの犯罪にも関与してきた。国務省は2025年2月20日に両カルテルをFTOおよびSDGTに指定した。米国は外国麻薬王指定法に基づき、シナロアを2009年4月15日、CJNGを2015年4月8日に、それぞれ重大な外国麻薬密売組織と認定した。2021年12月15日には、OFACも大統領令14059号に基づいて両カルテルを指定した。

## 主要な物流協力組織であるロス・メンドーサとロス・ウイスタス

1980年代に発足したロス・メンドーサは、グアテマラで最も古く強力な犯罪組織の一つである。同族組織で、シナロアの主要な輸送・物流の仲介役となり、グアテマラとホンジュラスを横断する麻薬密売を助けている。グアテマラのサン・マルコス、ウエウエテナンゴ、ペテン各県で国境通過地点、秘密滑走路、保管施設、現地の警護網へのアクセスを確保し、シナロアの密売網を支えている。麻薬密売のほか、請負殺人と資金洗浄にも関わり、ペテン、イサバル、メキシコとの国境地域で土地の奪取、牧畜、農業事業、不動産投資を通じて大きな経済的権益を築いた。

1990年代から活動するロス・ウイスタスは、グアテマラで最も強力で長く続く犯罪組織の一つである。南米からメキシコを経て米国に至るコカイン密輸網の要所を担う。OFACは2022年3月18日、大統領令14059号に基づいて同組織を指定した。同組織はシナロアとCJNGの双方と活動上の関係を維持し、麻薬の輸送に物流支援と警護を提供する。地元の実業家、法執行当局者、政治家との長年のつながりを通じ、グアテマラ北西部の一部で犯罪社会を支配してきた。こうした関係を通じて政治的影響力と公的機関へのアクセスを獲得し、犯罪活動を進めるとともに法執行当局の監視を免れる助けとしてきた。

## 制裁の効果

本日の措置により、上記の指定対象者の財産および財産上の利益のうち、米国内にあるか米国人が保有・管理するものはすべて凍結され、OFACに報告する必要がある。さらに、1以上の凍結対象者が、単独または合算で直接または間接に50％以上所有する事業体も凍結対象となる。OFACが発行する一般許可や個別許可で認められる場合、または適用除外の場合を除き、OFAC規則は一般に、指定対象者やその他の凍結対象者の財産または財産上の利益に関わる、米国人による、米国内の、または米国を経由するあらゆる取引を禁止する。

米国の制裁に違反した米国人や外国人には、民事または刑事の罰則が科されることがある。OFACは厳格責任に基づいて民事罰を科すことができる。米国経済制裁の執行についてはOFACの経済制裁執行指針に詳しい。金融機関などは、指定対象者やその他の凍結対象者が関わる特定の取引や活動を行えば、制裁を受けるおそれがある。禁止行為には、指定対象者や凍結対象者による、それらの者に対する、またはその利益のための資金・物品・サービスの拠出や提供、あるいはそれらの者からの拠出や提供の受領が含まれる。米国人以外にも、米国人が認識の有無にかかわらず米国の制裁に違反するよう仕向けること、その共謀、および米国の制裁を回避する行為が禁じられている。米国内外の個人が金融犯罪取締ネットワーク（FinCEN）の内部告発者報奨制度に制裁違反の情報を提供し、それが100万ドルを超える金銭的制裁につながる執行措置の成功に結びついた場合、報奨の対象となり得る。
[経済制裁執行指針](https://www.ecfr.gov/current/title-31/subtitle-B/chapter-V/part-501/appendix-Appendix%20A%20to%20Part%20501) · [FinCENの報奨制度](https://www.fincen.gov/whistleblower-program)

また、本日指定された者が関わる特定の取引に従事する外国金融機関には、二次制裁が科されるおそれがある。関連する権限に基づき指定された者に代わって、重要な取引であると知りながらその取引を実行または仲介した外国金融機関について、OFACは、米国内のコルレス口座またはペイヤブルスルー口座の開設・維持を禁止するか、厳格な条件を課すことができる。

OFACの制裁の効力と信頼性は、対象者を指定して特別指定国民・凍結対象者リスト（SDNリスト）に追加できることに加え、法に沿って同リストから削除する意思にも支えられている。制裁の最終目的は、懲罰を科すことではなく、行動を望ましい方向に変えることである。SDNリストを含むOFACのリストからの削除手続や申請については、OFACの削除申請指針を参照されたい。
[削除申請指針](https://ofac.treasury.gov/specially-designated-nationals-list-sdn-list/filing-a-petition-for-removal-from-an-ofac-list)
