# イラン革命防衛隊海軍、ホルムズ海峡のタンカー2隻の機雷接触・火災を発表

出典: https://sepahnews.ir/fa/news/41218/

翻訳状態: partial

革命防衛隊海軍広報は、ホルムズ海峡東方と海峡内で、タンカー各1隻が機雷に接触して爆発し、激しく炎上していると発表した。同隊は、2隻が航法・測位装置を停止し、イランが許可していないとする経路を通ろうとしたと主張した。さらに、米軍に協力し、イランが定める航行規則に反して同隊のいう禁止海域へ入れば機雷に接触すると警告し、米中央軍司令官の発言に従わないよう求めた。
