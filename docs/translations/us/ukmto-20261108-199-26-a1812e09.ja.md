# 英海事当局の警報199-26　不審活動

出典: https://www.ukmto.org/-/media/ukmto/products/20261108-ukmto_warning_199-26.pdf

翻訳状態: partial

英国海運貿易オペレーション（UKMTO）警報 199-26、不審活動。

発生日時欄 2026年11月7日 19:20 UTC（日本時間11月8日 04:20）。通報元欄 軍当局。

英国海運貿易オペレーション（UKMTO）は、オマーンのハサブ北西8海里で起きた事案について、発生後に報告を受けた。軍当局の報告によると、タンカーで火災が発生し、乗員が退避した。 当局が調査する間、船舶は注意して通航し、不審な活動をUKMTOに報告するよう勧告する。

地図はオマーン・ハサブとその北西沖を表示。
