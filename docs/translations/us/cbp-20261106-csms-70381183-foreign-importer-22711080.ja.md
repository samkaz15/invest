# CBP、外国の輸入申告責任者向けの申告様式を更新

# 貨物システム・メッセージサービス（CSMS）第70381183号
## 外国の輸入申告責任者に対する要件を強化する暫定最終規則に基づく、CBP様式3461・7501と対応する電子様式の更新

米税関・国境警備局（CBP）は、大統領令第14411号「税関執行の強化」第2節および関連法令に基づき、輸入申告時の外国の輸入申告責任者（IOR）に新たな要件を設け、認可通関業者に対応する責任を課す。2026年11月6日付の暫定最終規則（IFR）「外国の輸入申告責任者に対する要件の強化」（連邦官報91巻69977頁）を参照されたい。

この案内は、CBP様式3461・7501および対応する電子様式に設けられた新しいデータ項目を貿易関係者に知らせるものである。

2027年1月5日以降、IFRにより、米国内での消費向けに貨物を輸入申告し、または保税から引き取るためには、外国のIOR自身がテロ対策のための税関・貿易パートナーシップ（CTPAT）の認証を受けているか、CTPAT認証済みの通関業者を指定して申告させなければならない。

CBP様式3461・7501および対応する電子様式には、次の3項目が追加された。

1. 「米国の輸入申告責任者」。「Y」を選ぶのは、IORが米国IORの基準を満たす場合、または通関業者がIORを務め、委任状の委任者が米国IORの基準を満たす場合。IORまたは該当する委任者が基準を満たさないときは「N」を選ぶ。
2. 「代理して申告」。通関業者が自らを申告提出者かつIORとする場合の欄。委任者に代わる輸入申告のため通関業者が自身を提出者かつIORとして記載する場合は「Y」、それ以外は「N」を選ぶ。
3. 「委任状の委任者」。CTPAT認証を受けていない通関業者が委任者の代理でIORを務める場合に必須。通関業者は、委任者のCBP様式5106にひも付いた委任者のIOR番号（社会保障番号、雇用主識別番号、CBP割当番号など）を報告する。

CBPは追加の検証機能を設けた。2027年1月5日以降、次の場合は輸入申告や申告明細を受け付けないことがある。

- 外国のIORがCTPAT認証を受けず、かつCTPAT認証済みの通関業者を利用せずに申告を試みる場合。
- CTPAT認証のない通関業者がIORを務め、必要とされる委任者情報を提出しない場合。

必要に応じ、通関業者は2027年1月5日までに遵守期限の延期を申請できる。[CBPの延期案内](https://www.cbp.gov/trade/strengthening-customs-enforcement/delayed-compliance)

IFRの公表に合わせ、新要件の概要を説明する収録済みのウェビナーを掲載する。[CBPの税関執行強化ページ](https://www.cbp.gov/trade/strengthening-customs-enforcement)

この案内についての問い合わせは、貿易局の貿易近代化部門へ送付できる。［連絡先アドレスは収録対象外］
