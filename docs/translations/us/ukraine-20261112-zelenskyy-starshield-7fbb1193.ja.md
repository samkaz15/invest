# ウクライナ大統領、Starshieldの速度制限と米側への照会を発表

出典: https://x.com/ZelenskyyUa/status/2120804738031616095

翻訳状態: complete

ウクライナのイェウヘニー・フマラ国防相とミハイロ・ドラパティー軍総司令官から報告を受けた。

残念ながら、われわれの部隊は数日前から、ウクライナ領内でStarshieldの運用に重大な支障が生じていることを確認している。前線全域と、一時的に占領されている地域で起きている。具体的には、Starshieldの使用に時速161キロメートル（時速100マイル）の速度制限が系統的にかかっている。ウクライナ軍はすでに状況を調査し、偶発的なエラーではなく、系統的な速度制限だと確認した。

われわれにとって、これは主にロシアのジェット推進無人機の迎撃を著しく難しくする。残念ながら、迎撃手段が十分な速度に達せず、間に合わなかったため、すでに攻撃が着弾している。これにより、ロシア側はより多くのウクライナ人を殺害し、ウクライナへの攻撃の精度を高めることができている。

米国側とすべての事情を確認しようとしている。
