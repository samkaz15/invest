# 米財務省、イランの石油取引に関わる人物を制裁対象に指定

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/43396e7

翻訳状態: partial

米財務省は、イラン政権による国外への石油販売を仲介する主要な「石油受託者」を制裁対象とすると発表した。同省は、米軍の封鎖外を航行する石油はなく、作戦開始以来、船舶への石油積載もないと主張し、政権が受託者から数十億ドルを回収しようとしていると述べた。また、多くの場合、受託者は石油収入を私益のために保持していたと主張した。これらの状況は独立検証されていない。
