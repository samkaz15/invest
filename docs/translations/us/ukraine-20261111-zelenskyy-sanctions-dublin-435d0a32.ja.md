# ウクライナ大統領、ロシアの兵器生産を支える部品・設備への制裁を要請

翻訳状態: partial

欧州の制裁に関する取り組みに触れたいと思います。制裁は必要です。プーチン氏とその体制のために働くロシアの個人・団体も、ロシアが兵器、特に弾道ミサイルや攻撃用無人機、通信システムを製造するのに不足している部品や設備、工作機械を調達するために利用する企業も対象です。

欧州と世界のすべてのパートナーに、ここに力を注ぐようお願いします。ロシアの兵器生産を制限する必要があります。それは、ロシアに和平に向けた実際の行動を促すための最善の方法の一つです。

ウクライナ独自の長距離攻撃による制裁は機能しており、ロシアの兵器生産施設は私たちの長距離攻撃の届く範囲にあります。重要なのは、パートナーがこれを法的、経済的、政治的に支えることです。制裁強化に取り組む欧州のすべての皆さんに感謝します。

ミホル・マーティン氏との共同会見で、こう述べました。
