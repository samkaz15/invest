# 米司法省、貿易不正の捜査端緒受付様式案への意見を募集

翻訳状態: partial

### 1ページ、連邦官報72922頁の司法省告示2026-23059

司法省。OMB番号1105-0NEW。情報収集活動。新たな電子情報収集案への意見募集。国際貿易・商取引執行課の捜査端緒受付様式。

担当機関は司法省の国家不正取締部門（FRD）。60日間の告示。FRDは1995年書類削減法に従い、この情報収集要請を行政管理予算局（OMB）に提出し、審査・承認を求める。意見募集は60日間で、2027年1月11日まで。照会窓口の個人名・連絡先を省略。

補足情報。一般および関係機関からの書面による意見・提案を歓迎する。次の4点のうち1点以上に触れてほしい。

- 提案した情報収集が担当部門の機能を適切に果たすために必要か。情報に実用性があるかを含む。
- 収集に伴う負担に関する機関の推計は正確か。方法と前提の妥当性を含む。
- 収集する情報の品質、有用性、明確性を改善できるか。できる場合はその方法。
- 電子的な回答提出など、自動化、電子的・機械的手段、その他の情報技術を用い、回答者の負担を最小化できるか。

情報収集の概要。

1. 区分は新規。
2. 名称は国際貿易・商取引執行課の捜査端緒受付様式。
3. 様式番号等の欄は105-0NEW。主な対象は政府、州、先住民部族。国際貿易・商取引執行課（GTCES）は貿易不正の捜査端緒を扱うために様式を利用する。複数の法執行機関と連携し、情報を精査し、優先順位を付け、捜査の重複を調整する。様式はウェブサイトに掲載せず、関係機関、非政府組織、業界側の弁護士、その他の情報提供元に直接提供する。
4. 回答は任意。
5. 推定回答者数は144。
6. 推定回答時間は1件10分。
7. 頻度は1回。
8. 年間時間負担の推計は1,440分。
9. その他の年間費用負担の推計欄には金額の記載がなく、追加照会先が記載されている。個人名・連絡先を省略。

2026年11月9日付。米司法省の書類削減法担当職員。官報文書2026-23059、11月10日08:45に公衆閲覧。請求コード4410-WZ-P。
