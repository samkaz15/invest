# 米墨国際橋の架け替えに関する環境評価案の官報告示

出典: https://www.govinfo.gov/content/pkg/FR-2026-11-12/pdf/2026-23077.pdf

翻訳状態: partial

米墨国際境界水委員会（IBWC）米国部門

テキサス州ハズペス郡リオ・グランデ河道改修事業におけるフォート・ハンコック＝エル・ポルベニル国際橋の架け替えに関する環境評価案と重大な影響なしとの判断の公表通知

米国部門（USIBWC）は、当該架け替え事業の環境評価案（EA）と重大な影響なしとの判断（FONSI）が閲覧できることを通知する。電子版はUSIBWCの意見募集ページで閲覧できる。［担当者の個人名・連絡先は省略。］

補足情報。USIBWCは、橋の構造上・安全上の問題に対処するため、米国側の新しい橋部分を建設し、メキシコ側に接続することを提案している。改正後の1969年国家環境政策法（NEPA）第102条第2項(C)および1981年9月2日付官報に掲載された同条の実施手順に従い、USIBWCは、実施案（優先案）と事業を実施しない案を分析した環境評価案を作成した。優先案は米国側を既存と同様の形状で架け替え、下部構造と橋床版の健全性に対処する。新しい部分は良好な状態にあるメキシコ側に接続する。高さ、幅、車道と歩道はおおむね既存と同様とし、水門を改良する。実施しない案では新設せず、安全上の問題に対処しない。

自然・文化その他の資源への潜在的影響を評価した。評価書の事実と分析に基づく提案事業の判断は重大な影響なし。環境影響評価書（EIS）は作成しないとしている。

2026年11月9日付。官報2026–23077、公衆閲覧登録11月10日午前8時45分。請求コードP。
