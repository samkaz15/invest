# OFACのSDNリスト更新通知　麻薬対策・テロ対策の指定

公表：米国11月13日付、時刻不明。受信：2026-11-14T02:04:49+09:00（日本時間）。

OFACの特別指定国民・凍結対象者（SDN）リストの更新

SDNリストが更新された。最新版は[制裁リストサービス](https://ofac.treasury.gov/sanctions-list-service)を参照されたい。リストに関する新しい形式や製品が提供された場合にも、このページが更新されることがあるため、定期的な確認を案内している。

本日の更新については、[OFACの個別告示](https://ofac.treasury.gov/recent-actions/20261113)を参照されたい。

## 確認範囲と再取得対象

受信メールの実質本文の全文訳。配信用ナビゲーション、連絡先および購読管理情報を除いた。個別告示は別文書として再取得する。
メールの実質本文は翻訳済み。公開配信版とリンク先の個別指定告示を取得できず、告示本文・指定表・脚注・付属PDFの有無は未確認。

制裁の対象は麻薬密売・テロ支援。燃料窃盗の言及は既往の背景説明で、対象措置による原油供給、金取引、関税、米国債への経路は本文から確認できない。
