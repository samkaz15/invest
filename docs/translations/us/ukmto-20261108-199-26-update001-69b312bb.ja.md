# 英国海事当局の警報199-26　攻撃への再分類

出典: https://www.ukmto.org/-/media/ukmto/products/20261108-ukmto_warning-_199-26_update_001.pdf

翻訳状態: partial

英国海事当局（UKMTO）警報199-26「攻撃」更新001。発生は11月7日19:20 UTC（11月8日04:20 JST）、通報元は軍当局。

UKMTOはオマーン・ハサブ北西8海里の事案の通報を発生後に受けた。軍当局によればタンカーで火災が発生し、乗員は退避した。当局が調査する間、船舶には注意して通航し、不審な活動をUKMTOに報告するよう勧告する。

更新001。UKMTOはこの事案を「攻撃」に再分類した。地図はハサブとその北西沖のおおよその対象海域を示す。
