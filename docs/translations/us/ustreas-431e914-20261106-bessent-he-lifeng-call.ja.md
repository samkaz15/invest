# 米中経済協議：ベッセント長官、中国に釜山合意の履行を要求

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/431e914

翻訳状態: complete

会談概要：スコット・ベッセント米財務長官と中国の何立峰副首相との電話協議

ワシントン — 本日、スコット・ベッセント米財務長官とジェミソン・グリア米通商代表は、中華人民共和国の何立峰副首相と電話で協議し、二国間の経済関係と釜山合意の履行について話し合った。両当局者は、直接かつ率直な意思疎通を維持することの意義を改めて確認した。

ベッセント長官は、中国が釜山で約束した事項を完全かつ即時に履行することの重要性を強調し、中国の最近の行動に対する懸念を伝えた。また、今後も前進するためには具体的な成果が必要であり、米国は中国による合意の履行状況を注意深く評価すると強調した。

ベッセント長官は、米国の労働者、農業従事者、企業に利益をもたらし、米国の経済安全保障と国家安全保障を強化する通商・経済政策を追求するという、トランプ政権の方針を改めて表明した。
