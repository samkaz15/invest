# OFAC制裁リスト更新とルクオイル関連一般許可の改定

出典: https://ofac.treasury.gov/recent-actions/20261119

翻訳状態: partial

OFACの特別指定国民・資産凍結対象者（SDN）リストの更新

米財務省外国資産管理局（OFAC）は、「2026年11月19日に資産凍結された特定の者に関わる取引の終了処理を認める」違法薬物関連一般許可第1号を発行します。

さらにOFACは、「Lukoil International GmbHの売却に係る条件付き契約の交渉・締結、および関連する維持活動に関する特定の取引を認める」ロシア関連一般許可第131L号を発行します。関連する改訂済みFAQ第1224号および第1225号も発行します。

最後に、OFACはSDNリストを変更しました。最新版はSDNリストのページを確認してください。同ページはリスト関連の形式・成果物が新たに提供される場合にも更新されるため、定期的に確認してください。

本日の更新の詳細は、関連ページを参照してください。
