# カタール外務省が米・イラン仲介の継続を説明

出典: https://mofa.gov.qa/en/qatar/latest-articles/latest-news/details/2026/11/10/foreign-ministry--qatari-mediation-efforts-continue-to-bridge-views-between-washington--tehran

翻訳状態: partial

カタール外務省の報道担当幹部は、米国とイランの隔たりを埋める仲介を続けており、地域内外の関係国との調整がこの数日・数週間で進んだと説明した。首相兼外相は11月9日にワシントンでバンス副大統領と会談し、その後ホワイトハウスでトランプ大統領と非公開で会談した。外務省は大統領との会談を前向きと評価し、米・イランの立場の隔たりを縮めることが焦点だったと説明した。合意の輪郭が固まった段階で詳細を公表するという。ホルムズ海峡については、冬を前に通航制約が各国、とりわけ脆弱な人々の負担を増すとして、航行の自由を早期に回復するよう求めた。サウジアラビアが安全と領土の一体性を守る措置を取ることへの連帯も表明した。会見後半では、仲介をめぐる報道の文脈と情報源の確認を呼びかけた。
