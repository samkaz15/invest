# G7外相会合 セッション1「危機・国際的課題」

出典: https://www.mofa.go.jp/fp/pc/pageite_000001_01910.html

翻訳状態: complete

現地時間11月9日午後0時15分（日本時間同日午後8時15分）から約90分間、フランス・パリを訪問中の茂木敏充外務大臣は、G7外相会合の「危機・国際的課題」に関するセッション（ワーキング・ランチ形式）に参加しました（G7各国外相及びEU上級代表が参加。ルーク・リンドバーグ世界食糧計画（WFP）事務局長も一部参加）。

本セッションにおいて、G7各国外相は、インド太平洋、アフリカ、中南米を始めとする地域情勢及びグローバル・ガバナンスといった国際的課題について、率直な意見交換を行いました。

茂木大臣から、インド太平洋情勢について、力又は威圧によるあらゆる一方的な現状変更の試みに反対する必要性、欧州・大西洋とインド太平洋の安全保障は不可分である旨を強調しました。また、核・ミサイル問題、暗号資産窃取、拉致問題を含む北朝鮮への対応についての連携を呼びかけました。さらに、拉致問題の即時解決に向けたG7各国の理解と協力への謝意を表明しました。

G7各国外相は、法の支配に基づく自由で開かれたインド太平洋の重要性を強調し、東シナ海、南シナ海及び台湾海峡におけるものを含む、力又は威圧によるあらゆる一方的な現状変更の試みに強く反対することを改めて表明しました。また、北朝鮮の不法な核・弾道ミサイル計画を強く非難し、国連安保理決議に従った北朝鮮の完全な非核化へのコミットメントを確認しました。さらに、北朝鮮による暗号資産窃取を含む悪意あるサイバー活動に共に対処する必要性を表明しました。加えて、G7各国外相は、北朝鮮に、拉致問題を即時に解決するよう改めて強く求めました。

また、茂木大臣からインド太平洋情勢の文脈で経済安全保障上の課題についても提起し、G7各国外相は、非市場的政策・慣行、恣意的な輸出規制といった経済的威圧等に、共に対応していくことを確認しました。
