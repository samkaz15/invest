# 中国商務部・海関総署、輸出管理公告6本の停止を延長

出典: https://www.mofcom.gov.cn/zcfb/dwmygl/art/2026/art_46a13d76cf7243b7af4394ecbdf13b90.html

翻訳状態: complete

商務部・海関総署2026年第58号公告。商務部・海関総署の2025年第55号、第56号、第57号、第58号および商務部の2025年第61号、第62号の施行停止を継続する決定を公表する。

承認を経て、2026年11月11日から2027年1月10日まで、商務部・海関総署の2025年第55号、第56号、第57号、第58号と、商務部の2025年第61号、第62号の施行停止を継続する。

商務部・海関総署。2026年11月9日。
