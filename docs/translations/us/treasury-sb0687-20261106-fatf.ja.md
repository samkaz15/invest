# FATFが米国のマネーロンダリング・テロ資金対策制度の有効性を認め、不正金融に関する主要な取組を推進。

出典: https://home.treasury.gov/news/press-releases/sb0687/

翻訳状態: complete

FATFが米国のマネーロンダリング・テロ資金対策制度の有効性を認め、不正金融に関する主要な取組を推進。
2026年11月6日、パリ。
先週、財務省高官が率いる米政府代表団が金融活動作業部会（FATF）の総会に参加した。マネーロンダリング、テロ資金供与および大量破壊兵器の拡散金融への対策で国際基準を定めるFATFは、英国議長国の下で初めての総会を終えた。FATFは米国とメキシコの相互審査報告書を採択し、イランへの対抗措置を求める呼びかけを再確認し、詐欺拠点に関する新報告書の公表と、デジタル資産関連基準の世界的な実施加速に合意した。

イランの不正金融の阻止：
イランは引き続きFATFのブラックリストに掲載されている。FATFは、イランが核合意を継続的に遵守していないことに関連して再適用された国連安全保障理事会決議を、すべての国が実施するよう求めた。また、イランとのコルレス銀行業務、デジタル資産取引および取引関係を制限する対抗措置を講じるよう、すべての法域に改めて求めた。

東南アジアの詐欺拠点の解体：
FATFは、詐欺拠点を支える資金の流れを調べた重要な報告書も採択した。これは詐欺への、より強力で協調的な世界的対応の基礎となる。これらの知見を踏まえ、FATFは利用可能な手段を全面的に使う具体策を進め、犯罪ネットワークの活動を妨げ、こうしたリスクに対処しない法域の責任を問い、被害者と世界の金融システムを守る。これらの拠点による詐欺は高齢者や弱い立場の米国人を標的にすることが多く、トランプ政権は詐欺を止めるため多数の制裁措置を取ってきた。

デジタル資産分野の前進：
FATFは、不正金融リスクを高める仮想資産分野の長年の不備がある一部の法域について、対象を絞った審査の開始にも合意した。この審査は、詐欺師、麻薬密売人、拡散関与者が交換業者を通じて資金洗浄できるような制度上の弱点を持つ法域に責任を求めるため、次回総会でFATFが取り得る措置の判断事項を示す。
