# 米国務省、ルビオ・王毅電話会談での首脳対話と米中ロ会談の可能性を公表

出典: https://pubt.io/view/D0DB709EC964865A1A213192E68525ED3CC836F3

翻訳状態: complete

中国側の要請により、マルコ・ルビオ国務長官兼国家安全保障担当大統領補佐官は本日、中国共産党中央外事工作委員会弁公室主任で党中央政治局委員の王毅外相と電話で会談した。両者は、中国で開かれるAPEC首脳会議に出席するトランプ大統領の訪中予定と、G20首脳会議に出席する習近平総書記のフロリダ訪問予定について協議した。

両者は、尊重、公平、相互主義を基礎とする建設的な戦略的安定関係に向けた、両国首脳の約束を改めて確認した。ロシアを含む三者首脳会談が開かれる場合も含め、平和や非核化といった目標を進めるため、実質的な首脳対話が重要であるとの認識で一致した。
