# 米商務省のPTMEG反ダンピング仮決定4地域

出典: https://www.trade.gov/commerce-preliminary-antidumping-duty-investigations-polytetramethylene-ether-glycol-peoples

翻訳状態: complete

米商務省は2026年11月6日、中国、韓国、台湾、ベトナム産PTMEGの反ダンピング調査で肯定的な仮決定を公表した。

| 原産地 | 製造・輸出者 | 率（％） |
| --- | --- | --- |
| 中国 | 中国全体 | 213.44* |
| 韓国 | Korea PTG Co., Ltd. | 25.32 |
| 韓国 | BASF Company Ltd. | 49.79* |
| 韓国 | その他 | 25.32 |
| 台湾 | Dairen Chemical Corporation | 7.46 |
| 台湾 | Formosa Asahi Spandex Co., Ltd. | 26.42* |
| 台湾 | その他 | 7.46 |
| ベトナム | Hyosung Dong Nai Company Limited（製造・輸出） | 36.55 |
| ベトナム | ベトナム全体 | 36.55 |

* 利用可能な情報に基づく不利な推認を用いた率。中国全体の率にも同じ注記がある。

中国の最終決定は仮決定署名日を基準に2027年1月18日、韓国・台湾・ベトナムは官報掲載日を基準に2027年3月29日頃を予定。申立人はBASF Corporation（ニュージャージー州フローラムパーク）。米国国際貿易委員会（ITC）は並行して損害調査を実施中。日程はITCのカレンダー参照。一般情報と次の手順は仮決定のFAQを参照。対象範囲や申し立てられた補助金制度などの追加資料は、執行・遵守部門の反ダンピング税・相殺関税の電子システム（ACCESS）で下記の案件番号を参照する。商務省によれば、現時点で米国の企業・産業を不公正貿易から救済する反ダンピング・相殺関税の命令は856件。

案件番号は中国A-570-227、韓国A-580-922、台湾A-583-882、ベトナムA-552-855。
