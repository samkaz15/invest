# 原油価格のコアインフレへの影響、先進経済の最近の証拠

出典: https://www.federalreserve.gov/econres/notes/feds-notes/the-effect-of-oil-prices-on-core-inflation-recent-evidence-from-the-advanced-economies-20261109.html

翻訳状態: partial

「ここで示す結果は、米国や海外経済のインフレについての公式予測を表すものではない。」

対象はカナダ、ユーロ圏、日本、英国、米国。米国のコアPCEと他地域のコアCPIを使用し、現地通貨ベースの相対ブレント価格、需給ギャップ、供給網圧力を組み込んだ。2021年1〜3月期から係数が変わり得る仕様で推計した。

表1の標本内RMSE（全期間／パンデミック後）は、係数固定0.31／0.37、持続性上昇のみ0.24／0.31、持続性と原油波及の上昇を許す仕様0.14／0.17。予測力の標本外検証ではない。表2の95％区間は、持続性の前期0.225〜0.470、増分0.202〜0.395、波及係数の前期−0.002〜0.004、増分0.004〜0.021。

図2は原油価格が恒久的に10％上がる実験。図表データの12四半期後のコア価格水準は、波及と持続性の両方を引き上げる仕様で約0.36％高い。これは価格水準の変化で、表2を用いたインフレ率の反応とは指標が異なる。図3のシナリオには2026年8月初めの先物曲線を使用。図4はコスト上昇と需要抑制の両経路を示す構造モデル実験。推定はパンデミック後の短い標本に依存し、構造変化と供給ショックの頻度・持続期間の変化を区別できない。国別の波及上昇はカナダ、日本、米国で有意、ユーロ圏・英国で有意でなかったと脚注に記載。
