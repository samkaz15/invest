# ウクライナ大統領府のインド首相との電話協議発表

出典: https://www.president.gov.ua/en/news/prezident-ukrayini-obgovoriv-iz-premyer-ministrom-indiyi-dip-107209

翻訳状態: partial

ウクライナ大統領府によると、両首脳は電話でアブダビ会合の準備や黒海の穀物輸送を協議した。同府はインドが食料回廊の設置に向けた仲介に応じる用意があると述べた。両政府の担当チームは連絡を続ける。引用文の訳「インドには食料回廊の設置を仲介する用意があり、ウクライナはこうした取り組みの継続に期待している。」
