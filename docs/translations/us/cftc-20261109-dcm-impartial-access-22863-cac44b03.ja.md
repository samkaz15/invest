# 米商品先物取引委員会の指定契約市場の公平なアクセス要件

出典: https://public-inspection.federalregister.gov/2026-22863.pdf

翻訳状態: partial

## 1頁
この文書は2026年11月10日の連邦官報掲載予定。掲載予定先は https://www.federalregister.gov/d/2026-22863 と https://govinfo.gov 。請求コード6351-01-P。米商品先物取引委員会（CFTC）、連邦規則集17編第38部、指定契約市場（DCM）の公平なアクセス要件。措置の種類は解釈指針。

CFTCは、委員会規則38.151(b)に基づき、DCMが会員および取引権限を持つ者に対して競争的で、開かれ、公正かつ公平なアクセスを提供すべき要件を解釈する。最終解釈指針は、取引所がアクセス基準を選定する際に指針とすべき同要件について、委員会の見解を公にするもの。イベント契約やその他の金融資産の上場・取引の監督、DCMのアクセス要件の監視に相当の時間と労力をかけた上で公表する。発効は連邦官報掲載日。問い合わせ先の個人情報は省略。
## 2頁
I　背景。商品取引所法（CEA）の中核には、DCMが会員と取引権限を持つ者に競争的で、開かれ、公正かつ公平なアクセスを提供する要件がある。これは参加者に対して差別的アクセスが競争上の手段として不当に使われることを防ぐ。市場全体の流動性を高め、リスク管理と価格・情報発見の機会を最大化することにより、DCMと全国市場にも利益をもたらす。委員会は、イベント契約やその他の金融資産の上場・取引を監督し、DCMのアクセス要件を監視してきた職員の経験を踏まえ、DCMとその関連会社・提携先に見解を伝える。取引所がアクセス基準を選ぶ際の指針となる公平なアクセス要件について、委員会の見解を公にする。

II　公平なアクセスを求める規制枠組み。DCMは商品取引所法が定める23の基本原則と適用されるCFTC規則を守る必要がある。基本原則は、取引規則の設定・執行（開かれた公平なアクセス基準の設定を含む）や取引監視を通じて、デリバティブ市場の健全性を支える取引所の役割を反映する。脚注1は米国法典第7編第1条以下、2は同法5条(d)（米国法典第7編第7条(d)）、3は連邦規則集17編38部。
## 3頁
基本原則2はDCMにアクセス要件を含む規則を定め、監視し、遵守を確保するよう求める。基本原則9は、取引所の集中市場での価格発見を保護する、競争的で開かれた効率的な市場と取引執行の仕組みの提供を求める。DCMは会員、取引権限保有者、独立系ソフトウェア業者に市場とサービスへの公平なアクセスを提供し、公平で透明かつ差別なく適用される基準を定める。会員と取引権限保有者への拒否・停止・取消しに関する規則を定め、懲戒・緊急措置の一部として行う場合を含め公平に執行する。

III　公平なアクセスの一般原則。委員会は2012年、特定の参加者に対して差別的なアクセス要件を競争手段に使うことを防ぐために公平なアクセスの規則が必要と説明した。規制対象者の基準の設定にあたり、参加者の財務・業務の健全性を基準にすべきで、差別的なアクセスや参入障壁につながる要素によって拒むべきではない。公正で公平な基準はDCMと会員の双方に利益をもたらす。脚注4は同法5条(d)(2)(A)(i)、5は同法5条(d)(9)(A)、6は規則38.151(b)(1)、7は同(c)、8は2012年6月19日官報77 FR 36612、36625、9は同上。
## 4頁
例えば、要件を満たす参加者への公平なアクセスは、DCMの流動性とスワップ・先物市場の全体の透明性を高めると見込まれる。異なる参加者区分は設けられるが、同じ区分内で差別はできない。

委員会は、差別的な参加制限は市場全体の健全性と効率に影響すると考える。財務または業務が健全な幅広い参加者のアクセスを制限したり、参加の誘因を弱めたりすれば、流動性と価格発見が弱まるおそれがある。市場ショックを吸収し対応する参加者が通常から少なくなれば、価格形成と市場効率の悪化によって変動が大きくなり、取引・リスク管理の場としてのDCMの機能が損なわれ得る。

DCMへのアクセスを求める参加者は、明確に定義し事前に公表し一律に適用する基準で評価すべきと委員会は考える。各参加者は要件を把握して備えられる。不透明、恣意的、または参加者の財務・業務の健全性と無関係な基準は規則38.151の原則を損なう。客観的で透明な財務・業務上の資格要件を満たせば、DCMは偏りなくアクセスを認める義務があるとの見解。幅広い参加者が市場流動性に寄与できる競争的で強固なデリバティブ市場を支える。脚注10は前掲、11は同36672頁。
## 5頁
公平なアクセスが問題になった過去には、委員会は規制対象者へ指針を公表してきた。2011年にはスワップ執行施設（SEF）に重要な公平アクセス要件を課す案を出し、2013年に最終規則を公布。同年には市場監督、清算・リスク、スワップディーラー・仲介業者監督の各部門（最後は現在の市場参加者部門）が、一部SEFによる取引の制約や「取引を可能にする仕組み」に関する指針を公表した。今年は、奨励制度で比較可能な手数料体系を設定する際のDCM向け指針を職員書簡で公表した。

IV　地理的所在地に基づくアクセス基準。一部のDCMは、取引希望者の所在地や居住地に基づき、特定のイベント契約市場へのアクセスを制限している。CEAと委員会規則は、ほかの資格要件を満たす参加者について、米国内の所在地を理由にDCMがアクセスを制限することを原則認めない。

脚注12はSEFの提案（76 FR 1214、2011年1月7日）、最終規則（78 FR 33476、2013年6月4日）と訂正（78 FR 47154、2013年8月5日）。13は2013年11月14日付の3部門のSEFに関する委員会規則の適用指針。14は2026年8月12日付CFTC書簡26-23。脚注13のリンクは https://www.cftc.gov/sites/default/files/idc/groups/public/@newsroom/documents/file/dmostaffguidance111413.pdf 、脚注14のリンクは https://www.cftc.gov/csl/26-23/download 。15は基本原則2に基づきDCMは、会員規則に従う仲介業者が地理を理由に公平アクセスに反する制限を課さないよう、合理的な措置を講じる必要があるとする。同法5条(d)(2)(B)は違反の検知・調査・適切な制裁の能力を求める。基本原則12は自主規制機関として、不公正な行為から市場と参加者を守り、公正で公平な取引を促進するよう求める。規則38.651は、基本原則2と4に従い、取引制度と市場構造に適した方法・資源を使って不正を検知し懲戒することを含む。
## 6頁
連邦議会はCEAの制定に当たり、流動的で公正かつ財務的に安全な取引施設で価格リスクを管理・引き受け、価格を発見し、価格情報を伝える手段をデリバティブ市場が提供することから、連邦規制に全国的な公益があるとした。法の目的を達成するには、全国規模で統一的に運営される必要がある。

DCMは、資格要件を満たす参加者を意図的に排除したり、参加を思いとどまらせたりする基準を設けられない。ある米国の州や地域の参加者を認めながら別の地域の参加者を排除する制限は、財務・業務の健全性で同じ状況にある適格者に一律に適用されず、所在地だけで恣意的に区別するため、公平なアクセスを損なう。

地理的制限は市場の健全性とリスク管理にも問題を生む。アクセス可能な地域で建てたポジションを持つ参加者が制限地域に移動すると、ポジションを管理し、市場の動きに対応し、証拠金の追加請求に応じることができないおそれがある。強制決済が起こり得る。

脚注15続き。委員会は、基本原則2に基づく公平アクセスを仲介業者が妨げないよう確保する責任がDCMにあると考える。同法5条(d)(11)と規則1.52(c)も参照。脚注16は同法3条(a)。全国規模の取引の促進という議会の目的は、先物・スワップ取引を妨げる者への差止措置を求められるCFTCの権限（同法6c条(a)）にも表れている。
## 7頁
強制決済は、関与した先物取引仲介業者と清算機関の双方に損失を生じさせ、デリバティブ市場と金融市場全体のシステミックリスクを高め得る。混乱は個別参加者と関連市場全体に及び、市場の健全性と効率を損ない得る。

所在地に基づく制限は、DCMの価格発見機能と効率も損なう。州や地域で経済構造が異なるため、一部住民を排除すれば市場が歪むおそれがある。取引量の多い参加者やマーケットメーカーが集中する地域を制限すれば、流動性への懸念が生じ、その影響は一部の契約に偏り得る。全体の取引量が減少し、売買気配の差が広がり、参加者全体の取引費用が増える可能性がある。

地理的制限は、全国の流動性を分断し得る。所在地によって関連市場にアクセスできなければ、関連契約間やデリバティブと原資産の現物市場の間の裁定が妨げられる。価格差が長引き、利用可能なヘッジ手段がリスクへのエクスポージャーに十分追随せず、ベーシスリスクが高まり得る。

取引活動が少数で同質的な参加者に集中するおそれもある。参加者層が広いと、投資期間、リスク許容度、情報、取引戦略の違いから、状況変化に対する流動性の強靱性が高まり得る。取引活動が多い地域を丸ごと排除すれば、一部の参加者への依存が強まり得る。スポーツ関連契約が例となる。
## 8頁
例えば地元チームのプレーオフ進出に関する契約のように、特定地域の関心が特に高い場合、その地域を除外すれば契約全体の流動性が低下し得る。

関係する実務経験、地域固有のリスクや知識、活発な取引活動を持つ参加者がいる地域を排除すると、ヘッジ機会やDCMの価格・情報発見機能も損なわれる。異常気象が起きやすい地域を気象関連契約から排除すれば、その地域の取引参加者は異常気象リスクのヘッジ手段を失う。エネルギー生産やインフラが集中する地域の生産者、商業事業者、取引業者が排除されれば、生産・輸送・貯蔵に関わるリスクのヘッジが制限され、ヘッジ・裁定・投機から得られる価格シグナルが失われ得る。金融、農業、文化、技術に専門性が集中する地域でも、程度の差はあれ同様の影響が生じ得る。

選挙契約の市場はとりわけ地理的制限の影響を受けやすい。州や地域の選挙に関する市場では、その州・地域の住民が取引量や知識の多くをもたらす場合がある。住民のアクセスを制限すると、その選挙の市場の取引量や情報発見機能が大きく損なわれ得る。特に、情報に基づく取引は州や地域に集中し得る一方、選挙契約市場の情報発見の恩恵は全国に及ぶ。報道機関や他の第三者が、予想される結果を考える際の一情報源として契約価格を用いる場合があるため、影響は直接の取引参加者以外にも及び得る。
## 9頁
以上から、委員会は地理的アクセス制限はCEAと委員会の規則に整合しないと考える。DCMが遵守確保のため、アクセス基準、取引所規則、仲介業者を通じたアクセスの仕組みを点検することを期待する。

行政管理予算局は、改正後の大統領令12866が定める重要な規制措置に該当しないと判断したため、同令に基づく審査の対象ではなかった。委員会は2026年11月5日にワシントンDCで発出。委員会事務局長クリストファー・カークパトリック。付録の投票結果は連邦規則集に収録されない。セリグ委員長が賛成し、反対票はなかった。官報文書2026-22863。提出11月9日午前8時45分、掲載予定11月10日。
