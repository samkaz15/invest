# EU首脳のダブリン共同声明、対ロ制裁第22弾とウクライナ資金協議を予告

出典: https://www.consilium.europa.eu/en/press/press-releases/2026/11/12/joint-statement-by-president-costa-and-president-von-der-leyen-following-their-meeting-with-president-zelenskyy-in-dublin/

翻訳状態: partial

ダブリンの欧州政治共同体首脳会合は、ゼレンスキー大統領とウクライナに対する揺るぎない支持を改めて確認する機会となった。

今週のアブダビ協議と、和平プロセスが再び動き出したことを歓迎する。EUはこの和平協議の場におり、今後もこの枠組みに関与する。ロシアの侵略戦争の初日からそうしてきたように、ウクライナの主権、領土保全、欧州大陸の安全を守る公正で持続的な平和に向けて、ウクライナを支え続ける。

EUとその政策手段は、こうした取組の中核をなす。ウクライナの立場を強めるため、相当規模の財政・軍事支援を引き続き提供する。和平協議の一環として、実行可能な戦後復興計画の確保に取り組み、ウクライナのEU加盟に向けた歩みを積極的に支える。

次回11月26～27日の欧州理事会で、欧州委員会の提案に基づき、2027年に向けたウクライナの緊急資金需要を協議する。欧州委員会は並行して、第22弾の対ロシア制裁パッケージを提示する。

ウクライナは強い立場から交渉する必要があり、ロシアには真に和平を求める意思を持って交渉の場に着くよう働きかける必要があるためだ。

戦時下でまた冬を迎えるなか、欧州委員会は現地で緊急支援を展開している。私たちは、電力を維持し、冬を通じてウクライナの人々を支えると約束した。その約束を実行している。

rescEUの備蓄から発電機500台を動員し、緊急支援センターの設置を助け、必要不可欠な機材を提供している。ノルウェーからの浮橋4基と、バス200台の引き渡しも支援している。必要とする人々に支援が届くよう、私たちの担当者はウクライナ当局と緊密に連携している。
