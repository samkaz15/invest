# 日米外相間の意見交換

出典: https://www.mofa.go.jp/na/na1/us/pageite_000001_01911.html

翻訳状態: complete

現地時間11月9日午後、G7外相会合に出席するためフランス・パリを訪問中の茂木敏充外務大臣は、マルコ・ルビオ米国国務長官と意見交換を行いました。

両外相は、日米共通の課題について意見交換を行い、その中で、安全保障環境が一層厳しさを増す中、日米同盟の抑止力・対処力を強化していくため、日米間で安全保障協力を一層進めていくことで一致しました。

また、両外相は、今後の外交日程も念頭に、インド太平洋地域をはじめとする地域情勢について意見交換を行い、引き続き緊密に連携していくことで一致しました。

両外相は、ICCを含め、これまでも議論してきた国際社会が抱える様々な課題に対して緊密に連携して取り組んでいくことを確認しました。
