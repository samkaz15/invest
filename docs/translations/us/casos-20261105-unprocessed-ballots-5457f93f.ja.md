# カリフォルニア州務長官室の未処理票推計（11月5日発表）

出典: https://www.sos.ca.gov/administration/news-releases-and-advisories/2026-news-releases-and-advisories/office-california-secretary-state-issues-unprocessed-ballot-report

翻訳状態: partial

カリフォルニア州務長官室は、郡の選挙当局が2026年11月3日の総選挙の開票を続けていると有権者に案内した。郡の選挙当局には、票の集計、監査、認証を含む公式集計手続きを完了するため、選挙日から最長30日が与えられている。結果の更新頻度は郡ごとに異なる。

郡の選挙当局はすでに8,906,017票の投票用紙を処理・集計した。処理・集計が残っている投票用紙は4,816,722票と郡当局が推計している。未処理票報告は各郡の推計をまとめたもので、州の結果サイトに掲載される。

選挙日以前または当日の消印があり、選挙日から7日以内に郡の選挙当局へ届いた郵便投票は、処理しなければならない。

郡の選挙当局は、州および連邦の選挙の最終結果を12月4日までに州務長官に報告しなければならない。州務長官は12月11日に結果を認証する。票の集計手続きについては州の案内を参照。
