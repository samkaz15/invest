# カタール外務省報道官が米・イラン協議の継続を説明

出典: https://x.com/majedalansari/status/2118845689497358338

翻訳状態: partial

### 原文抜粋の日本語訳

「両当事者は合意に向けた取り組みを続けている」

### 投稿全体の要約

カタール外務省報道官は、米国とイランが合意に至らなかったと首相兼外相が述べたとする情報を否定し、発言の歪曲だと主張した。報道官によれば、首相兼外相は、両当事者が合意を目指し、カタールの仲介担当者が交渉を支えるため両側と緊密に連絡を取っていると説明した。報道官は、世論を誤導し外交を妨げるような情報発信を批判した。
