# 米退役軍人省コリンズ長官、記念日に医療・給付の実績を発表

出典: https://news.va.gov/press-room/sec-collins-highlights-va-accomplishments-pledges-additional-improvements-ahead-of-veterans-day/

翻訳状態: complete

ワシントン。退役軍人省のダグ・コリンズ長官は、2026年の退役軍人の日に以下の声明を発表しました。

「米国は今年、建国250周年を迎えました。偉大な国を守るために戦った何百万人もの退役軍人がいなければ、この節目を迎えることはできませんでした。毎年、退役軍人の日に、私たちはこの英雄たちの奉仕と犠牲に敬意を表し、制服を脱いだ後の彼らを支える取り組みを一層強めます。

退役軍人が奉仕によって得た医療と給付を提供するのが退役軍人省の仕事です。トランプ大統領の下で、これまで以上に質を高め、迅速かつ効率的に提供しています。取り組みは続いており、近い将来さらなる改善を進めます。」

第2次トランプ政権下での主な実績。

- 新たに診療所47か所を開設し、各地で受診機会を拡大。
- 2025年1月20日から給付待ち案件を約70％削減。障害補償請求の平均処理時間は46％短縮。
- 2026会計年度に補償請求311万件を処理。2024会計年度比23.5％増。申請の60％超を承認し、正確性は約94％で過去3年で最高。退役軍人不服審査委員会への不服申立ては決定の約3％。
- 2026年に33万人を超える退役軍人が新たに医療に登録。
- 2026会計年度の省直営医療の受診は過去最多の8,270万件で、2024会計年度比4.9％増。地域の医療機関での受診も過去最多の6,810万件で、同26.7％増。
- 2026会計年度に医療施設の近代化・修繕・改善へ約50億ドルを投じた。省の臨時保守投資として過去最大。
- 2025年1月20日以降、通常の業務時間外に350万件を超える受診枠を提供。早朝、夕方、週末の枠で受診しやすくした。
- 電子医療記録の近代化を計画軌道に戻し、オハイオ・ケンタッキー両州で計5施設、ミシガン州で4施設、インディアナ州で3施設、アラスカ州で1施設に導入。
- 2025・2026会計年度に、住まいのなかった退役軍人9万5,000人超の住まいを確保。
