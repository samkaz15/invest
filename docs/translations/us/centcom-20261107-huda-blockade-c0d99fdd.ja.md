# 米中央軍がオマーン湾で貨物船Hudaを航行不能にしたと発表

出典: https://www.dvidshub.net/news/578872/us-forces-disable-cargo-vessel-attempting-violate-naval-blockade

翻訳状態: complete

**米中央軍発表の日本語全訳**

フロリダ州タンパ。米中央軍（CENTCOM）部隊は11月7日、オマーン湾で商船1隻を航行不能にした。CENTCOMによると、同船の民間人乗組員は繰り返しの警告に従わず、米国の対イラン海上封鎖に複数回違反しようとした。

米軍機はセントクリストファー・ネービス船籍の貨物船M/V Hudaの船尾に精密誘導弾を発射し、同船を航行不能にした。CENTCOM部隊はその前に、乗組員に攻撃対象区画から退避するよう指示した。同船はイランの港に寄港した後、同地域の海域から離れようとしていた。

CENTCOMは米国の対イラン海上封鎖を厳格に執行し続けている。7月以降の執行で、米軍は指示に従った商船147隻の針路を変更させ、指示に従わなかった商船5隻を航行不能にした。

このほかCENTCOMは以前、イラン革命防衛隊の数十億ドル規模の非公然ネットワークの一部だったイランの商業石油タンカー10隻を破壊した。

イランの沿岸域や周辺海域を航行するすべての船員に、米軍の封鎖警告に従うよう勧告する。

出典は米中央軍。死傷者、積載貨物、環境影響は本文に記載がない。添付映像は米中央軍が公表した17.8秒の映像で、標本フレームでは船尾付近から煙が上がる様子を確認した。映像だけで船名や位置、封鎖違反、被害の全体を独立に確定できない。
