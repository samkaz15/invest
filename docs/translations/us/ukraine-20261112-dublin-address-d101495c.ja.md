# ウクライナ大統領のダブリン演説

出典: https://www.president.gov.ua/en/news/zvernennya-prezidenta-ukrayini-do-uchasnikiv-9-go-samitu-yev-107281

翻訳状態: partial

ゼレンスキー大統領は欧州政治共同体のダブリン会合で、ウクライナ代表団がアブダビで米露と協議し、捕虜交換で合意したと説明した。安全保障の保証には欧州・ロシア間の枠組みも関わるとして、欧州の恒常的な参加を求めた。米特使らはモスクワ訪問後、ダブリンで協議結果を話す予定だと述べた。

同氏によると、ウクライナ側は黒海での緊張緩和とエネルギー施設への攻撃停止を提案したが、ロシア代表団は協議の権限がないと答えた。大統領は防空用の迎撃ミサイル、F-16の弾薬、冬季のエネルギー機材、大都市の強靱化計画への支援を要請した。

大統領はまた、一時占領地域でStarshieldの時速161キロの制限を再び検出し、無人機迎撃に影響すると述べた。米側に確認中で詳細はほとんど把握できていないとも説明した。前線の状況に関する説明や攻撃に関する記述は当事国の発言。今回、技術ログ、米側説明、現地の独立検証は取得できなかった。

EU加盟交渉の残る2分野を年内に開くこと、弾道ミサイル・攻撃用無人機・通信機器の製造、ロシアの石油輸送船団と金融機関への制裁強化も求めた。
