# ロシア外務省、駐米大使ダルチエフ氏の死去を発表

出典: https://t.me/MFARussia/33312

翻訳状態: partial

ロシア連邦の駐アメリカ合衆国特命全権大使アレクサンドル・ダルチエフ氏の死去について。

ロシア外務省の幹部と職員は深い悲しみとともに、ロシア連邦の駐米特命全権大使アレクサンドル・ダルチエフ氏が11月11日、66歳で急逝したことをお知らせします。

私たちは、優れた外交官、経験豊かな指導者、心優しい同僚、そして指導者を失いました。卓越した実務家で米国事情にも精通していたアレクサンドル・ダルチエフ氏は、ロシア外交の中でもとりわけ難しい分野を担当しました。

ダルチエフ氏のご家族と親しい方々に、心から深くお悔やみを申し上げます。あまりに早く旅立った同僚の大切な記憶は、私たちの心に永遠に残ります。
