# 米中央軍が対イラン輸送対策部隊アイアンゲートの設置を発表

出典: https://x.com/CENTCOM/status/2119059918120526182

翻訳状態: partial

【米フロリダ州タンパ】11月7日、米中央軍（CENTCOM）の司令官は、イランが先進兵器やその他の物資の輸送に陸路を使うのを阻止するため、米政府が進めている取り組みを支援する部隊の設置を指示した。

司令官は、フロリダ州タンパを拠点とする、文民と軍人約20人からなる内部組織「タスクフォース・アイアンゲート」の編成を指示した。新部隊は他の米政府機関と連携し、イランの陸上国境とカスピ海を通じた先進兵器システム、軍民両用技術、制裁対象物資の移動や、違法な資金の流れを阻止する。

司令官は「タスクフォース・アイアンゲートの設置は、イランに対する我々の強固な海上封鎖の成果をさらに確かなものにする。米政府の関係機関との連携を強化することで、イランがテロに資金を提供し、兵器工場を再建し、軍備を補充する能力を一層制約する」と述べた。

米中央軍によると、米国の海上封鎖によって、ここ数カ月でイランは250億ドル超に相当する原油を輸出できなかった。イランの港湾に出入りするすべての船舶を対象に、海上での厳格な措置が続いている。

### 添付図の日本語訳

- **タスクフォース・アイアンゲート**　2026年11月発表。対象はイランの国境とカスピ海。先進兵器システム、軍民両用技術、制裁対象物資の違法な移動と、違法な資金の流れを監視・検知・阻止する。
- **海上封鎖**　2026年7月発表。対象はペルシャ湾（原文はアラビア湾）とオマーン湾に面するすべてのイランの港湾。人道支援を例外として、イランへの輸入とイランからの輸出を阻止する。
