# 米大統領判断第2027-02号、イラン以外の石油供給の十分性

出典: https://public-inspection.federalregister.gov/2026-23233.pdf

翻訳状態: complete

ホワイトハウス、ワシントン。2026年10月28日。大統領判断第2027-02号。

国務長官、財務長官、エネルギー長官宛て覚書。件名は、2012会計年度国防権限法第1245条(d)(4)(B)および(C)に基づく大統領判断。

合衆国憲法および法律により大統領に与えられた権限に基づき、2026年10月に提出されたものを含むエネルギー情報局（EIA）の議会提出報告、世界経済の状況や戦略備蓄の利用可能性などの関連要因を慎重に検討した。2012会計年度国防権限法（公法112-81）第1245条(d)(4)(B)および(C)に基づき、従前の判断と同様、外国金融機関が、または外国金融機関を通じてイランから購入する石油および石油製品の量を大幅に減らすことが可能なだけの石油および石油製品が、イラン以外の国から十分に供給されていると判断する。

この状況を引き続き注視する。国務長官に対し、この判断を連邦官報に掲載する権限を付与し、その掲載を指示する。

事前公開文書2026-23233。米国日付2026年11月12日11:15受付、11月13日官報掲載予定。
