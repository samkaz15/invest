# チョルノービリ原発の新安全閉じ込め施設修復に向けた拠出表明

出典: https://www.ebrd.com/home/news-and-events/news/2026/international-community-backs-ebrd-managed-fund-to-restore-chorn.html

翻訳状態: partial

## 発表の詳細要約

仏政府、ウクライナ政府、欧州復興開発銀行（EBRD）がパリで共催した拠出会合で、米国を含む14の国・国際機関がEBRD管理の国際チョルノービリ協力勘定（ICCA）に総額3億300万ユーロを拠出すると表明した。参加は対面・オンラインを合わせ34の国・機関。EBRDはEU、カナダ、ドイツ、フランス、米国、英国、ノルウェー、スイス、リトアニア、オーストリア、エストニアなどの拠出に言及するが、米国分の金額、国・機関別の金額表、入金額は本文に記載されていない。ギリシャ、モルドバ、オランダは今後の表明を見込む。

対象は1986年事故の4号機の残骸を閉じ込め、旧覆いなどの解体を可能にする施設。EBRDは2025年2月14日のドローンによる損傷で両機能が損なわれたと説明。当日のIAEAチームは爆発音、煙・火災、外層の破損を現地で確認した。実行主体はEBRD・ウクライナ側の説明と区別する。

応急修理が進み、2026年3月承認の初期設計・調達は上限3,000万ユーロ。主要工事は2028年初頭着手、2030年末完了が現在の計画。2027年末までに費用見積もりの精度が上がる見通し。ウクライナ側は必要額を約5億ユーロと説明したが、EBRDは総工費はなお未確定としている。EBRDの先行発表にはG7の2億6,000万ユーロの関与がある。今回総額との重複内訳が未公表のため合算しない。
