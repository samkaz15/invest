# 米財務省９月TIC統計の本文翻訳補完

出典：https://home.treasury.gov/news/press-releases/sb0693/

公表日：2026年11月18日（米国日付）、時刻・日本日付不明。取得：2026-11-19T06:24:34Z

ワシントン発。米財務省は2026年9月の対米証券投資（TIC）統計を公表した。2026年10月分を扱う次回公表は2026年12月15日を予定する。
9月の外国人による長期証券、米短期証券の純取得と銀行フローを合計したTIC純流入は2610億ドルだった。内訳は外国民間部門が2670億ドルの純流入、外国公的部門が60億ドルの純流出だった。
外国居住者の米長期証券保有は増加し、純購入額は1867億ドルだった。外国の民間投資家の純購入は1483億ドル、外国公的機関の純購入は384億ドルだった。
米国居住者は外国長期証券の保有を増やし、純購入額は314億ドルだった。
株式交換を通じた外国人の米株式取得推計などの調整を加えた長期証券全体の外国人純購入額は、9月に1553億ドルだったと推計される。
外国居住者の米国財務省短期証券保有は35億ドル増加した。外国居住者のドル建て米短期証券全体とその他保管債務の保有は29億ドル減少した。
銀行自身の外国居住者に対するドル建て純債務は1086億ドル増加した。
完全なデータは財務省ウェブサイトで利用できる。
【TIC統計について】
長期証券保有の月次データと米国債の主要外国保有者の月次表は、主に保管機関のデータに基づいて収集された外国人の米国証券保有を反映する。これらは保有状況を知る手掛かりになるが、保有者を完全に正確には特定できない。例えば外国居住者が購入した米国債が第三国の保管口座にあれば、真の所有者は統計に反映されない。また、他国居住者のために投資する外国の民間運用会社が管理する米国債も、保管機関データでは適切に保有者に割り当てられない。さらに外国は、TICに捉えられないドルやその他の米国資産を保有している場合がある。こうした理由から、TIC統計を使って国別の米金融資産保有の変化について正確な結論を導くことは難しい。
