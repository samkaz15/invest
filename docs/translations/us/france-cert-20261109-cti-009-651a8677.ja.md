# 仏C4技術報告、革命防衛隊と関連する対仏サイバー活動

出典: https://cert.cyber.gouv.fr/uploads/CERTFR-2026-CTI-009.pdf

翻訳状態: partial

## PDF 1頁

C4（サイバー危機調整センター）の構成機関は、フランスの利益を狙った複数の不安定化攻撃を観測し、イラン革命防衛隊の電子・サイバー部門で活動するShahid ShoostariとShahid Kavehの両部隊に帰属させた。2026年10月11〜12日の産業用冷蔵制御装置への攻撃は規模と攻撃性で前例がないとし、少なくとも2020年からの攻撃の例として、2023年のシャルリー・エブドや、2024年パリ五輪・パラリンピックに関連する映像表示企業への攻撃を挙げる。

C4は10月12日に、フランスの大手小売業の約700拠点の冷蔵制御装置を狙った攻撃の通報を受けた。11日夜から12日に装置が侵害され、除霜の設定温度が高く変更され、大量の商品が失われ、少なくとも15件の出火があったとする。主な被害先は大手小売業で、複数の小規模な食肉店、食肉処理場、協同組合の食品加工施設も被害を受けたという。脚注1はC4を省庁横断の脅威分析組織とし、ANSSI、COMCYBER、DGA、DGSE、DGSIからなると説明する。

## PDF 2頁

C4によると、フランス国内の小規模水力発電所の装置も同時に標的となり、同じ攻撃との関連が認められた。対象装置への影響は中程度だったとする。冷蔵設備への攻撃について、複数の証拠をもとに革命防衛隊が指示し、Shahid Kaveh部隊が実行したと評価している。同部隊は複数の活動家名義などで一部の攻撃を公に主張し、フランス・欧州・米国・イスラエルの産業設備を標的とした過去の活動も報告されている。個人名、個別の技術手順と過去事例の細部は省略。

## PDF 3頁

前頁から続く帰属の根拠として、C4はエネルギー・水関連施設を調査した際のインフラと手法、過去の活動と共通するツール、関連媒体での2026年10月13日の言及、ペルシャ語使用の痕跡を挙げる。C4はShahid Shoostari部隊を、2020年以降の対仏活動および2023年の週刊誌オンライン店舗の改ざんとデータの持ち出しにも結び付けた。脚注2は攻撃手法を、時間とともに変化しながらも一貫性を持つ技術・戦術・手順、コード、インフラの組合せと定義する。技術的手がかりの細部や個別の過去事例は要約。

## PDF 4頁

C4は、2024年パリ五輪・パラリンピックの準備に関わる映像表示企業を狙った攻撃をShahid Shoostari部隊に帰属させる。2024年7月20日以降に侵害され、攻撃者はイスラエル選手の参加を非難する画像を表示しようとしたが、表示前に侵害が見つかったとする。7月25日からの調査で事前の活動と技術的痕跡を確認。画像は7月24日にペルシャ語のアカウントで先に公開された。被害企業のネットワークでイランの通信事業者に属するIPアドレス2件が使われたとする。調査手法・個別媒体の細部は要約。

## PDF 5頁

付録。イラン革命防衛隊電子・サイバー部門とShahid Kaveh部隊の指導者を掲載。顔写真と個人名は保存・訳出対象外。
