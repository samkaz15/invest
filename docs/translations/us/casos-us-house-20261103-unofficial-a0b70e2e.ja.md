# カリフォルニア州連邦下院52選挙区の未認証開票速報

出典: https://media.sos.ca.gov/media/V26GG.txt

翻訳状態: partial

対象は2026年11月3日の総選挙、カリフォルニア州の米連邦下院52選挙区の州集計。郡コード59の各得票を、選挙区定義と候補者情報の党派コードで照合した。
速報メッセージの生成時刻は2026年11月07日 13:48:35 JST。取得は2026年11月07日 13:50:52 JST。州の案内はデータ生成時刻を定義しているが、ファイルが公開された正確な時刻は示していない。
投票区は全52区で報告済みと総数が一致。報告区分は全てF（選挙夜の準最終報告）。未処理の郵便投票、暫定票などの集計が続く。州務長官の認証は12月11日予定。
州全体の速報集計では投票数9,991,651、登録者数23,273,590、投票率42.9%、報告済み投票区23,860／23,860。
