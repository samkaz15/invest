# 米財務省、国際的な薬物密売組織を制裁対象に指定

出典: https://ofac.treasury.gov/recent-actions/20261119

翻訳状態: partial（冒頭部分のみ）

米財務省外国資産管理局（OFAC）は、豪州を拠点とするコマンチェロと、イタリアを拠点とする犯罪組織ンドランゲタの2つの国際的な薬物密売組織を制裁対象に指定した。財務省は、両組織が重要な物流・運営面の支援を通じてテロ組織に指定されたカルテルの国際展開と薬物密売網の維持を助けていると主張している。
