# UAE外務省によるアブダビ三者協議第3ラウンドの開催発表

出典: https://www.mofa.gov.ae/en/MediaHub/News/2026/11/10/10-11-2026-UAE-Russia-Ukraine-USA

翻訳状態: partial

抜粋訳。米国、ロシア連邦、ウクライナの三者協議の第3ラウンド。

本文要約。UAE外務省によると、アブダビで11月10日に協議が始まり、UAEの副首相兼外相が立ち会った。UAEは対話を通じた政治的解決に向けて米国の取り組みを支援していると説明。外相は実務的な進展を期待し、対話と緊張緩和を重視すると述べた。
