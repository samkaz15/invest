# 米財務省の長期実質金利平均、11月24日は3.19％

出典: https://home.treasury.gov/resource-center/data-chart-center/interest-rates/TextView?type=daily_treasury_real_long_term&field_tdr_date_value=2026

翻訳状態: partial

長期実質金利平均：2026年11月23日は3.17％、11月24日は3.19％。長期実質金利平均は、残存期間が10年を超える全ての既発物価連動国債（TIPS）の買い気配実質利回りの単純平均であり、長期実質金利の代用指標である。
