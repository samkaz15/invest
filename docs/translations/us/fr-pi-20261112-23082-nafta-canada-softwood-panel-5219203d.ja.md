# カナダ産針葉樹製材の二国間パネル決定の公告

出典: https://public-inspection.federalregister.gov/2026-23082.pdf

翻訳状態: partial

## PDF 1ページ

官報掲載予定は2026年11月13日。米商務省国際貿易局、NAFTA第1904条に基づく二国間パネル審査の決定公告。発表機関はNAFTA事務局米国部門。2026年11月6日、二国間パネルはカナダ産の一部針葉樹製材について、公正価格未満で販売されたとの最終肯定判断（USA-CDA-2017-1904-03）の第2次差戻し再決定に関する判断を示した。パネルは商務省の再決定を支持した。［連絡先省略］。NAFTA第19章第1904条は米国、カナダ、メキシコ政府が行った貿易救済の決定に関する紛争解決の仕組みを定める。審査申立てがあれば、争われた決定を司法審査し拘束力ある判断を下す二国間パネルが構成される。3政府が第1904条2項に基づくパネルに適用する手続規則を採択している。
