# イラン関連一般許可Wの官報再掲

出典: https://public-inspection.federalregister.gov/2026-23193.pdf

翻訳状態: partial

## PDF 1ページ

OFACは2026年5月1日発行の一般許可Wを官報に掲載する。大統領令13846で禁じられる一部取引を認めた許可で、2026年5月31日に失効した。発行時にOFACサイトで公表している。

## PDF 2ページ

同許可は、青島海業石油ターミナルまたは同社が直接・間接に50％以上保有する企業が関与する取引の縮小に通常付随し必要な取引を、例外を除き2026年5月31日午前0時1分（米東部夏時間）まで認める。遮断対象者への支払は、米国内の利息付き凍結口座に入れることが条件。別途許可がない限り、その他の同大統領令による禁止取引や他の遮断対象者が関与する取引には適用しない。
