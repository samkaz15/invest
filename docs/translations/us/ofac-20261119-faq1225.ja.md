# OFAC FAQ 1225：LIG関連の一般許可

出典: https://ofac.treasury.gov/faqs/1225

更新日: 2026-11-19（時刻不明）

取得: 2026-11-20T10:44:23+09:00

質問：一般許可128Dと131LはLIGに関連してどの活動を認めるか。

OFACはLIGとその過半数保有子会社（LIG事業体）に特有の一般許可128Dおよび131Lを発出した。両者は似ているが、目的が異なるため期限と条件が異なる。
小売消費者への指定の影響を緩和するため、OFACは2025年12月4日、ロシア国外のルクオイル小売自動車サービスステーションという狭い範囲のLIG事業体の維持、運営、終了活動を認める128Bを発出した。その後128Cと128Dで既存許可を2027年4月24日まで延長した。
ルクオイルがロシア国外資産を非封鎖者に売却できるよう、OFACは2025年12月10日、すべてのLIG事業体の維持と終了活動などを認める131Aを発出した。その後131Bから131Lまでを発出し、既存の維持・終了許可を2027年2月20日まで延長した。売却交渉の許可の詳細はFAQ1224を参照。
128Dと131Lはそれぞれに記載されたLIG事業体以外の封鎖者が関与しないことを条件に、通常の事業過程における取引を明示的に許可する。
通常の取引には、自動車燃料・潤滑油の供給、賃借料、保険料、資産保守・環境サービス、従業員の給与・福利厚生・退職金・費用償還、ITサービス、当局への支払、法律サービス・法的手続、仕入先・賃貸人・貸し手・提携先への支払、既存有形資産の保全、既存資本投資の維持に関連する活動などが含まれるが、これらに限られない。
両許可は、それぞれの条件に従い、以前から確立された慣行に整合し、既存の事業・業務を支える場合に、既存契約の履行および社内移転に通常付随し必要な取引も認める。
また両許可は、各許可の実行のため金融機関、決済処理業者等が関連LIG事業体の口座を使用し、引き落とし、入金することを認めるが、ロシア国内の者または口座への資金移転を禁じる条件を明示する。
米国人に一般的に許可される封鎖者との取引を行う非米国人は、128D・131Lで許可された取引を含め、通常、大統領令14024に基づく米制裁の対象となるリスクを負わない。同様に、非米国人は外国金融機関が封鎖口座を保持するか否かにかかわらず両許可を利用できるが、その活動がロシア国内の者または口座への支払移転禁止を含む各許可の条件に合致することが必要である。更新日2026年11月19日。
