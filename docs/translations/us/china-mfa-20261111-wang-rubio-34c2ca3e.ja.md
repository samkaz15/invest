# 中国外交部、王毅・ルビオ電話会談と首脳交流を公表

出典: https://www.fmprc.gov.cn/web/wjdt_674879/gjldrhd_674881/202611/t20261111_12057696.shtml

翻訳状態: complete

原文抜粋の訳。双方は米中関係と両国首脳の交流を巡って踏み込んだ意見交換を行い、電話会談は前向きで建設的だった。

本文の詳細要約。11月11日、中国共産党中央政治局委員の王毅外相がルビオ米国務長官と電話で会談した。王氏は習近平氏の9月の訪米が成功し、両首脳が米中関係の新たな位置づけを具体化することで一致したと説明した。関係安定は両国が各自と共通の利益に照らして選んだもので、中国は一貫した対米政策のもと、意思疎通と協力を強化し、意見の隔たりや敏感な問題に対処する考えを示した。APECとG20の開催を互いに支え、建設的な戦略的安定関係を具体化する意向も述べた。
