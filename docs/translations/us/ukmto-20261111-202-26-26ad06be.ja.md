# 英国海事当局の警報 202-26「不審な活動」

出典: https://www.ukmto.org/-/media/ukmto/products/20261111-ukmto_warning_202_26.pdf

翻訳状態: partial

英国海事当局（UKMTO）警報 202-26。区分は「不審な活動」。

発生の日付と時刻はともに確認中。通報元は軍当局。地図にはホルムズ海峡のおおよその対象海域が示されている。

英国海事当局は、ホルムズ海峡でタンカーが関係する事案の通報を受けた。本警報時点で、乗員の状況、損傷の評価、環境への影響は不明。当局による調査中、船舶には注意して通航し、不審な活動を英国海事当局に報告するよう勧告する。
