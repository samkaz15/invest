# 米・アルメニア・アゼルバイジャン、TRIPPの三者技術計画グループ設置を公表

出典: https://www.mfa.am/en/press-releases/2026/11/07/Trilateral/14257

翻訳状態: complete

本日、ブレンダン・ハンラハン米国務次官補（欧州・ユーラシア担当）、ヴァハン・コスタニャン・アルメニア外務・国際貿易副大臣、エルヌル・ママドフ・アゼルバイジャン外務副大臣は、複合輸送の通過ルート「国際平和と繁栄のためのトランプ・ルート」（TRIPP）を進めるため、三者技術計画グループを立ち上げた。この枠組みは3か国の政策担当者と技術専門家を結び、協働を通じて地域全体の長期的な安定、経済活力、連結性、商業の繁栄に寄与する。トランプ大統領が仲介した2025年8月8日の歴史的な平和首脳会合の宣言を重視する。

構想を具体的な進展につなげる共同の意思を示し、各国は最初の二つの三者計画グループを輸送と送電に焦点を当てて発足させることに合意した。各グループは複雑な技術課題を解決し、他の地域インフラとの接続を含む実施の次の段階に移るための重要な一歩となる。

各国はTRIPPの全分野を速やかに運用段階に移すというそれぞれの約束を再確認した。
