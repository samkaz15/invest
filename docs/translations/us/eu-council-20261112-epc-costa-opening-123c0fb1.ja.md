# 欧州理事会コスタ議長のダブリン会合冒頭発言

出典: https://www.consilium.europa.eu/en/press/press-releases/2026/11/12/opening-remarks-by-president-antonio-costa-at-the-meeting-of-the-european-political-community-in-dublin/

翻訳状態: partial

ミホル、きょうダブリンで欧州政治共同体（EPC）首脳会合を主催してくださり、感謝します。

最初のEPC首脳会合は、ロシアがウクライナに対し、いわれのない大規模な軍事侵略を始めてから数か月後の2022年10月に、プラハで開かれました。EPCは当初から、ロシアによるウクライナでの戦争が影を落とす中、欧州大陸全体が集まり、欧州の安全保障を議論する場でした。

これらの首脳会合は、欧州のすべての国の安全、欧州大陸の安全が、ウクライナの安全と不可分だと強調するうえで重要でした。私たちの集団的安全保障も、ウクライナに公正で持続する平和が実現することと不可分です。ウクライナの和平をめぐる協議が活発化する今日、その重要性はこれまで以上に増しています。

ウクライナに公正で持続する平和を実現し、それによって欧州の安全を回復するために守るべき原則を、明確に示す必要があります。

第一の原則は、ウクライナがここに集う他の主権国家と同じように、協力相手、同盟国、将来を自由に選べなければならないことです。欧州を勢力圏に分ける時代はとうに過ぎました。

第二の原則は、欧州の安全保障を議論する場には欧州の声が必要だということです。その声は欧州諸国、EU、NATOの協力によるものでなければなりません。EUはその役割を果たしています。

第三の原則は、欧州の安全保障の枠組みをどう議論するかです。ここで一から考え直す必要はありません。欧州には機能する安全保障の枠組みがありましたが、次第に損なわれ、最後にロシアによるウクライナ侵攻で壊されました。

今後の議論はこの事実を考慮し、1975年のヘルシンキ最終文書以来、私たちが共に築いてきた次の原則に基づかなければなりません。

- 欧州諸国の主権平等
- 武力による威嚇または武力行使の自制
- 国境の不可侵
- 国家の領土保全
- 紛争の平和的解決

これらの原則は50年前と同様に今日も重要で、公正で持続する平和に不可欠です。

EUはウクライナ、そしてウォロディミル、あなたと共に、これらの原則を守り続けます。真の平和は公正であってこそ持続し、原則に立ってこそ公正であり得るからです。

欧州の優先事項は明確です。まず停戦を実現し、黒海で具体的で目に見える進展を得て、和平合意に向けた条件を整えなければなりません。

これらすべてを可能にするうえで残る主な条件は、ロシアが真に和平を望んでいるかです。残念ながら、これまでに見てきたのは、ロシアが事態の激化とウクライナの民間人への攻撃を重ねる姿です。和平を実現するには、これが変わらなければなりません。今後数週間が、ロシアに戦争を終える意思があるかを見極める決定的な試金石になります。

最後に、欧州の安全保障の将来に向けた主要原則の宣言を適時に提案したフランスのエマニュエルに感謝します。申し上げたように、私たちは原則を再確認し、定着させ、強化する必要のある時代に生きています。欧州として、この大陸にどのような安全保障を求めるかを明確にする必要があります。

きょうEPCは、欧州全体の安全保障を議論する主要な場であることを、改めて示すでしょう。

冒頭と同じく、本日ここダブリンに私たちを集めたミホル・マーティン首相に感謝して締めくくります。

会合の成功を願っています。
