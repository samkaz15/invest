# 米財務省、イランの金融ネットワークに制裁

出典：https://content.govdelivery.com/accounts/USTREAS/bulletins/433d3be

発表時刻不明。受信：2026年11月24日03:16:07 JST。

翻訳状態：部分訳。以下はメールから選択した4段落の訳です。

今回の措置は、イランに残る対外貿易の多くを支える金融基盤を対象とし、包括的な制裁にもかかわらず政権が外貨を利用できるよう、国際金融システムを通じて数十億ドルを移動させる両替商、フロント企業、仲介者を妨げるものです。

この措置は次の大統領令に基づきます。イランの金融部門を含む特定分野を対象とする第13902号、改正後のテロ対策に関する指定権限である第13224号、イランの金属産業の各分野で活動する者を対象とする第13871号です。

さらに今回、OFACは、イランの国際貿易において不可欠な仲介役を担うイラン拠点の通貨・金取引センターを対象とします。このセンターは、海外販売で外貨を得る輸出者と、商品購入のため外貨を必要とする輸入者とを結び付け、毎年数百億ドル規模の貿易を支える金融上の仕組みを提供しています。イランの影の銀行システムが国際貿易から生じた資金を移動させる一方、センターは取引相手を引き合わせ、資金をイラン国内の最終目的地に導きます。イラン中央銀行はまた、センターが発行する債券を利用し、米ドルに依存せずロシア・ルーブルや中国人民元を用いた国際貿易を支援しています。

同センターは、イラン経済の金融部門で活動しているとして、大統領令第13902号に基づき指定されます。
