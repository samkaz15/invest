# 米特使クシュナー氏、モスクワで協議する提案の事前調整を公表

出典: https://x.com/jaredkushner/status/2120535519171850378

翻訳状態: partial

本日、私たちは人道面で重要な前進を果たしました。ウクライナとロシアは、この戦争で最大規模となる捕虜交換に原則合意しました。これにより家族が再会し、信頼が醸成され、和平に向けた機運が生まれます。

ウクライナとロシアが2月以来初めて三者協議の場に再び集まったことは、重要な一歩でした。協議は真剣かつ詳細で、率直なものでした。両国は、隔たりを縮めて戦争を終わらせる道を見つけるため、具体的な考えを示しました。

ウクライナと欧州のパートナーと緊密に調整し、明日モスクワでプーチン大統領と協議する提案について認識をそろえました。その後、ゼレンスキー大統領と協議します。

トランプ大統領はこの悲惨な戦争を終わらせる決意です。大きな隔たりは残っていますが、これまでの進展を踏まえ、永続的な平和と、主権を持ち、安全で繁栄するウクライナを実現できる、より幅広い多国間交渉へ進む決意です。
