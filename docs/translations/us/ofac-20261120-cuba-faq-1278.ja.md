# キューバの海運分野に関するFAQ 1278

一次資料：https://ofac.treasury.gov/faqs/1278  
米国公表日：2026年11月20日、公表時刻不明  
取得：2026年11月22日06:40 JST

質問：許可された貿易に関してキューバの港で支払うなど、キューバの海運分野との関係を伴う許可済みの活動を行っています。大統領令14404に基づきキューバ経済の海運分野を指定した2026年11月5日の決定後も、この活動を継続できますか。

回答：はい。キューバ制裁規則またはキューバ資産管理規則に基づき許可された活動を行う米国人は、マリエル港を含むキューバの港への支払いや港との取引を含め、当該活動を続けることができます。
一般に米国政府は、それぞれキューバ制裁規則やキューバ資産管理規則により米国人または米国の管轄に服する者に許可された取引を行うことを理由として、米国人以外を制裁対象にはしません。FAQ 1264と整合的に、米国政府は、米国人以外の者が食料を含む農産物、医薬品、医療機器、医療機器の交換部品・構成部品および医療機器のソフトウェア更新をキューバに提供することに関する取引を行う場合、マリエル港との取引を含む海運分野での事業を理由に、大統領令14404に基づく制裁対象とする意図はありません。
