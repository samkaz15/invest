# OFAC FAQ 1224：LIG関連の一般許可

出典: https://ofac.treasury.gov/faqs/1224

更新日: 2026-11-19（時刻不明）

取得: 2026-11-20T10:44:23+09:00

質問：一般許可131Lはどの交渉を認め、LIG資産の売却実行について追加許可を審査する際にOFACはどの条件を考慮するか。

2025年10月22日、OFACはロシアのエネルギー部門への圧力を高め、戦争遂行のための資金調達能力を損なうため、ルクオイルを指定した。制裁の影響を踏まえ、同社がロシア国外資産を非封鎖者へ売却しようとする可能性をOFACは認識している。
そうした売却を支援し、ロシアへの資金をさらに断つため、OFACは一般許可131Lを発出した。これはLIGまたはLIGが過半数を保有する子会社の売却についてルクオイルとの交渉および条件付き契約の締結を認める。最終契約の条件交渉、財務・法務・業務上のデューデリジェンス、外部弁護士や顧問の起用を含む。この交渉・条件付き契約の許可は2026年12月19日に終了する。
131LはLIGの事業体または資産の実際の売却、処分、移転を実行する取引を許可しない。締結契約には別途OFAC許可取得を条件とすることを明記しなければならない。米国の対ロシア制裁は、戦争終結に向けモスクワに圧力をかけることを目的とする、とOFACは述べている。
財務省は米国の国家安全保障および外交政策上の目的を支える要素に基づいてLIG売却案を評価する。OFACは少なくとも、LIGとルクオイルの関係を完全に断つこと、ルクオイルに支払う資金を米国の管轄下にある口座に置き制裁解除まで封鎖すること、資産や株式の交換を含めルクオイルに前払い価値などの棚ぼた利益を与えないことを求める見通しとする。
さらに将来売却を実行する許可の条件として、LIG資産の買い手が重要資産を再売却する前にOFACの審査を求めることを義務付ける見通しである。ルクオイルとLIGが資産売却について誠実に交渉していないとみられる場合を含め、OFACは131Lをいつでも取り消し得る。更新日2026年11月19日。
