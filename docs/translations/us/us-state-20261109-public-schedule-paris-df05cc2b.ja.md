# 米国務長官の11月9日パリ公開日程

### 2026年11月9日の公開日程

国務省報道官室、2026年11月8日付。公開日程は変更される場合がある。

**マルコ・ルビオ国務長官**　11月8日から10日までフランスを訪問する。以下の時刻はパリ現地時刻。

- 11:30　G7外相会合の集合写真および世界食糧計画との集合写真に参加。代表取材。
- 12:00　危機と国際的課題に関するG7外相会合の昼食会に参加。冒頭のみ代表撮影。
- 13:40　ドイツのヨハン・ヴァーデフール外相と会談。冒頭のみ代表撮影。
- 14:15　フランスのジャンノエル・バロ外相と会談。冒頭のみ代表撮影。
- 15:15　招待パートナーとのG7集合写真に参加。代表取材。
- 15:30　超知能を議題とするG7外相会合の会合に参加。冒頭のみ代表撮影。
- 18:45　フランスのエマニュエル・マクロン大統領と会談。取材非公開。

**クリストファー・ランドー国務副長官**　国務省内の会合と説明会に出席する。

**アリソン・M・フッカー政治担当国務次官**　11月8日から10日までのフランス訪問にルビオ長官と同行する。

**ディラン・ジョンソン国際広報担当国務次官補**　同じフランス訪問にルビオ長官と同行する。

国務省の報道向け定例説明は予定していない。
