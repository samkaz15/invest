# フランス外務省のパリG7外相会合の議題

出典: https://www.diplomatie.gouv.fr/en/presse-et-ressources/decouvrir-et-informer/actualites/quelles-priorites-pour-la-reunion-des-ministres-des-affaires-etrangeres-du-g7-a-paris

翻訳状態: complete

G7外相は2026年11月9、10日にパリで会合を開く。フランスのG7議長国の下で開く2回目の正式な2日間の会合で、外相は危機解決を中心とする主要な国際政治の課題について立場を調整し、2026年3月のヴォー・ド・セルネ外相会合以降の進展を点検する。

### パリ会合の優先事項

1. 危機の解決と現代の主要課題への対応。外相は紛争や国際危機の現場を議論する。主な議題はウクライナの能力、資金、エネルギー面の支援、中東の安定化とエネルギー供給の多様化・安定確保、スーダン、アフリカの角、ベネズエラ、キューバ、ハイチ、法の支配に基づく自由で開かれたインド太平洋の重要性。参加国間の認識を近づけ、危機への協調対応につなげる。
2. 麻薬取引対策のため海事・港湾の安全を強化する。エビアン首脳会議で発表したG7プラス港湾ネットワークは、パリ外相会合と同時期にマルセイユで初会合を開く。麻薬取引対策に向け、G7とパートナー国の港湾の安全確保に関する実務をメンバー間で共有する。
3. 人道支援の有効性を高める。世界食糧計画のルーク・J・リンドバーグ事務局長の出席の下、人道支援の供給網の効率化と合理化、食料安全保障、栄養改善を引き続き進める。
4. 人工知能（AI）の安全性を高める。2026年6月のエビアン首脳会議と同年9月の国連安全保障理事会で始まったG7の調整を踏まえ、AIの安全を議論する。AIには機会と新たなリスクがある。最先端モデルの進展が世界の戦略環境を大きく変え、社会の強靱性と安全を損なうおそれがある中、G7は安全な開発・導入を確保しつつ革新を維持できるよう協調して対応する必要がある。

### 2026年のフランスG7議長国としての取組

フランスは、一年を通じて「均衡、収れん、成果」を掲げ、主要課題に具体的な事業で取り組み、G7外の国との協力も強めてきた。

- 人道支援の効果を高めるため、緊急時に迅速に対応できるよう、世界の人道支援備蓄の分布を把握する作業を始めた。
- ウクライナの復興を進めるため、G7のパートナーは、2025年のロシアによる攻撃で深刻な損傷を受けたチェルノブイリの新安全閉じ込め施設の復旧に向け、国際的な資金調達を支援すると約束した。フランスは欧州復興開発銀行とウクライナ当局とともに11月9日にパリで資金拠出国会合を開く予定。
- 分野横断的な脅威に対応するため、テロ資金をより効果的に特定、追跡、抑制する目的で、2026年5月にパリで「No Money For Terror」会議を開催した。
- 麻薬取引対策を強化するため、2026年7月にマルティニークでカリブ地域安全保障会議を開催した。

フランスは、これらすべての課題で具体的な成果を出し、G7諸国、ひいてはフランスとその国民の安全と繁栄を高める方針。パリ会合にはブラジル、エジプト、韓国、サウジアラビア、ウクライナを招待した。これらの国は年初からフランス議長国の議論と成果文書などに積極的に関わってきた。
