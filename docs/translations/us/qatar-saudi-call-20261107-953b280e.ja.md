# カタールとサウジの外相が電話協議し、カタールが航行の自由に向けた外交努力を支持

出典: https://mofa.gov.qa/en/qatar/latest-articles/latest-news/details/2026/11/07/prime-minister-and-minister-of-foreign-affairs--saudi-foreign-minister-hold-phone-call

翻訳状態: partial

カタール首相兼外相とサウジ外相は電話で、二国間協力の深化・拡大と地域情勢について話し合った。両者は緊張緩和および地域の安全・安定に向けた外交努力と連携を協議した。カタール首相は、海上航行の自由を確保し、持続的な平和につながる包括合意を目指す外交努力を支持すると述べた。
