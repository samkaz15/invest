# イラン革命防衛隊海軍、ホルムズ海峡でタンカー2隻の爆発を発表

出典: https://sepahnews.ir/fa/news/41513/%D8%A7%D9%86%D9%81%D8%AC%D8%A7%D8%B1-%D8%AF%D9%88-%D9%86%D9%81%D8%AA%DA%A9%D8%B4-%D8%B3%D8%B1%DA%A9%D8%B4-%D9%88-%D9%85%D8%AC%D8%B1%D9%85-%D8%AF%D8%B1-%D8%AA%D9%86%DA%AF%D9%87-%D9%87%D8%B1%D9%85%D8%B2

翻訳状態: complete

昨夜、タンカー2隻は、革命防衛隊海軍のホルムズ海峡通航管理センターから、南側の航路を許可しておらず安全でないとの警告を繰り返し受けた。それでも同海軍が無許可とする航路を通過中に事故に遭い、激しい爆発で停止した。

両船は超大型タンカーで、合わせて400万バレルを超える原油を積んでいた。今も燃えており、略奪と侵略を行う米軍を信頼した結果だ。

ペルシャ湾やホルムズ海峡で航法装置を切り、密輸を行う米軍に協力して南側の無許可航路を通る船舶は、同じ結末を迎えることになる。
