# キューバの指定分野に関するFAQ 1277

一次資料：https://ofac.treasury.gov/faqs/1277  
米国公表日：2026年11月20日、公表時刻不明  
取得：2026年11月22日06:40 JST

質問：大統領令14404に基づく2026年11月5日のキューバ経済の製造、技術、電子、海運分野についての決定は、これらの分野で事業を行っている、または過去に行った全ての者がOFACの制裁を受けることを意味しますか。

回答：いいえ。2026年11月5日、OFAC局長は国務省との協議の上、大統領令14404に基づき、キューバ経済の製造、技術、電子、海運分野で事業を行っている、または過去に行ったと認定された外国人に経済制裁を課すことを認める決定を出しました。
大統領令14404に基づく分野の決定により、その分野で事業を行う、または行った者には制裁リスクが生じますが、その分野で事業を行う、または行った全ての者に自動的に制裁が課されるわけではありません。上記分野で事業を行う、または行ったと同大統領令に基づいて認定された者のみが、同令に基づく制裁の対象です。このため、キューバ一般許可1を含む個別許可・一般許可などの適用除外や許可がなければ、その分野で事業を行う、または行った米国人以外の者は制裁リスクに直面する可能性があります。
キューバ資産管理規則に基づく適用除外や別途の許可がない限り、米国人は、当該キューバ国民が指定分野で事業を行っているか過去に行ったかにかかわらず、全てのキューバ国民との取引を引き続き禁じられます。
