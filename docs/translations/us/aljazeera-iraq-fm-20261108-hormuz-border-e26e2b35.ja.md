# イラク外相、オマーン沿岸航路で原油輸出を再開したと説明

出典: https://www.aljazeera.net/video/the-interview/2026/11/8/%D9%88%D8%B2%D9%8A%D8%B1-%D8%AE%D8%A7%D8%B1%D8%AC%D9%8A%D8%A9-%D8%A7%D9%84%D8%B9%D8%B1%D8%A7%D9%82-%D9%84%D9%84%D8%AC%D8%B2%D9%8A%D8%B1%D8%A9-%D8%AA%D9%81%D8%A7%D9%87%D9%85%D8%A7%D8%AA-%D9%85%D8%B9

報道本文の要約

アルジャジーラのインタビュー記事でフアード・フセイン・イラク外相は、米国とイランとの了解を受け、オマーン沿岸の航路を通る原油輸出を再開したと説明した。了解の文書、対象船や積出港、適用開始日、米国側の確認は取得できていない。

外相の説明では、戦闘開始後の最初の4か月にホルムズ海峡の通航が妨げられ、船会社や保険会社がバスラ港への寄港を懸念し、イラクの損失は約600億ドルに達した。輸出は平時の日量330万〜340万バレルから一時ゼロに落ち込み、タンク車やトルコ向けパイプラインによる部分的な輸送を経て、オマーン沿いの海上航路で再開したという。トルコ向けは段階的に日量26万バレルに達したとし、ヨルダン・シリア経由のパイプラインについては交渉を始めた段階と説明した。

別途、ロイターはイラクのエネルギー当局者を根拠に9月の日量265万バレルから10月に約350万バレルへ回復したと報じた。この月次数字はイラク外相の発言の訳ではなく、今回の航路で実際に積み出した数量の裏付けにも使わない。

追加確認した対イラン国境通過点の記述。イラク外相は、米財務省がイランとの国境通過点を二つだけ残して閉鎖するよう正式に求めたと説明したという。放送局の記事によれば、残す通過点の一つはクルディスタン地域、もう一つはイラクの他地域とされた。イラク側は通過点が多く、閉鎖すると経済に影響が出るとして、米側と協議中だと説明した。放送局記事が伝えた外相の説明では、対イラン取引は年150億〜180億ドル、うち天然ガスの購入は約40億ドル。米側の要請文書、実際の閉鎖命令、適用開始は未確認。
