# 特定の指定先の関連会社に対する輸出管理拡大の停止期間延長

出典: https://www.govinfo.gov/content/pkg/FR-2026-11-09/pdf/2026-22793.pdf

翻訳状態: partial

## PDF 1頁

米商務省産業安全保障局（BIS）。対象は15 CFR第732、734、736、744、748部。案件番号261027-0002、RIN 0694-AK34。

**特定の指定先の関連会社にエンドユーザー規制を拡大する措置の停止期間延長**

種別は最終規則、停止。BISは「特定の指定先の関連会社を対象に含めるエンドユーザー規制の拡大」という暫定最終規則の停止を延長する。従来の停止は2026年11月9日に終了予定だった。この最終規則は停止を2027年1月10日まで延長する。

日付。2026年11月9日発効。2025年9月30日付90 FR 47201の暫定最終規則に含まれ、90 FR 50857により2025年11月10日から停止されていた15 CFR各部の改正は、2027年1月10日まで引き続き停止する。

問い合わせ先欄は省略。

補足情報、背景。BISは2025年9月20日［原文表記。日付欄は9月30日］、「特定の指定先の関連会社を対象に含めるエンドユーザー規制の拡大」（90 FR 47201、関連会社規則）を暫定最終規則として公表した。BISは同年11月12日、「特定の指定先の関連会社にエンドユーザー規制を拡大する措置の1年間停止」と題する最終規則を公表した。

## PDF 2頁

（続き）同規則（90 FR 50857）は関連会社規則を1年間停止し、当初は2026年11月9日に停止が終わる予定だった。BISは停止を2027年1月10日まで延長する。

### 2018年輸出管理改革法

大統領は2018年8月13日、2018年輸出管理改革法（ECRA、50 U.S.C. 4801–4852）を含む2019会計年度ジョン・S・マケイン国防権限法に署名した。ECRAはBISの主要な権限と本規則の根拠を定める。1753条（50 U.S.C. 4812）は米国管轄下の品目の輸出・再輸出・国内移転の規制を認める。1754条(a)(1)～(16)（50 U.S.C. 4813）は、とりわけ、1752条(2)(A)の方針に従い国家安全保障・外交政策に脅威となる外国の者や最終用途のリストを作成・維持し、該当先への規制品目の輸出・再輸出・国内移転を制限し、政策・規則・手続の変更を公示し、法律で禁止されない範囲でECRA施行に必要なその他の措置をとる権限を認める。1762条(a)（50 U.S.C. 4821）に基づき、事前告示や意見募集を経ずに最終規則で変更できる。

### 規則制定の要件

1. 本規則は大統領令12866上の重要規則に当たらず、そのため大統領令14192上の規制措置にも当たらない。
2. 1995年書類負担削減法（44 U.S.C. 3501以降）の対象となる情報収集について、有効な行政管理予算局（OMB）管理番号が表示されない限り、回答や不履行への制裁を受ける義務はない。本規則に関係する承認済み収集は次のとおり。
   - 0694-0088。簡易ネットワーク申請手続と多目的申請書。手動・電子提出1件につき推計29.7分。
   - 0694-0096。5年間の記録保持。推計1分未満。
   - 0607-0152。自動輸出システム（AES）。電子提出1件につき推計3分。
   - 0694-0134。エンティティー・リストまたは未確認リスト掲載先が削除・変更を申請する手続。電子提出1件につき推計15時間。
   許可要件と関連規定の停止が続くため、BISは情報収集の変更を見込まない。関連資料はReginfo.govで件名またはOMB管理番号を検索して参照できる。
3. 大統領令13132が定義する連邦制への影響を伴う政策を含まない。
4. ECRA1762条により、行政手続法（5 U.S.C. 553）上の規則案告示、一般参加の機会、発効日の延期の要件が免除される。本規則は関連会社規則に寄せられた意見を考慮していない。これらは将来の規則制定で検討する。
5. 5 U.S.C. 553などが規則案の告示や意見募集を要求しないため、規制柔軟性法（5 U.S.C. 601以降）の分析要件は適用されず、最終分析は作成されていない。

産業安全保障担当商務次官。官報文書2026-22793、11月5日16:15提出、請求コード3510–33–P。署名者名は省略。
