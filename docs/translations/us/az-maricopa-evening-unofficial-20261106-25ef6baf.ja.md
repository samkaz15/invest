# マリコパ郡の一般選挙速報（11月6日夕方）

出典: https://elections.maricopa.gov/news-and-information/elections-news/additional-unofficial-results-11-6-2026-2.html

翻訳状態: partial

郡選挙当局は11月6日夕方、11月3日一般選挙の未認証速報を更新した。集計済みは154万6,594票で、投票資格のある登録有権者258万9,827人の59.72％。更新分は4万609票。郡は票の99％を報告したとしている。残る票は集計前に有権者または選挙職員の対応が必要。署名不備の補正、または条件付き暫定票の本人確認の期限は現地11月8日17時（日本時間11月9日9時）。

未集計票の内訳はその時点の推計で、処理に伴い各区分の数が増減する。

| 区分 | 郡の推計 | 内容 |
|---|---:|---|
| 合計 | 21,500 | 下記3区分の合計 |
| 署名補正・集計前処理中の期日前票 | 10,750 | 投票日19時までに受領し、有権者の対応が必要なもの、または署名確認後に集計前処理中のもの |
| 暫定票 | 2,500 | 通常と条件付きの2種類。多くは有権者の追加対応を必要とせず、職員が資格を確認できれば集計する |
| 集計待ち | 8,250 | 破損票の複製、記名候補票など追加作業が必要なものを含む。集計待ちの票はライブ配信カメラのある保管庫に置く |

郡当局の所管には、候補者の届出、対面投票と投票会場の運営、選挙職員の採用と開票が含まれる。郡内の市町、学校区、特別区の選挙も対象。
