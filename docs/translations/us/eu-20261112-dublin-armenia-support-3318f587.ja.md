# ダブリンのアルメニア支援国声明

出典: https://www.consilium.europa.eu/en/press/press-releases/2026/11/12/statement-after-the-leaders-meeting-of-the-core-group-of-support-to-armenia/

翻訳状態: partial

欧州政治共同体のダブリン首脳会合に合わせ、エストニア、フランス、リトアニア、英国の首脳・代表とEU外務安全保障政策上級代表がアルメニアのパシニャン首相と会談した。ドイツ、ノルウェー、ポーランド、欧州理事会議長、欧州委員会委員長が加わり、以下の声明を発出した。

アルメニア共和国の主権、領土保全、安定、独立、強靱性に対する支持を改めて表明する。

5カ月前、アルメニアで議会選挙が行われた。ロシアから多方面の干渉を受けながらも、アルメニアの人々が平和、民主主義、欧州との関係強化を明確に選ぶ機会となった。

それ以来、ロシアによるアルメニアへの直接的な政治・経済上の圧力は増す一方だ。ロシアはアルメニアの輸出に前例のない制約を課し、今はエネルギー供給を威圧の手段に使うと脅している。

これに対応し、アルメニアが主権を守り、自らの将来を自由に選べるよう行動している。アルメニアの対EU輸出の80％について関税を停止するEUの決定を踏まえ、特に貿易とエネルギーで経済関係の多角化を引き続き支援する。

アルメニアの人々が欧州との関係を志向していることを認識する。活力と強靱性を備えた民主主義と豊かな経済を築き、域内の連結網と国際貿易に十分に参加できるよう、引き続き支援する。

アルメニアとアゼルバイジャンの和平プロセス、2025年8月のワシントン会合以来の大きな進展、アルメニアとトルコの関係正常化も支持する。両国の人々とより広い地域の利益のため、この方向で一層の努力を促す。
