# 米中関係全国委員会のガラでのスコット・ベッセント米財務長官の講演準備原稿

出典: https://home.treasury.gov/news/press-releases/sb0688/

翻訳状態: complete

講演用の準備原稿

エバン［グリーンバーグ］、ご紹介とお招きに感謝します。この機会に皆さまとご一緒でき、大変うれしく思います。

今晩私たちは、世界最大の二つの経済大国の代表という以上に、今世紀で最も重要な関係の一つを託された者として集まりました。

この委員会が発足した1966年、太平洋は米国と中国を隔てる距離のうち、最も目に見えやすいものにすぎませんでした。正式な国交の樹立は、まだ10年以上先のことでした。両国の政府はめったに言葉を交わさず、国民同士もめったに会うことがありませんでした。

しかし、「小規模で、緩やかにつながった」中国研究者たちは、隔たりがあるからこそ、もっと知る必要があると考えました。そこで、中国への理解を深め、より真剣に向き合う取り組みを始めました。この関係が具体的にどこへ向かうかは予想できませんでしたが、重要なものになることはわかっていました。

この委員会の創設者たちは、「一般の人から専門家、政策担当者まで」、社会のあらゆる層に働きかけ、その間に「長く続くつながりを築く」という意欲的な課題を自らに課しました。

それから60年がたった今晩、この会場を一目見渡せば、その志がどれほど実現したかがわかります。

米国と中国は異なる体制を持ち、国益もしばしば食い違います。それでも、皆さまが築いたつながりは、今や世代と文化を結びつけています。そのつながりは公務に携わる人々や一般市民、新しい発想を世に出す研究者や、それを実践に移す起業家にも及んでいます。

米中関係全国委員会が人々を引き合わせたことで、太平洋の両岸で相互理解が深まりました。

そこで、話を先に進める前に、この取り組みの最も優れた面を体現するお二人をたたえたいと思います。

スティーブ・オーリンズ氏は、職業人生の大半を米中関係にささげてきました。1970年代に国交を樹立したチームの一員であり、その後数十年にわたり、国交を支える結びつきを強めてきました。スティーブ、あなたが残す功績は大きな意味を持ちます。心からの感謝とお祝いを申し上げます。

もうお一方の受賞者をご紹介できることもうれしく思います。スティーブ・オーリンズ氏が対中関与の歴史を形作ったとすれば、スティーブン・シュワルツマン氏はその未来を大きく変える投資をしてきました。シュワルツマン・スカラーズを創設し、この委員会を動かしてきた信念を受け継いでいます。国家間の関係は、人と人との関係の上に成り立ちます。スティーブ、あなたが米中関係を、そして互いをより深く理解する機会を提供したことで、新しい世代の指導者たちは、この関係に向き合うための備えをさらに充実させられます。おめでとうございます。

この委員会は数十年にわたり二国間関係を支えてきましたが、実際には両国のつながりは数世紀に及びます。中国との関係は、米国という共和国とほぼ同じ長さの歴史を持っています。

1784年の冬、米国にまだ大統領がおらず、憲法さえなかった頃、米国船「エンプレス・オブ・チャイナ号」はニューヨーク港を出て、珠江へと船首を向けました。

船には米国の乗組員と貨物が載っていました。そこにはまた、独立を勝ち取り、早くも世界の主要な貿易国の一員になろうとしていた若い国の自信がありました。

後に初代駐中国米国領事となったサミュエル・ショー少佐は、船が到着した際、中国の人々が「自分たちの産物にこれほど大きな市場が開ける見込みを、大いに喜んだ」と回顧しています。かつて大きな距離で隔てられていた二国が、交易の可能性によって引き寄せられたのです。

ですから、ワシントンと北京が大使を置く前から、私たちには商人がいました。

使節が相手国との付き合い方を学ぶ前に、国民はすでに商売のやり方を見いだしていました。

外交がこの関係に形を与える前に、物資の流れがこの関係に力を与えていました。

ショーは双方向の交易を歓迎しました。そして、その交易がどのような条件で行われるべきかを明言しました。「あらゆる場合に対等であること」。当時から米国人は、公平な条件を求めていたのです。

エンプレス・オブ・チャイナ号の初航海から、ほぼ二世紀半が過ぎました。

広州へ向かった米国船一隻に始まり、朝鮮人参を陶磁器、茶、絹と交換することから始まった交易は、世界最大の二つの経済大国を結ぶ広大な貿易網に発展しました。

サミュエル・ショーが生きた世界は、とうの昔に歴史のものとなりました。しかし、彼を海の向こうへ駆り立てた気質は、今も息づいています。

当時と同じく、米国人は今も、機会があるところならどこへでも求めて行き、競争するところではどこでも公平さを求めます。

貿易は、いずれの主権も損なうことなく、双方の利益を前進させるものでなければなりません。

まさにその精神に基づいて、トランプ大統領は中国との関係に向き合ってきました。

今日の米中関係を形作っているのは、両国の指導者同士の関係です。

初当選以来、トランプ大統領は本人の言葉を借りれば、「相互尊重と両国民の極めて重要な利益を土台に、［習近平国家主席との］友好関係を築いてきた」のです。

その友好関係によって、両国の指導者の間にかつてない直接対話が生まれました。私はその対話を実務レベルにも広げようとしています。

5月にはトランプ大統領が北京を訪問しました。9月には習主席がワシントンを訪れました。そして来週、私はトランプ大統領に同行して深圳を訪れます。両首脳はそこで会談し、その後マイアミで4回目の会談を行う予定です。

会談の頻度は歴史的です。両国の指導者が1年のうちにこれほど頻繁に対面で話し合ったことはありません。さらに重要なのは、その会談が両国の間に築きつつある理解です。

トランプ大統領と習主席は、均衡と相互主義を土台に、米中が建設的な関係を築くべきだという点で一致しています。その目的のために、両首脳は二つの新たな機関を設けました。

貿易委員会では、双方それぞれ300億ドル相当の機微性の低い品目について、より有利な関税上の扱いを見いだすことで一致しました。同委員会は、農業分野の貿易障壁に対処する作業部会も立ち上げました。これに先立ち、中国は今後2年間に、米国から大豆を少なくとも2,500万メートルトン、石炭を1,000万メートルトン輸入することに合意しました。

一方、投資委員会は、米国企業の市場アクセスや中国企業にとっての予見可能性の向上など、事業上重要な問題を議論するための正式な場を提供します。

これらの取り組みは、中国との公平で相互的な関係を進めるための、より広い活動の一環です。トランプ大統領の政策の核心にある原則を具体化するものでもあります。その原則とは、米国の対外関与の成否を、国内でどのような成果をもたらすかで測るというものです。国民の繁栄をどれほど促進し、経済の強靱性を高め、国の安全を守るかで測るのです。

米国の対中貿易の不均衡は、長く摩擦の原因となってきました。中国の慣行を容認してきた政界に対し、トランプ大統領はそれらに対処するため断固とした措置を講じました。

今晩、はっきりと申し上げます。より均衡の取れた関係に向けて取り組む中で、私たちの目標はリスクを減らすことであり、両国の経済を切り離すことではありません。

数十年の間に、米国経済は海外からの供給に依存しすぎるようになり、中国経済は海外の需要に一段と依存するようになりました。言い換えれば、米国は自ら消費するものをもっと生産し、中国は自ら生産するものをもっと消費する必要があります。協力すれば、両国間の不均衡を長引かせずに、双方の経済を強化できます。

レイ・ダリオ氏なら、「大きく、すばらしいリバランスを実現すべきだ」と言うでしょう。

トランプ大統領が米国民を米国の政策の中心に据え直すにあたり、改めて経済力を重視することは、貿易相手との関係への敵意を表すものではないと明言します。私たちは、それぞれの関係に価値を与える目的を取り戻しています。数十年の不均衡を経て、両国民の利益のために、相互主義の精神を回復しています。

前世紀の大きな課題に協力して取り組むと同時に、次の世紀の課題に答える決意も固めなければなりません。

ヘンリー・キッシンジャーは晩年の数か月、自らが見届けることのできない世界の課題を考え続けていました。100歳になっても、彼らしく、目は未来を見据えていました。最後の訪問では、北京で習主席と会い、協力を深めることについて協議しました。

キッシンジャーは、超知能の出現が、これまでにない種類の戦略上の危険をもたらし得ると考えるに至りました。そして大国には、深い相違を抱える国同士であっても、おそらくそういう国同士だからこそ、共通の目的を見いだす責務があると認識していました。

そこでトランプ大統領の指示により、超知能（SI）をめぐる新たな対話を中国との間に設け、この重要な取り組みを始めました。共通のリスクに備え、両国の間の誤解を防ぐことが目的です。先端モデルを公開前に評価・試験するための優れた実務や、この技術の運用を人間の判断がしっかりと統御するための方法についても、知見の交換を見込んでいます。さらに、どちらの国でも自国の超知能モデルに関わる重大な事故が起きた際、相手国へ速やかに知らせられるよう、直接連絡経路を設けつつあります。

超知能の進歩に伴い、新たな分野でリスク管理に取り組み、両国が競争上の要請と指導的立場に伴う責任をどう両立できるかを示す必要性も高まります。その際、米中間の相違について幻想を抱くべきではありません。先ほど述べた通り、両国の利益が常に一致するわけではありません。同様に、個々の課題への対処法も常に一致するわけではありません。

1960年代の初期の中国研究者たちは、両国の違いがあまりに大きく、無視できないことを理解していました。同時に、両国が疎遠になることも、到底受け入れられないと知っていました。

エンプレス・オブ・チャイナ号に乗った進取の気性に富む商人たちがニューヨーク港に戻った時代から、代々の指導者がこの関係の価値を信じていることを示してきました。

そこで今晩の結びには、14か月の航海を終えたサミュエル・ショーの言葉を借りたいと思います。「こうして幸いにも、私たちと地球の東の果てとの間に、往来の道が開かれた」と、彼はその到来を告げました。

1784年の愛国者たちは交易を通じてその道を開きました。1970年代の政治家たちは外交を通じてその道を広げました。そして60年にわたり、この委員会の皆さまは、両国の人々を引き合わせる地道な取り組みを通じて、その道を維持してきました。

トランプ大統領の下で、米国はこの取り組みを新たな時代へと引き継ぎます。太平洋の両岸で繁栄の可能性を広げていきます。そして自らの力に自信を持ち、米国民に対する揺るぎない責任を果たしながら、この関係をさらに強める決意を新たにすることで、最初に築いた人々に敬意を表します。

ありがとうございました。そして、おめでとうございます。
