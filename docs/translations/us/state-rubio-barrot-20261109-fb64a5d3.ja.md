# ルビオ米国務長官とバロ仏外相の会談概要（公開転載）

出典: https://www.defconlevel.com/alert/2026-11-09-secretary-rubio-s-meeting-with-french-foreign-minister-barrot

翻訳状態: partial

広報官室。会談概要。2026年11月9日。

マルコ・ルビオ米国務長官は本日、フランスのジャンノエル・バロ外相と会談した。両者は国際刑事裁判所に関する米国の根本的な懸念について協議した。

両者は中東情勢にも触れ、ホルムズ海峡の航行の自由の重要性を再確認した。ルビオ長官はまた、EUによる優遇措置と、米企業を対象とする過剰な規制をやめるよう求めた。

最後に、ロシアとウクライナの戦争の長期的かつ持続的な和平に向けた取り組みについて協議した。
