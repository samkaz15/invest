# 米内務省、北極圏外縁大陸棚の試掘規則案の意見募集を再開

出典: https://public-inspection.federalregister.gov/2026-23145.pdf

翻訳状態: partial

## 1ページ（対象箇所）

米内務省の海洋鉱物局（MMA）、安全環境執行局（BSEE）、海洋エネルギー管理局（BOEM）。北極圏の外縁大陸棚における石油・ガス・硫黄事業の試掘要件を見直す規則案。2026年8月6日付91 FR 50998で公表した規則案への意見募集を再開する。提出期限は官報掲載から30日後と記載。規則番号はRIN 1082-AA05、案件BSEE-2026-0133。

## 2ページ（対象箇所）

連邦の規則策定ポータルには提出手順、関連資料と平易な規則案の要約がある。行政管理予算局のオンライン窓口は情報収集に関する当該募集を終了しているが、連邦ポータルで引き続き意見を出せる。30 CFR Part 250に関する番号は1014-0036、Part 550は1010-0151。郵送・持参も可能。提出した個人情報を含め意見全体が公開され得る旨の注意がある。

## 3ページ（対象箇所）

8月6日に開始した60日間の募集は10月5日に終了した。延長要請を受け、追加の検討・意見提出のため30日間再開する。期限後の意見は十分に考慮されない場合がある。内務長官命令3451によりMMAがBOEMとBSEEを引き継ぐ。移行期間中の権限に基づき、MMAがこの通知を発出した。
