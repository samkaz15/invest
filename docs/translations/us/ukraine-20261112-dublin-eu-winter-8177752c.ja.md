# ウクライナ大統領とEU首脳の冬季支援協議

出典: https://www.president.gov.ua/en/news/volodimir-zelenskij-obgovoriv-iz-prezidentami-yevroradi-ta-y-107297

翻訳状態: partial

ウクライナ大統領府によると、ゼレンスキー氏はダブリンで欧州理事会議長と欧州委員長にアブダビでの協議を報告し、欧州が対ロ協議に全面的に加わる必要を述べた。冬季に向けた追加支援を協議し、エネルギー・人道支援と避難施設への援助を見込むと発表した。EU加盟交渉の残る2分野を開くことと今後の手順についても調整した。支援の引き渡しや効果は未確認。
