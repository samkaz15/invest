# 米エネルギー省EDF エルクホーン事業の概要と統計表

出典: https://www.energy.gov/edf/elkhorn

翻訳状態: complete

### 事業の目的

アリーナ・エナジーのエルクホーン事業は、ルイジアナ州ユージーン島付近の海洋プラットフォームを修繕・改修し、再稼働させる。米国で待遇の良い雇用を数千人分支え、原油・天然ガスの生産能力を高める。

### 事業概要

EDFは2026年11月、同湾でのエネルギーインフラ再投資事業であるエルクホーンを支援するため、アリーナ・エナジーへの4億8,000万ドルの融資契約を締結した。事業は米国民に豊富で信頼できるエネルギーを供給するインフラを支援することで、トランプ大統領の大統領令「米国のエネルギーを解き放つ」の目標達成を後押しする。

### エネルギーへの影響

融資により、アリーナはルイジアナ州沖にある22基の海洋プラットフォームの設備更新、改修、動力設備の更新、能力拡大を進められる。これにより使用期間を延長し、重要なインフラを改良する。この改良によってプラットフォームの耐用年数が延び、事業期間中に米国の石油・天然ガス生産を約1億2,500万バレル増やす見込みだ。操業・環境安全の最高水準を保ちつつ、米国民が手頃で信頼でき、安全なエネルギーを利用できるようにする。

### 経済への影響

エルクホーン事業は、操業400人、建設2,400人の計2,800人の雇用を支える。米国の主要な海洋エネルギー生産地帯の一つで、地域の雇用機会を拡大する。また、この事業による原油・天然ガスの増産で、連邦政府のロイヤルティ収入は推計16億ドル増える。EDFは米国の納税者にとって3倍を超える還元に当たると説明する。
