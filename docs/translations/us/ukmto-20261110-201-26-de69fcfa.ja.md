# 英国海事当局の警報 201-26「攻撃」

出典: https://www.ukmto.org/-/media/ukmto/products/20261110-ukmto_warning_201_26.pdf

翻訳状態: partial

英国海事当局（UKMTO）警報 201-26。区分は「攻撃」。

発生日時欄は11月10日13:38 UTC（同日22:38 JST）、通報元は船長。地図はオマーンのリマ北東沖の概略位置を示す。

英国海事当局は、オマーンのリマから北東19海里で発生した事案の通報を受けた。タンカーの船長は、正体不明の飛翔体が命中したと報告した。乗員は無事で、環境への影響は報告されていない。船長は夜明けに損傷を調べる予定。当局による調査中、船舶には注意して通航し、不審な活動を英国海事当局に報告するよう勧告する。
