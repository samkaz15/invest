# 子ども向け投資口座への家族・友人の拠出が10億ドルを突破

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/433f774

翻訳状態: メール本文は全文訳。公開配信ページは取得不可。

友人・家族による個別のトランプ・アカウントへの拠出額が10億ドルを突破

ワシントン発――トランプ・アカウントは本日、友人や家族による個別口座への拠出額が10億ドルを超えたと発表した。これは、すべての米国の子どもにより強固な経済的将来を与える取り組みにおける歴史的な節目としている。

この10億ドルの達成は、マイケル・アンド・スーザン・デル財団などによる大規模な慈善寄付とは別に、300万人を超える友人・家族の拠出によって実現した。友人・家族、慈善家による拠出の約束と、米財務省による1,000ドルの初期拠出を合わせ、トランプ・アカウントに預け入れられた資産の総額は90億ドルを超えたとしている。

内国歳入庁のフランク・J・ビシニャーノ最高経営責任者は「トランプ・アカウントは米国の子どもたちのための画期的な政府プログラムであり、米国史上最大の政府による新規事業です。この取り組みに加え、個別口座の保有者の友人や家族から並外れた反応があり、その拠出額は全国で10億ドルを超えました」と述べた。「保護者には今すぐアプリをダウンロードして子どもの口座を請求し、その経済的将来の成長を見守ってほしい」と呼びかけた。

スコット・ベッセント財務長官は「米国民は、国民性の最も優れた本能を示す寛大さでトランプ・アカウントに投資しています。トランプ大統領は口座への拠出を特に簡単にしたいと考え、全国の友人や家族が次世代の資産形成を初日から支援する機会を活用しています。今週、大統領自身も個別口座に私的な寄付を行った何百万人もの米国民に加わりました。拠出のたびに、あらゆる家庭や背景を持つ米国の子どもたちが長期的な経済的安全を得るという約束の実現に近づいています」と述べた。

口座が請求された後、友人や家族は子どものアプリ内のQRコード機能を使って直接拠出できる。

トランプ・アカウントは、Working Families Tax Cutsの下で設けられた、18歳未満の米国の子ども向けの税制優遇投資口座である。財務省は、有効な社会保障番号を持つ適格な子ども一人ひとりに口座を開設し、何百万人もの子どもの経済的将来に向けた慈善拠出の道を設けたとしている。

2025年1月1日から2028年12月31日の間に生まれた子どもは、財務省から一度限りの1,000ドルの初期拠出を受ける資格もある。

保護者または後見人が口座を請求しなければ、口座の管理や家族・友人・雇用主による拠出はできない。

請求には、Apple App StoreまたはGoogle Playで提供される公式アプリをダウンロードする。手続き中に保護者等は本人確認と子どもとの関係の確認を行い、子どもの情報を確認し、口座規約に同意する。

請求後、友人・家族は年間最大5,000ドルを拠出でき、雇用主は年間最大2,500ドルを拠出できる。雇用主による拠出も年間5,000ドルの上限に服する。
