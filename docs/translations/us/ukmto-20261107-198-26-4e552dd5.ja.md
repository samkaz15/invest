# 英海事当局の注意情報198-26、UAE沖でばら積み船と軍が関係する事案

出典: https://www.ukmto.org/-/media/ukmto/products/20261107-ukmto_advisory-198-26.pdf

翻訳状態: partial

英海事当局（UKMTO）は、アラブ首長国連邦ホールファッカーンの東方約18海里のオマーン湾で、ばら積み貨物船と軍部隊が関係する事案の報告を受けた。報告時点で乗員の状況、損傷の評価、環境への影響は不明だった。当局は事案を把握しており、調査が続いている。船舶には、最新の海上安全情報を確認し、変化する航行環境を把握するよう勧告する。

報告日11月7日、発生時刻は確認中。情報源欄は「軍当局」。地図はUAEのホールファッカーンと沖合の対象海域を表示。出典 UK Maritime Trade Operations。
