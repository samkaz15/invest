# G7外相会合 セッション2「AI」

出典: https://www.mofa.go.jp/fp/pc/pageite_000001_00020.html

翻訳状態: complete

現地時間11月9日午後3時30分（日本時間9日午後11時30分）から約60分間、フランス・パリを訪問中の茂木敏充外務大臣は、G7外相会合の「AI」に関するセッションに参加しました（G7各国外相及びEU上級代表並びに招待国であるブラジル、韓国、サウジアラビア及びエジプトの各外相が参加）。

本セッションにおいて、G7各国外相は、招待国と共に、AIをめぐる諸課題への対応について議論を行いました。

茂木大臣からは、今後、安全保障面を含め、AIを有効に活用していくためには、AIへの意味のある人間の関与をいかに確保するか、また、サイバー犯罪も含めAIが悪用される場合、各国、さらに国際的に協調して、いかに対処するかが最も重要な課題であるとして、G7を含む同志国間で共通の認識を構築するための議論を続けたい旨述べました。その上で、まさに2023年のG7広島サミットで打ち出した「広島AIプロセス」はこうした常に進化するAIの課題に的確に対処するための枠組みであり、日本としてその活用を各国に促していきたい旨述べました。また、AIの活用が進む中で、世界のデータ流通の約99％を担う海底ケーブルの重要性が増していることを指摘しました。

各国外相は、AIがもたらす可能性と潜在的なリスクを認識しつつ、フロンティアAIの安全で信頼できる開発を確保する必要性に言及するとともに、国際的な協力や情報共有を通じ、海底ケーブルの安全性・強靭性を強化していく必要性を強調しました。
