# OPEC石油市場月報11月版付表の需給・在庫要約

出典: https://www.opec.org/assets/assetdb/momr-appendix-november-2026.xlsx

翻訳状態: partial

OPECの11月月報付表11-1の年平均では、世界の石油需要は2026年に日量1億572万バレル、2027年に1億828万バレルの見通し。公表精度ではいずれも10月版と同じ。丸め前の年平均値から計算した前年比の増加幅は2026年が約18万バレル／日、2027年が約255万バレル／日。付表11-2では、2026年7〜9月期の需要を日量約30万バレル下方修正し、10〜12月期を同約30万バレル上方修正した。付表11-3では、9月末のOECD陸上商業石油在庫は約28億1,110万バレル。

資料はOPECの著作物。ここでは対象の統計値を独自に要約し、表全体と原本を転載していない。
