# 背景資料：10月28日FOMC実施要領

出典: https://www.federalreserve.gov/newsevents/pressreleases/monetary20261028a1.htm

翻訳状態: complete

2026年10月28日公表：金融政策実施に関する決定

FRBは、10月28日のFOMC声明で発表した政策姿勢を実施するため、次の決定を行った。

・理事会は全会一致で、準備預金への付利金利を3.90%に維持し、2026年10月29日から適用することを決定した。
・FOMCは別途指示するまで、NY連銀の公開市場デスクに対し、以下の国内政策指令に従ってSOMA取引を行うよう議決した。

「2026年10月29日から、デスクに次を指示する。
・フェデラルファンド金利を3.75～4.00%の目標レンジに維持するため、必要な公開市場操作を実施する。
・常設翌日物レポ・オペを4.0%で実施する。
・常設翌日物リバースレポ・オペを提示金利3.75%、取引先ごとの1日上限1,600億ドルで実施する。
・潤沢な準備預金水準を維持するため、適切な場合には短期国債、必要なら残存3年以下の他の国債を購入し、SOMAの証券保有を増やす。
・FRB保有国債の元本返済を全て入札で借り換える。FRB保有の政府機関証券の元本返済を全て短期国債へ再投資する。」

・関連措置として、理事会は全会一致でプライマリー・クレジット金利を現行の4.0%に維持することを承認した。

この情報は、FOMCまたは理事会による運営手段・政策実施方法の詳細決定を反映し、必要に応じ更新される。公開市場操作・再投資の詳しい情報はNY連銀のウェブサイトに掲載される。
