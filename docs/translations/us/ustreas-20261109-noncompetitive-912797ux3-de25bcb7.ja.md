# 米財務省の26週物短期国債の非競争入札暫定結果

翻訳状態: partial

米財務省財政局の短期国債非競争入札結果。2026年11月9日発表。連絡先は省略。

26週物（182日）の短期国債、CUSIP 912797UX3。募集額面 82,000,000,000ドル。発行日 2026-11-12、当初発行日 2026-05-14、満期 2027-05-13。

| 募集額内の区分 | 認定額面（ドル） |
|---|---:|
| プライマリーディーラー | 0 |
| 直接入札者 | 1,100,000 |
| 間接入札者 | 794,267,500 |
| FIMAの非競争分 | 615,000,000 |
| 財務省個人向け | 690,495,000 |
| 暫定小計 | 2,100,862,500 |

募集額外のSOMA（公開市場勘定）は5,487,459,400ドルで、募集額外の暫定小計も同額。競争入札に残る概算額面は79,899,137,500ドル。

脚注1　正式な入札結果が公表されると、運用上の理由により最終の非競争結果がわずかに異なる場合がある。
