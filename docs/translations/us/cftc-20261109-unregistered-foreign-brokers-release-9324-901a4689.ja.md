# CFTCの外国紹介業者に関する登録違反の和解命令8件

出典: https://www.cftc.gov/PressRoom/PressReleases/9324-26

翻訳状態: partial

米商品先物取引委員会（CFTC）は、未登録の外国紹介業者の未登録の関係者として活動した8人への申立てと和解命令8件を公表した。個人名は省略。

命令によると、紹介業者は適格契約参加者に該当しない米国顧客を対象に、取引所外のレバレッジまたは証拠金を伴う個人向け外国為替取引と商品取引の注文を勧誘した。対象者は、必要な紹介業者の関係者としての登録をせずに顧客を勧誘した。

各命令は違反行為の停止を求め、2年間、CFTCへの登録またはCFTC登録業者の責任者、代理人もしくは従業員となることを禁止する。各命令は関連する米証券取引委員会（SEC）の手続で対象者が負う制裁金も認めている。

これらの命令は、米国顧客との違法な取引所外商品取引を仲介したとしてNetrios LP Ltd.およびRed Acre Ltd.に制裁を科した従前のCFTC命令に関連する（CFTC発表9263-26参照）。SECも同一の行為に基づく申立てと和解を行った。CFTCはSECの協力に謝意を表明した。
