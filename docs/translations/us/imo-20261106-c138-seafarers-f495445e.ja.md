# IMO理事会が船員保護を要請し、中東の商船被害を報告

出典: https://www.imo.org/en/mediacentre/pressbriefings/pages/imo-council-c138-urges-stronger-protection-of-seafarers-amid-threats-to-global-shipping-.aspx

翻訳状態: partial

原文抜粋の訳。IMOは同地域で商船に対する攻撃を少なくとも130件確認した。

中東関連の詳細要約。IMO理事会は11月2～6日のロンドン会合で、重要航路の開放と安全を維持し、船員の国籍・所在や地政学的紛争への関与の有無を問わず保護する方針を再確認した。事務局長は紛争で船員の死亡、重傷、置き去り、帰国の妨げ、水・食料・医療の不足が続くと説明した。発表は11月5日のVELOS SAPPHIREへの攻撃による船員1人の死亡を挙げ、死者25人、商船への確認済み攻撃130件以上とした。ペルシャ湾から出られない船舶を含め、数千人の船員が危険にさらされていると述べた。理事会は船員や国際海運の安全を脅かす違法な措置を避けるよう加盟国に求め、事務局長は追加の具体策を検討するとした。

その他の航路。理事会は紅海・バブエルマンデブ海峡でのフーシ派の商船攻撃と、黒海でのロシアによる商船・港湾・捜索救助等への攻撃を非難した。西インド洋とアデン湾で年初来17件の海賊行為・武装強盗の実行または未遂を指摘し、ジブチ行動規範とジッダ改正の取組に言及した。事務局長に状況監視と加盟国への継続報告を求めた。
