# NY連銀の10月消費者期待調査

出典: https://www.newyorkfed.org/newsevents/news/research/2026/20261109

翻訳状態: partial

本稿はNY連銀の2026年11月9日付公表本文の日本語訳です。翻訳は調査側によるものです。

ニューヨーク連銀のミクロ経済データセンターは、2026年10月の消費者期待調査を公表した。家計の短期・中期・長期のインフレ期待は横ばいだった。労働市場では、失業率の上昇や失職への懸念が強まる一方、再就職への期待は改善した。失業率上昇を見込む度合いは2020年4月以来、再就職への期待は2025年11月以来の高水準となった。所得・支出の伸びの期待はおおむね安定したが、延滞の見通しは悪化した。調査期間は2026年10月1～31日。

### インフレ

- 1年・3年・5年先のインフレ期待の中央値は、それぞれ3.9％、3.3％、3.0％で横ばい。回答者間のばらつき（第75百分位と第25百分位の差）は1年・5年先で縮小し、3年先では横ばい。
- 将来のインフレに対する不確実性の中央値は、1年・3年先で低下し、5年先で横ばい。
- 住宅価格上昇期待の中央値は3.0％で横ばい。過去12カ月平均の3.1％をわずかに下回る。
- 1年先の価格変化予想の中央値は、ガソリンが0.6ポイント低下して4.2％、食料は5.5％で横ばい。医療費は0.1ポイント上昇の9.3％、大学教育費は0.1ポイント上昇の7.6％、家賃は0.9ポイント上昇の7.7％。

### 労働市場

- 1年先の勤労所得の伸びの中央値は2.6％で横ばい。過去12カ月平均は2.7％。
- 1年後に米国の失業率が現在より高くなると回答者が考える確率の平均は、1.4ポイント上昇して45.3％となり、2020年4月以来の高水準。上昇は大学学位を持たない層が主導。
- 今後12カ月に失職すると考える確率の平均は0.4ポイント上昇の13.9％で、過去12カ月平均の14.3％を下回る。自発的に離職すると考える確率の平均は0.5ポイント低下の19.4％で、同平均の18.4％を上回る。
- 現職を失った場合に仕事が見つかると考える確率の平均は0.4ポイント上昇して46.5％。2025年11月以来の高水準。

### 家計金融

- 家計所得の伸びの中央値は0.1ポイント低下の3.0％。2025年6月以降は2.8～3.1％の範囲。
- 1年先の家計支出の伸びの中央値は0.2ポイント低下の5.3％。過去12カ月平均の5.0％を上回る。
- 1年前と比べた信用へのアクセスの認識と、今後の信用供与の見通しはおおむね横ばい。
- 今後3カ月に最低返済額を支払えないと考える確率の平均は1.6ポイント上昇の13.8％で、2025年12月以来の高水準。
- 現在の所得水準を前提とした1年先の税額の変化予想の中央値は0.1ポイント上昇の3.8％で、2025年12月以来の高水準。
- 1年先の政府債務の伸びの中央値は0.2ポイント低下の9.7％。過去12カ月平均の9.3％を上回る。
- 12カ月後の平均預金金利が現在より高いと考える確率の平均は1.3ポイント上昇の31.6％で、2023年4月以来の高水準。
- 家計の現在の財政状態に対する認識はやや改善し、1年前より良いと答えた割合のネット値が上昇。1年先の見通しはおおむね横ばい。
- 12カ月後の米株価が現在より高いと考える確率の平均は0.2ポイント低下の40.0％。

### 調査方法

この調査は、全体のインフレや食料・ガソリン・住宅・教育の価格、雇用・所得、支出・信用へのアクセスに関する家計の見通しと不確実性を把握する。年齢、地域、所得、教育、数的能力ごとの結果も利用できる。全米を代表する約1,300世帯の世帯主を対象としたオンラインの交代制パネルで、各回答者は最長12カ月参加し、毎月ほぼ同数が入れ替わる。毎回異なる対象を抽出する横断調査と比べ、同じ回答者の期待や行動の変化を追える。調査方法、よくある質問、図表ガイド、質問票は原文リンクを参照。
