# 中国の米国関連船舶への特別港務費と海運・造船関連調査の停止延長

出典: https://xxgk.mot.gov.cn/jigou/syj/202611/t20261109_4227425.html

翻訳状態: complete

米国関連船舶への特別港務費の徴収と、海運・造船および関連産業・供給網の安全と発展上の利益への影響に関する調査の停止継続についての交通運輸部公告
交通運輸部公告2026年第90号

第8回米中経済・貿易協議の成果を実施するため、国務院の承認を得て、次の3文書の実施停止を2027年1月10日まで継続する。

- 「米国関連船舶への特別港務費の徴収に関する交通運輸部公告」（交通運輸部公告2025年第54号）
- 「『米国関連船舶への特別港務費徴収実施弁法』の公布に関する交通運輸部弁公庁通知」（交弁水〔2025〕59号）
- 「海運・造船および関連産業・供給網の安全と発展上の利益への影響に関する調査の開始についての交通運輸部公告」（交通運輸部公告2025年第55号）

以上、公告する。
交通運輸部
2026年11月9日

配布先　外交部、工業・情報化部、国家安全部、財政部、商務部、各省・自治区・直轄市の交通運輸庁・委員会、各直属海事局。
