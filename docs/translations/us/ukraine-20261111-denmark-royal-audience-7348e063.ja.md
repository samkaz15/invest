# ウクライナ大統領がデンマークのフレデリック10世と面会

出典: https://www.president.gov.ua/news/prezident-ukrayini-mav-audiyenciyu-v-korolya-daniyi-frederik-107249

翻訳状態: partial

ウクライナ大統領府によると、ゼレンスキー大統領はデンマークのフレデリック10世と面会した。クリスチャン皇太子とフレデリクセン首相も同席した。大統領はデンマーク政府による毎年の財政支援に謝意を示した。ロシアによるエネルギーなどの重要インフラへの攻撃が激しくなっていると説明し、両国の安全保障協力と防衛力を強める長期的な連携に意欲を示した。負傷兵と退役軍人への支援・リハビリについても話し合い、デンマークの既存支援の継続に期待を示した。
