# 米通商代表部のベトナム知的財産301条調査の延長

米通商代表部（USTR）　案件番号 USTR-2026-0364

ベトナムの知的財産保護・執行に関する行為、政策及び慣行についての通商法301条調査を延長する決定の告示

機関　米通商代表部。文書の種類　告示。

概要　米通商代表は、ベトナム政府による知的財産の保護と執行に関する一部の行為、政策及び慣行について、進行中の301条調査を3カ月延長することを決定した。

問い合わせ先　連絡先の段落は保存対象外。

日付　本告示は2026年11月3日（火）午前0時01分（米東部夏時間）から効力を有する。

補足情報　通商代表は2026年5月29日、改正1974年通商法302条(b)(2)に基づき、知的財産の保護と執行に関するベトナム政府の一部の行為、政策及び慣行を対象に301条調査を開始した。2026年6月3日付91 FR 33285を参照。同条に基づいて開始し、通商協定に関係しない調査では、304条(a)(3)(A)は、措置の対象となるか、また措置を取る場合に何を取るかを開始から6カ月以内に判断するよう定める。304条(a)(3)(B)は、通商代表が、調査が追加の時間を要する複雑な問題を含む、対象国が適切かつ実効的な知的財産権の保護を実現する立法・行政措置の起草または

## PDF 2頁

実施で相当の進展を遂げている、または対象国が知的財産権を適切かつ実効的に保護するための執行措置を講じていると判断する場合、開始から9カ月以内に措置の対象となるか、また措置を取る場合に何を取るかを判断するよう定める。この規定に基づき、通商代表は、調査が追加の時間を要する複雑な問題を含むと判断した。したがって、調査の判断は遅くとも2027年2月28日までに行われる。

署名　米通商代表部法務顧問（氏名は省略）。
