# NY連銀、11月10日・12日の政府機関MBS小口取引の運用テストを公表

出典: https://www.newyorkfed.org/markets/opolicy/operating_policy_261103

翻訳状態: complete

日本語訳（当調査による翻訳）

ニューヨーク連邦準備銀行の公開市場取引デスクは、連邦公開市場委員会（FOMC）の現行および将来あり得る政策指示を実行するための態勢を確認する目的で、小口取引を実施する。FOMCは、公開市場操作の権限および継続指示において、この運用態勢の検証を行うようデスクに権限を与え、指示している。

これらの指示に基づき、デスクは2026年11月10日に政府機関MBSの小口ドルロール取引を4件、11月12日に政府機関MBSの小口クーポンスワップ取引を4件実施する予定。

11月10日にはドルロールを売る。未決済の11月TBAポジションを売却し、12月TBAポジションを購入する予定。対象は15年物UMBSのクーポン5.5%。各ドルロール取引の額面は500万ドルで、4件の現時点の額面合計は2,000万ドル。

11月12日には、30年物ジニーメイのクーポン6.0%の未決済11月TBAポジションを、調達しやすい他のMBSに交換する予定。各クーポンスワップ取引の額面は500万ドルで、4件の現時点の額面合計は2,000万ドル。
