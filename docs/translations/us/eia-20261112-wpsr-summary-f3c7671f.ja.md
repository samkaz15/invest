# 米EIA週間石油統計（11月6日終了週）の概要

出典: https://ir.eia.gov/wpsr/summary.txt

翻訳状態: complete

2026年11月6日までの週に、米国の製油所は日量1,700万バレルの原油を処理した。前週比32万2,000バレル増で、稼働率は95.2％だった。ガソリン生産は日量平均960万バレルで、留出油生産は日量510万バレルに減った。

原油輸入は日量32万5,000バレル増えて670万バレルとなった。4週平均は日量630万バレルで、前年同期を14.0％上回った。ガソリン輸入は日量平均20万2,000バレル、留出油輸入は同9万9,000バレルだった。

戦略石油備蓄を除く商業原油在庫は470万バレル増の4億1,440万バレルで、過去5年平均を4％下回った。ガソリン在庫は180万バレル増え、過去5年平均を1％上回った。留出油在庫は410万バレル増え、過去5年平均を8％下回った。プロパン・プロピレン在庫は10万バレル増え、過去5年平均を12％上回った。商業石油在庫全体はこの週に1,140万バレル増えた。

過去4週の石油製品供給量は日量平均2,080万バレルで前年同期比0.9％増。ガソリンは同1.0％減の日量870万バレル、留出油は同4.2％増の日量390万バレル、ジェット燃料は同1.8％増だった。
