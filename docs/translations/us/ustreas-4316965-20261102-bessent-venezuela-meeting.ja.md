# 米財務長官とベネズエラ外相が会談：エネルギー生産拡大と金融部門の再接続を協議

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/4316965

翻訳状態: unverified

会談概要：スコット・ベッセント米財務長官とベネズエラのオリバー・ブランコ外相との会談

ワシントン — 本日、ベッセント長官はベネズエラのオリバー・ブランコ外相と会談し、外相就任への祝意を伝えた。また、ベネズエラ情勢と、トランプ政権の「安定化・復興・移行」という3段階のアプローチを前進させる機会について協議した。

ベッセント長官は、信頼の回復、投資の呼び込み、より豊かなベネズエラの基盤づくりを目指し、同国の経済復興と主要部門の再活性化を支援するトランプ政権の姿勢を強調した。これには、エネルギー生産の拡大と、ベネズエラの金融部門の再接続が含まれる。
