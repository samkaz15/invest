# 米エネルギー省、エルクホーン海洋油ガス事業への4億8,000万ドル融資契約を締結

出典: https://www.energy.gov/articles/energy-department-closes-480-million-loan-expand-american-energy-production-and-strengthen

翻訳状態: complete

米国エネルギー省（DOE）のエネルギー優位性金融局（EDF）は本日、メキシコ湾（米政府呼称「アメリカ湾」）の大陸棚で原油・天然ガスの生産を増やすアリーナ・エナジーのエルクホーン事業について、4億8,000万ドルの融資契約を締結したと発表した。この事業ではルイジアナ州沖の海洋プラットフォーム22基を近代化する。生産のピーク時には、米国の生産を原油で日量最大3万8,600バレル、天然ガスで日量最大7,700万立方フィート押し上げる見込みだ。

今回の発表はトランプ大統領の「勤労世帯減税」によって可能になった。国内の原油・天然ガス生産を支援する融資契約の締結は、同省にとって初めてとなる。同省は、米国のエネルギー分野での優位性を高め、米国の家庭と企業に手頃で信頼でき、安全なエネルギーを供給する方針を示している。

クリス・ライト米エネルギー長官は、「米国は原油と天然ガスの世界最大の生産・輸出国であり、トランプ大統領の下で、米国のエネルギー生産は今後も伸びる。エルクホーン事業は原油生産を日量最大3万8,600バレル増やし、数千人の雇用を生み出す。エネルギー省は、エルクホーンのような事業への資金供給を通じて国内生産を拡大し、エネルギー安全保障を強化し、今後数十年にわたる米国の繁栄を支える」と述べた。

アリーナ・エナジーは現在、同湾の海域で日量約3万バレルの原油を生産している。エルクホーン事業では既存の海洋インフラを近代化して生産能力を拡大し、事業期間全体で米国の生産に原油約1億2,500万バレルと天然ガス約2,500億立方フィートを追加する。米国の主要な海洋エネルギー生産地帯の一つで、建設関連2,400人、操業400人の雇用を創出する。

EDFのグレゴリー・A・ビアード局長は、「トランプ大統領とライト長官の指導の下で、EDFは既存のエネルギーインフラを再稼働させ、米国民に役立てている。エルクホーン事業は国内の原油・天然ガス生産を拡大し、米国で待遇の良い雇用を生み、エネルギー安全保障を強化するとともに、米国の納税者に大きな還元をもたらす」と述べた。

トランプ大統領の下で、EDFは、国内生産を拡大し、米国のエネルギー安全保障を強化し、すべての米国民の負担を抑える国内のエネルギーインフラ事業に資金を供給している。その際、納税者の資金を責任を持って管理する。
