# G7外相会合（セッション4：ウクライナ支援）

出典: https://www.mofa.go.jp/mofaj/fp/pc/pageit_000001_00031.html

翻訳状態: complete

現地時間11月10日午後0時25分（日本時間同日午後8時25分）から約60分間、フランス・パリを訪問中の茂木敏充外務大臣は、G7外相会合の「ウクライナ支援」に関するセッション（ワーキング・ランチ形式）に参加しました（G7各国外相及びEU上級代表並びにウクライナ外相が参加）。
本セッションにおいて、G7各国外相は、シビハ・ウクライナ外相と共に、ウクライナ情勢及びこれをめぐる対応について議論を行いました。
茂木大臣は、ロシアによる攻撃の悪影響の拡大への懸念を共有しつつ、日本が一貫してウクライナ支援及び対露制裁に取り組んでいることを説明しました。また、露朝軍事協力等の動向は、欧州・大西洋とインド太平洋双方の安全保障が不可分であることを示しており、それぞれの地域の課題にG7一体で協調して取り組むべき旨を強調しました。
G7各国外相は、エネルギー安全保障や越冬支援を含め、ウクライナ支援に引き続き取り組んでいくことを確認しました。
