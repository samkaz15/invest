# 米国関税とカナダ・メキシコの対米輸出、総額の違いの背後にある共通点

出典: https://www.federalreserve.gov/econres/notes/feds-notes/a-common-pattern-behind-diverging-fortunes-u-s-tariffs-and-exports-from-canada-and-mexico-20261109.html

翻訳状態: partial

「両国の推計値の差は統計的に有意ではない。」

米国の2025年3月の関税を起点に、米国・メキシコ・カナダ協定（USMCA）の適用や金属・自動車への品目別税率で生じた関税のばらつきを利用。2024年の固定輸入構成を基に実効関税率を計算した。図1の実効税率はカナダ5.39％、メキシコ7.99％。国・業種と国・月の固定効果を使い、輸出総額に対する関税の効果とは区別する。

| 表1の仕様 | カナダ | メキシコ | プール |
|---|---:|---:|---:|
| 月次ベースライン | −4.9 | −11.8 | −7.4 |
| 米業種別鉱工業生産を調整 | −5.9 | −10.6 | −7.5 |
| 関連商品価格を調整 | −5.7 | −11.6 | — |
| 2023年から | −5.4 | −12.3 | — |
| 2024年から | −4.7 | −11.5 | — |
| 2024年11月〜2025年2月を除外 | −5.2 | −12.1 | −7.6 |
| 金属を除外 | 2.5 | −11.6 | −7.9 |
| 第三国からの米輸入を調整 | −5.5 | −5.1 | −6.0 |
| 米向け対その他仕向地 | −6.8 | −11.2 | −8.4 |

推計値は2025年3月以降、露出が10ポイント高い業種の相対的な対米輸出の変化率（％）。カナダは金属を除くと有意な関係が見えず、メキシコは広い業種に及んだ。メキシコの対米輸出の増加は機械に集中。機械を除くと約2％減。部品を輸入し組み立てたサーバーなどは、輸出総額の伸びをそのまま国内付加価値にはできない。仕向地比較でカナダの推計は不精確。推計は関税と同時に起きた業種別需要や第三国への切替と完全には分離できない。
