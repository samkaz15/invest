# TBAC報告：国債増発の必要性と金利・資金需要の背景

出典: https://home.treasury.gov/news/press-releases/sb0679/

翻訳状態: complete

財務省借入諮問委員会から財務長官への報告
2026年11月4日公表

長官殿

8月上旬の前回TBAC会合以降、国債市場は、力強い経済活動とそれに伴う資金需要、継続するエネルギー供給障害、FRBの最初の利上げと追加利上げ見通しを反映し、より高い金利経路を織り込んだ。債券売りは短期側が主導し、2年利回りは約50bp、10年は約40bp上昇した。9月から10月上旬に加速し、10年利回りは10月上旬に約5.4%、30年は約5.7%でピークを付けた。その後、一部は低下した。

この再評価のかなりの部分は、エネルギー価格高と金利上昇にもかかわらず、夏を通じて米国経済が強かったことを反映する。金融資産増と貯蓄率低下が実質所得への圧迫を和らげ、家計消費は底堅かった。既存の固定金利住宅ローンは保有者の返済負担増を抑えたが、新規借入金利上昇は住宅活動を圧迫した。コンピューター設備、知的財産、データセンターへの強い投資が、金利に敏感な他の投資の弱さを相殺した。このインフラ整備は従来の住宅主導の拡大ほど資金調達費用に敏感ではなかった。建設・設備製造への波及が見え始めたが、雇用全体の増勢加速にはまだ至っていない。

この底堅さによってFRBは、エネルギーショックで悪化した持続的インフレリスクに対応する余地を得た。夏に始まった供給障害は当初予想より長引き、四半期を通じ原油・石油製品価格を高止まりさせ、輸送・運賃へ波及した。9月の総合CPIは3.7%へ加速し、前月比上昇の半分超をガソリンだけで占めた。燃料・運賃が他品目へ転嫁され、コアCPIは2.6%だった。

FRBは9月に25bp利上げし、目標レンジを3.75～4.00%とした。Warsh議長は景気の強さとインフレ改善の不足を強調し、すでに制約的な金融環境を大幅に厳しくするのではなく、緩和を取り除く決定と位置付けた。9月の経済見通しでは2026・2027年末政策金利の中央値がともに4.1%へ上昇し、6月の3.8%、3.6%から引き上げられた。10月に据え置かれても、市場は今後1年で約3回の追加利上げを織り込んだ。最近は借入費用増と株式・信用市場の弱さが利上げ速度の予想を抑えたが、追加利上げ予想そのものは消えていない。

四半期中には次の市場横断的・技術的要因も生じた。

・今年のタームプレミアムの上昇は利回り上昇ほど大きくないが、初秋には10年タームプレミアムに圧力が見られた。NY連銀ACMモデルの10年推計値は9月に約20bp上昇した。金利のインプライド・ボラティリティは急上昇し、織り込まれた不確実性と追加利回り上昇へのオプション保険費用が増えた。金利上昇で借換えの誘因が弱まると住宅ローンのデュレーションが延び、コンベクシティ・ヘッジ主体はデュレーションを減らした。クーポン上限のあるCMO変動利付証券も、先渡し予想クーポンが上限へ近づいたことでヘッジ圧力を加え、中期金利のボラティリティ需要を増やした可能性がある。これらのフローは当初の売りと変動増を増幅したとみられるが、金利上昇につれて住宅ローンの追加的な期間延長余地は小さくなった。

・米国外でも強い経済活動が金利上昇予想を促した。主要先進国の引締めが織り込まれる中、ECBと日銀も当該期間に利上げした。欧州国債市場も米国債に影響した。フランスの財政・政治不安で同国国債スプレッドが急拡大し、世界の債券変動を強めた。ただし連動は一様でなく、仏米の利回り変化の相関は10月に弱まり、その後のフランスの緊張増大は米国債・ドイツ国債への安全資産需要を支えた。

・テクノロジー関連資金調達も資本市場と金融環境に影響した。大型起債と計画される巨大IPOは大きな民間資金需要を示した。大量の起債と将来の資金需要の不確実性は同セクターのスプレッドを拡大し、長期資本の獲得競争を強めた。銀行・運用会社はGPU担保融資、設備リース、データセンターのプロジェクト融資で調達源を広げた。米テクノロジーへの海外資金需要はドル高に寄与し、借入費用増に加えて金融引締めの経路となった。大型起債時の国債の価格調整やヘッジへの限界的な影響はあり得るが、入札需要が持続的に悪化した証拠はない。個別結果は異なるものの、最近の入札は概ね底堅かった。

・期後半にはテクノロジー関連ニュースがリスク心理を悪化させ、国債需要の回復を助けた。負債で賄う技術投資の収益への精査が強まる中、10月下旬のナスダック100は10月上旬高値から7%強下落した。株安と信用スプレッド拡大が国債への安全資産需要を回復させ、先の利回り上昇を一部巻き戻した。

こうした背景で委員会は四半期借換えを議論した。見通しでは資金不足が2027会計年度中に拡大し、2028・2029年度にさらに広がる。財務省は現金管理方針に沿い、2027会計年度第1・第2四半期末の現金残高前提を、それぞれ約8,500億ドル、約1兆ドルと公表した。

第1の諮問事項は超知能（SI）関連発行だった。委員はSIと関連事業の社債動向を議論し、大きなテクノロジー資金調達サイクルの途上にあると指摘した。長期社債以外にも調達が広がり、担保付き・資産担保証券の仕組みにより10年未満の発行が増えている。技術産業全体には借入・投資を持続する能力と動機の両方があるように見える。

米債券への海外需要は今年加速し、投資家層全体には追加発行を吸収する相当の余力がある。保険会社、年金、家計、海外投資家が多様な需要を供給し、家計と民間年金の債券配分は依然相対的に少ない。現金・株式からの小幅な配分変更でも、予想借入のかなりの部分を吸収し得る。

2026年の技術関連発行が長期国債需要を締め出した証拠は入札結果に見られない。委員会は、技術投資が金利に影響するなら、締め出しよりも成長強化を通じると見た。国債利回り上昇は、発行増による供給ショックより、主に成長、政策予想、エネルギー価格を反映するとされた。ただし、この調達サイクルは初期段階であり、SI関連発行拡大による国債需要への影響を財務省が監視し続けるよう勧告した。

第2の諮問事項は国債デリバティブの役割拡大だった。2022年の金利上昇以降、資産運用会社は先物で合成的な国債エクスポージャーを得ることを増やし、年金・保険など負債対応型投資家は金利スワップでデュレーションを管理してきた。委員会は、デリバティブによる期間リスク保有が市場参加の幅と仲介能力を広げ、国債需要を高めると強調した。

現物国債需要をさらに改善し得る政策選択肢として、国債のレバレッジ比率算入除外や割引窓口に事前差入れした担保の流動性指標上の認識など、バランスシート能力への規制制約緩和、レポ調達へのアクセス拡大、ターム物レポの利用改善、レポ仲介への新規参入促進を挙げた。レポ金利のファンド会計処理、税務処理、運営上の問題も検討するよう勧告した。これらは現物保有者を広げ多様化し、仲介を強め、持続的な国債需要を支え得る。

委員会は流動性支援買い戻しの有効性も議論した。2024年の導入以来、流動性を支えてきたことを示す多様な証拠があり、買い戻しはその目的に有効な手段である。ただし、財務省債務の満期構成の管理は入札規模変更で行うべきだと考えている。

政府の長期的調達費用最小化のため、利払いの期待費用・変動を均衡させ、市場需要に発行を合わせ、市場機能を円滑にし、規則的・予測可能な発行を続ける戦略を支持する。基準的な財政見通しでは現行規模のままだと短期国債など短期調達の比率が高まる。市場は最近の国債供給を十分吸収し、金利上昇の大半は需要不足ではなく景気の強さと金融政策見通しを反映すると委員会は考える。個人や一部機関の実需投資家は、金利上昇や景気悪化へのヘッジを背景に需要を増やした。一方、MMF資産は横ばいとなり、短期国債市場に価格への敏感さが現れ始めたとも指摘した。

当四半期は名目利付債・FRN・TIPS入札規模の据置きを勧告した。ただし、現在の財政予測では2027会計年度後半の利付債規模拡大が必要になると考えている。2028・2029年度の予想資金不足を踏まえ増発の手法を議論した。増発自体には広い合意があるが、長期側の速度・規模にはかなりの議論があった。

委員は先行き指針の表現変更を勧告し、規則的で予測可能な運営と明確な情報発信が、将来の変更への市場参加者の適応を助けると強調した。最後に、国債市場機能の混乱、納税者費用増、成長制約を避けるため、議会に債務上限の引上げまたは適用停止を従来同様求める。
