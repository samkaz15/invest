# 米財務省、Prince Groupなどの世界的詐欺網と支援企業基盤に制裁

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/431c714

翻訳状態: unverified

米財務省・広報室
プレスリリース：2026年11月5日

財務省、世界的な詐欺ネットワークと、それを支える企業基盤を標的に

ワシントン：米財務省外国資産管理局（OFAC）は本日、サイバー技術を利用した詐欺、資金洗浄、人身取引への関与を理由に米国が以前制裁を科したPrince Group国際犯罪組織（TCO）の事業ネットワークを支える個人4人と事業体41団体に制裁を科した。さらに、アフリカを拠点とする詐欺師のネットワークを管理し、米国の被害者から資金をだまし取ったマレーシア人1人を指定した。

スコット・ベッセント財務長官は、「サイバー詐欺組織は、巧妙な国際事業ネットワークに依存して犯罪収益を洗浄しながら、米国の被害者から数十億ドルを盗み続けている。財務省は、指導部から、処罰を免れて活動できるようにする企業構造や金融仲介者まで、これらの組織のあらゆる層を解体することに引き続き取り組む」と述べた。

本日の措置は、Prince Groupの指導部、関連企業、金融仲介者を対象とした2025年10月14日および2026年6月23日のOFAC指定を土台としている。Prince Group TCOの関係者は、デジタル資産投資詐欺、ロマンス詐欺、その他のオンライン詐欺など、巧妙なサイバー技術を利用した詐欺によって数十億ドルの不正収益を生み、米国人と世界各地の人々を被害に遭わせてきた。こうした活動の多くは、人身取引や強制によって働かされる労働者に依存する東南アジアの詐欺拠点と結び付き、犯罪収益は複雑なオフショア企業・金融仲介者のネットワークを通じて洗浄される。今回指定された個人・事業体は、オフショアの企業構造の管理、実質所有者の隠蔽、商業活動の仲介、幹部への管理・金融サービス提供により、2025年10月および2026年6月の指定後も同組織の不正な世界的活動を維持することを助けた。今回の個人対象者は、既に指定された指導者との、または指導者のための資産移転・会社所有など、従来の制裁を回避する活動に関与した。本日の措置は、指導者が資産を隠し、従来の制裁を逃れ、国際金融システムへのアクセスを維持することを可能にした企業・金融基盤を、さらに標的とする。

これらの措置は、2026年3月6日付のトランプ大統領の大統領令14390「米国市民に対するサイバー犯罪、詐欺および搾取的な手口との闘い」を推進するものである。同令は、サイバー犯罪、サイバー技術を利用した詐欺、恐喝によって弱い立場の米国人を搾取する外国支援の犯罪ネットワークを止めるため、利用可能なすべての手段を動員するよう米政府に命じている。OFACは、大統領令13863によって改正された大統領令13581「国際犯罪組織の財産の凍結」に基づき45対象を指定し、大統領令13757、14144、14306によってさらに改正された大統領令13694「重大かつ悪意のあるサイバー活動に従事する特定の者の財産の凍結」に基づき1対象を指定する。

これらの措置は、連邦捜査局（FBI）のニューヨーク・ホノルル両支局、司法省の詐欺拠点対策タスクフォース、アラスカ地区連邦検事局との連携によるものだ。OFACはまた、英領バージン諸島金融捜査局（BVI FIA）と英国外務・英連邦・開発省（FCDO）の協力に謝意を表する。両機関の適時の支援と情報共有は、この制裁措置を支えるうえで重要であった。

【詐欺によって米国人を搾取する者を標的に】

Prince Group TCO関係者は、デジタル資産投資詐欺、ロマンス詐欺、その他のオンライン金融詐欺など、巧妙なサイバー技術を利用した詐欺によって米国内外の被害者を狙ってきた。これらは欺瞞やソーシャルエンジニアリングにより、被害者に犯罪者の管理する口座へ資金やデジタル資産を移すよう説得し、数十億ドルの不正収益を生む。

活動の多くは東南アジアの大規模な詐欺拠点で行われ、人身取引や強制によって働かされる労働者が世界各地の被害者へのオンライン詐欺を強要されている。その後、犯罪収益は、ペーパーカンパニー、オフショア持株会社、金融仲介者、デジタル資産取引の国際的なネットワークを通じて洗浄され、国際犯罪組織が不正資金の出所を隠し、正規の金融システムに組み込むことを可能にしている。

本日の措置は、犯罪企業の指導部だけでなく、米国の被害者を狙い、不正収益を法域間で移動させ、法執行を逃れることを可能にする海外の企業基盤や専門的な支援者を解体するという、財務省の継続的な取り組みを土台とする。Prince Group TCOは、商業上の利益を支え、犯罪事業に関係する資産を隠すため、複数法域にまたがる広範な企業網を築いた。幹部らは単一の企業構造を用いるのでなく、オフショア持株会社、外国事業体、名義上の取締役、企業サービス提供者を重層的に利用し、実質所有者を不明瞭にしながら資産の支配を維持した。本日の指定は、企業管理の仲介、オフショア事業体の管理、幹部への事業サービス提供を行った企業・個人など、その網の重要な構成部分を標的とする。これらの支援者は、同組織が国際金融システムにアクセスし、正当な商業活動の外観を保つうえで重要な役割を果たしてきた。

【マダガスカル拠点の詐欺ネットワーク支援者への制裁】

〈Chui Kok Wa〉

Chui Kok Wa（Chui）は、デジタル資産をだまし取る行為など、米国人を狙うマダガスカル所在の広範な詐欺師ネットワークを率いた。その詐欺師らは、暗号資産、デジタルシステム・技術などのサイバー技術を悪用し、多数の米国人から40万ドル相当超をだまし取り、米国の国家安全保障、外交政策、経済の健全性に対するサイバー犯罪・詐欺拠点の脅威に実質的に寄与した。同ネットワークは弱い立場の被害者の同情を引き、私的な金銭的利益のために資金を不正流用した。

OFACは、米国外に全部または相当部分が所在する者を発信源とし、またはその指示によるサイバー活動について、直接・間接に責任を負い、加担し、または従事したことを理由に、さらに改正された大統領令13694に基づきChui Kok Waを指定する。これは、米国の国家安全保障、外交政策、経済の健全性・金融の安定に対する脅威を生む合理的な可能性があり、またはその脅威に実質的に寄与し、商業・競争上の優位や私的な金銭的利益のために、資金・経済資源、知的財産、専有情報・事業上の機密情報、個人識別情報、金融情報の不正取得を目的とし、またはそれを伴う活動である。

【制裁の意味】

本日の措置により、上記の指定対象者について、米国内にある、または米国人・米国法人の保有・管理下にあるすべての財産・財産上の権益は凍結され、OFACへの報告が義務付けられる。また、1人以上の凍結対象者が直接・間接に、単独または合算で50%以上を所有する事業体も凍結対象となる。OFACが発行する一般許可・個別許可で認められる場合、または適用除外となる場合を除き、OFAC規則は一般に、指定対象者・その他の凍結対象者の財産・権益に関係する、米国人・米国法人による取引、または米国内・米国を経由するすべての取引を禁止する。

米国制裁への違反は、米国および外国の者に民事・刑事罰をもたらす可能性がある。OFACは厳格責任の基準で、故意・過失の有無を問わず民事制裁金を科すことができる。執行の詳細はOFACの経済制裁執行ガイドラインに記載されている。また、金融機関その他の者は、指定対象者・その他の凍結対象者に関係する一定の取引・活動により制裁適用リスクに直面し得る。禁止には、指定対象者・凍結対象者による、同者に対する、または同者の利益のための資金・物品・サービスの拠出・提供、および同者からそれらを受け取る行為が含まれる。米国外の者も、米国人・米国法人に認識の有無を問わず制裁違反を引き起こし、またはそのために共謀すること、および米国制裁を回避する行為を禁じられる。米国内外の個人がFinCENの内部告発報奨制度に制裁違反情報を提供し、その情報が100万ドルを超える金銭的制裁をもたらす執行の成功につながった場合、報奨金を受け取れる可能性がある。
