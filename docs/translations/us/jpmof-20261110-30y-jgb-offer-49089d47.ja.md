# 日本の30年利付国債第92回の入札通知

出典: https://www.mof.go.jp/jgbs/auction/calendar/nyusatsu/offer20261110.htm

翻訳状態: complete

本日、入札参加者に対し、30年利付国債（第92回）の価格競争入札及び国債市場特別参加者・第Ⅰ非価格競争入札の実施を通知しました。その概要は下記のとおりです。

3．

年4.2パーセント

価格競争入札及び国債市場特別参加者・第Ⅰ非価格競争入札
