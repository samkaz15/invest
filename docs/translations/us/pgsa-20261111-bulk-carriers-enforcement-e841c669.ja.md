# イランの海峡管理当局がばら積み船2隻への措置を発表

出典: https://x.com/PGSA_IRAN/status/2120440425823735890

翻訳状態: partial

【1/】最近、偽造書類を使ってペルシャ湾南岸の港へ向かったばら積み船2隻に、法的な措置が取られた。海峡管理当局（PGSA）が定めた誓約事項を受け入れたため、両船は違反船舶リスト（NCL）への掲載を免れた。

添付図題「偽造書類を使って通航した規則違反船2隻の航路」。図はオマーン湾からホルムズ海峡を経てペルシャ湾内に分かれる概略経路を示す。地名はペルシャ湾、ホルムズ海峡、オマーン湾、アラブ首長国連邦、オマーン、サウジアラビア。
