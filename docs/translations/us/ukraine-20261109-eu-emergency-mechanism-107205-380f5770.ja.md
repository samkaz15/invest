# ウクライナ大統領府、EU緊急支援の方針で合意と発表

出典: https://www.president.gov.ua/en/news/yevrosoyuz-zastosuye-specialnij-mehanizm-iz-dopomogi-u-nadzv-107205

翻訳状態: partial

ウクライナ大統領府発表の日本語要旨

- ゼレンスキー大統領はフォンデアライエン欧州委員長と電話で協議した。大統領府によると、両者はEUの特別緊急支援の仕組みを使い、ウクライナの差し迫った需要に資金を早く届けられるようにすることで合意し、実務担当者は既に作業に着手している。制度の正式名称、金額、実行日、入金実績の記載はない。
- 大統領はロシアによる攻撃の影響として、キーウ、ドニプロ、スムイ、ドネツク各州やヘルソンなどで電力・水・暖房の供給が深刻な状況だと説明した。この地域別説明はウクライナ側の発表に帰属する。
- 両者は冬に備えた追加のエネルギー・人道支援、EU加盟交渉、和平努力を議論した。大統領府はブリュッセルの協議で復興計画と欧州による安全保障に進展があったと説明し、アブダビ会合に向けた立場を調整したとした。三者協議の合意結果は発表されていない。
