# 米財務省の特別公告　2026年11月9日の入札締切

出典: https://www.treasurydirect.gov/instit/annceresult/press/preanre/2026/SPL_20261105_1.pdf

翻訳状態: partial

米財務省・財政局。2026年11月5日即時公表。連絡窓口は国債入札担当。

2026年11月9日（月）の13週物・26週物短期国債入札の締切は、米東部時間で非競争入札が午前11時、競争入札が午前11時30分。

同日の6週物短期国債・3年債入札の締切は、米東部時間で非競争入札が正午、競争入札が午後1時。
