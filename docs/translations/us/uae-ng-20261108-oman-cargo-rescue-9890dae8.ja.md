# UAE沿岸警備隊、オマーン湾の貨物船火災で22人を救助と発表

出典: https://x.com/Uaengc/status/2119247094905258065

翻訳状態: partial

UAE国家警備隊は、人命の保護と海上の安全・保安を強化する取り組みの一環として、同隊の沿岸警備部門が、オマーン湾で火災が起きた貨物船に乗っていたアラブ諸国籍の22人を救助したと発表した。
