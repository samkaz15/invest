# IMO事務局長、ホルムズ海峡で海事安全・保安規則の執行強化を要請

出典: https://www.imo.org/en/mediacentre/pressbriefings/pages/imo-secretary-general-calls-for-enforcement-of-maritime-rules.aspx

翻訳状態: partial

原文抜粋の訳。不正登録または虚偽の旗を掲げた船舶の通航が続いている。

詳細要約。IMOによれば2026年2月28日以降、海峡で国際航行する商船に対し130件を超える攻撃を確認し、船員少なくとも25人が死亡、ほかに行方不明者と負傷者がいる。アルセニオ・ドミンゲス事務局長は海上人命安全条約（SOLAS）などの基本規定が守られていない通航が多いと指摘し、旗国、寄港国、沿岸国にそれぞれの管轄と国際法の範囲で違反に対応するよう要請した。船主・運航者には船員を許容できない危険にさらす商業活動を控えるよう求めた。各国政府には生活費上昇にもつながる紛争の根本原因への対処を、加盟国には航行の権利と自由を保つ統一的で安全な国際的航行の枠組みを回復するための政治的解決を求めた。
