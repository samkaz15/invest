# テキサス州の外国貿易地域におけるアルミ管製造計画の公告

出典: https://public-inspection.federalregister.gov/2026-23172.pdf

翻訳状態: partial

## PDF 1ページ

官報掲載予定は2026年11月13日。米商務省外国貿易地域委員会。B-143-2026。テキサス州ハーリンジェン、外国貿易地域第62号におけるPenn Aluminum International, LLCの押出・引抜加工コイル状アルミ管の製造活動提案。事業者は同地域内の施設について届け出た。委員会規則15 CFR 400.22に適合する届け出は2026年10月13日に受理された。15 CFR 400.14(b)に従い、活動は届け出に記載され、その後委員会が認める特定の外国ステータス材料・部品と最終製品に限る。制度上の利点は委員会の公開サイトの背景説明に記載。提案の最終製品は押出・引抜加工のコイル状アルミ管（無税）、外国ステータス材料はアルミビレット（税率50％）。ビレットには原産国に応じて1962年通商拡大法232条、1974年通商法301条の関税が適用されると届出は説明する。対象品の地域への搬入には特権外国ステータス（19 CFR 146.41）が必要。

## PDF 2ページ
