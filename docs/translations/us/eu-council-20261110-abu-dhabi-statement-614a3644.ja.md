# EU・仏独伊・英国・ウクライナ・米国・NATOのアブダビ協議に関する声明

出典: https://www.consilium.europa.eu/en/press/press-releases/2026/11/10/statement-on-today-s-meeting-in-abu-dhabi-between-the-eu-france-germany-italy-united-kingdom-ukraine-united-states-and-nato/

翻訳状態: partial

欧州理事会声明 907/26。2026年11月10日、表示時刻10:22。

ロシアとの三者協議を前に、欧州の関係国・機関、ウクライナ、米国の代表は、戦争終結と永続的な和平の条件を整える取り組みについて、緊密な調整を続けるため会合を開いた。いかなる解決にも強固な安全の保証を盛り込むことへの支持が含まれる。

欧州の関係国・機関、ウクライナ、米国は、共通の目標、継続中の協議、欧州・大西洋の安全保障への関与を踏まえ、協力して協議した。参加者は、将来のいかなる取り決めも、ウクライナの主権、領土の一体性、独立した意思決定を尊重し、信頼できる安全の保証を提供する必要があると強調した。

共通の目標は、ウクライナの長期的な安全を強め、交渉による解決に必要な信頼を築く、実行可能で相互に補完し合う安全保障の枠組みを構築することである。

永続的な和平を主眼としつつ、戦争終結後に既存の欧州の安全保障機関や協定をどう発展させるかも協議した。参加者は、戦後の安全保障上の懸念に対処し、紛争のリスクを減らすことが不可欠との認識を共有した。リスクを管理し、危険な事態の激化を防ぐ強力な仕組みをどう確保するかを議論した。参加者は戦後の欧州で強固な安全保障体制と取り決めを構築するという共通の決意を再確認し、強力なNATOが引き続き欧州・大西洋の集団防衛の中心となることを明確にした。

欧州の関係国・機関、ウクライナ、米国は交渉過程を通じて緊密に協力し、欧州の関係国・機関も参加するより広い多国間協議へ進み、包括的で永続的な和平を実現するという共通の目標を追求する。
