# 財務省借入諮問委員会：国債デリバティブ、現物とレポ資金

出典: https://home.treasury.gov/system/files/221/TBACCharge2Q42026.pdf

翻訳状態: partial

PDF 2ページ

委員会の発表資料によると、2022年の金利上昇以降、運用会社は国債先物で国債に相当するエクスポージャーを確保し、年金・保険会社は金利スワップで負債の金利感応度に対応してきた。政府債務・社債の発行増加は現物国債の需給に影響したとする。

国債先物は自らレポ取引の体制を整える必要がなく、取引のしやすさや余剰現金を運用できる点が特徴。資料では週次取引高は建玉の1.5〜2倍程度で現物国債の取引高に匹敵するとする。金利スワップは取引・清算が標準化された後も負債キャッシュフローに合わせた設計が可能で、長期の金利リスクを調整できる。ディーラーのバランスシート制約によって、仲介の一部はヘッジファンドに移った。

委員会の分析では、デリバティブの利用によって国債需要を担う主体が変わる。レポを使ったレバレッジ取引を介して現物需要が生じ、資金調達条件や証拠金が厳しくなると需要が弱まり得る。提案は、レポへのアクセスや期間付きレポの供給、新規参加者の参入、バランスシート利用の条件を改善する選択肢。採択・施行を示す資料ではない。
