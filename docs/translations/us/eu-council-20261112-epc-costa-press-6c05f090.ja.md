# 欧州理事会議長のダブリン首脳会合後の記者発表

出典: https://www.consilium.europa.eu/en/press/press-releases/2026/11/12/remarks-by-president-antonio-costa-at-the-press-conference-following-the-meeting-of-the-european-political-community-in-dublin/

翻訳状態: partial

こんばんは。まず、本日のダブリンでの温かい歓迎と欧州政治共同体首脳会議の開催について、ミホール・マーティン首相に感謝します。

本日の議論の中心は、ウクライナにおける公正で永続的な平和を追求することでした。進行中の交渉で欧州が重視する点を改めて確認します。優先事項は明確で、変わっていません。第一に停戦を実現すること、第二に黒海での航行を再開すること、第三に和平合意に向けた条件を整えることです。

これまで、その方向への具体的な進展は限られていました。ロシアはこれまで戦争の激化に注力しており、支配より平和を優先することをまだ示していないためです。

外交が加速する中で、永続する平和は公正である必要があります。欧州の安全を回復できる公正な平和は、明確な原則に基づかなければなりません。

第一に、ウクライナは欧州の他の国々と同様に主権国家です。同盟や協力相手を自由に選べなければなりません。欧州は帝国と勢力圏を過去のものとし、その復活を決して容認しません。

第二に、欧州の安全の将来は欧州抜きに議論し決定できません。だからこそEUは、NATOや複数の欧州諸国とともに、進行中の外交努力で役割を果たしています。ウクライナの仲間と肩を並べ、一つのチームとして取り組んでいます。

第三の原則は、欧州の安全保障の枠組みに関するものです。欧州には確立した安全保障の枠組みがあります。残念ながら、過去数十年にロシアは武力でこれを損なう道を選び、その結果ウクライナ侵攻に至りました。

それでも私たちは、平和を重んじる欧州諸国の外交政策を数十年にわたり導いてきた基本原則を守り続けます。欧州諸国の主権平等、武力による威嚇または武力行使の自制、国境の不可侵、国家の領土保全、紛争の平和的解決です。

ウクライナの平和と欧州の安全をめぐるあらゆる交渉において、EUはこれらの国際法の原則に引き続き従います。

ミホール、温かいおもてなしに改めて感謝し、会合の成功をお祝いします。パルムラン大統領、次回スイスでの欧州政治共同体の開催が成功するようお祈りします。ありがとうございました。
