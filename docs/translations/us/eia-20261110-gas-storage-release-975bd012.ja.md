# EIAが11月末の天然ガス貯蔵量の見通しを引き上げ

出典: https://www.eia.gov/pressroom/releases/press594.php

翻訳状態: complete

11月上旬の暖かさを受け、EIAが11月末の天然ガス貯蔵見通しを引き上げ
即時公表　2026年11月10日　ワシントンDC

米エネルギー情報局（EIA）は、11月末の米天然ガス貯蔵量が10月時点の予測を約700億立方フィート上回ると見込む。月初の暖かさが天然ガス価格の上昇圧力を和らげている。

11月版の短期エネルギー見通し（STEO）で、EIAは今冬を通じて米天然ガス貯蔵量が従来予測を上回ると見込む。ヘンリーハブ天然ガス現物価格は11月から3月の平均で百万Btu当たり2.87ドルとなり、前月時点の同期間の予測を16％下回る。

出典。EIAの短期エネルギー見通し2026年11月版の概況・予測表の草案。数値は丸めており、報告内の他の表と一致しないことがある。ヘンリーハブの年平均予測は整合性確認が未了。全数値はSTEOの最終確認の対象。

- **ブレント原油価格。** EIAはブレント現物価格を11月平均104ドル／バレル、12月99ドル／バレルと予測する。中東からの原油輸送が増え、世界の石油在庫が回復するにつれ、2027年は平均86ドル／バレルと見込む。海上輸送の混乱が続けば短期的に価格が振れる可能性がある。
- **ガソリンと軽油の価格。** EIAは2027年に米小売ガソリン・軽油価格が下がると予測する。一方、2027年末まで石油精製品の世界供給が逼迫すると見込むため、両方の予測を10月版から引き上げた。軽油の2027年平均は1ガロン5.03ドル（10月予測4.49ドル）、ガソリンは3.73ドル（同3.56ドル）。
- **米原油生産と在庫。** 輸出が増え輸入が減ったため、米商業原油在庫は10月として2014年以来の低水準となった。2027年は純輸入が増え、米原油生産が過去最高の日量1,430万バレルとなるため、EIAは在庫増加を見込む。
- **液化天然ガス輸出。** 新規輸出設備の稼働と既存施設の拡張に伴い、米LNG総輸出は2025年の日量約150億立方フィートから、2027年に約190億立方フィートへ増えると予測する。
- **発電量。** EIAは2026年の米電力部門の発電量が2025年比2.7％増の約4兆3,900億kWhとなり、過去最高に達すると見込む。企業の電力使用が増え、平年より暑い夏が冷房需要を押し上げた。予測期間中の発電増加の大部分は、設備容量の増加に伴う事業用太陽光発電による見込み。

2026年11月版の全編は[EIA公式サイト](https://www.eia.gov/outlooks/steo/)で閲覧できる。
