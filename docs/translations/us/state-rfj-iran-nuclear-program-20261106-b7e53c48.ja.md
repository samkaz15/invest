# 米国務省がイラン核計画の情報に最大2,000万米ドルの報奨金を提示

出典: https://rewardsforjustice.net/rewards/iran-nuclear-program/

翻訳状態: partial

## イランの核計画　報奨金は最大2,000万米ドル

米国務省の「正義への報奨」プログラムは、イランの核計画に関する情報に対し、最大2,000万米ドルの報奨金を提供し、移転の支援を行う可能性がある。対象は核計画の施設、機器、科学界などの関係者、またはこれらの移動に関する情報。

同プログラムによると、国際原子力機関（IAEA）は2025年、イランがウランを純度60％まで濃縮していると報告した。これは核兵器に必要とされる90％まで技術的にわずかな段階だと同プログラムは説明する。核兵器を保有しない国のうち、これほど高い水準にウランを濃縮しているのはイランのみで、専門家は、この量をさらに濃縮すれば複数の核兵器に足りる可能性があると推計している。

また同プログラムによると、イラン政府がIAEAの保障措置上の義務を履行していないため、IAEAは遠心分離機など主要部品の生産・在庫について、継続的に把握することができなくなった。

**英語ポスター**　募集対象は、核科学者・職員、核計画に関連する技術・能力、関連組織・関係者。該当する情報の提供者は、報奨金や移転支援の対象となる場合がある。連絡先は省略。
