# FRB主要金利日報（11月9日公表）

出典: https://www.federalreserve.gov/releases/h15/

翻訳状態: complete

1. 2016年3月1日以降、日次の実効FF金利は、特定短期金融市場金利報告（FR 2420）で預金取扱機関から収集する取引データの出来高加重中央値。それ以前は仲介取引金利の出来高加重平均。
2. 週次値は当週水曜までの暦日7日間の平均。月次値には月内のすべての暦日を含む。
3. 1年を360日として年率換算、または銀行利息方式。
4. 割引率ベース。
5. デポジトリー・トラスト・カンパニーで決済された一部のCP取引から補間する。ディーラーや直接発行体から投資家への売り提示側の取引。1、2、3か月物はFRBのCPページの30、60、90日物に対応する。
6. FDICの一時流動性保証制度の対象となる金融CPや、FRBの流動性供給制度の直接・間接の影響を受け得る金融・非金融CPも、関連指数から除外しない。2008年9月19日以降の金利には一時制度の影響が直接または間接に反映され得るため、それ以前の金利とは用途によって比較が難しい。
7. 米国内営業所の資産額で上位25行に入る預金保険対象の米国認可商業銀行の過半が掲示する金利。プライム金利は短期事業融資の価格を決める際の基準の一つ。
8. 2003年1月9日に始まったFRBのプライマリー・クレジット窓口貸出で、割引・貸出に適用する金利。1月8日を最後に廃止された調整信用の金利を置き換えた。掲載値はNY連銀。両系列の履歴はFRBのH.15データページで取得可能。
9. 取引の活発な非物価連動債の利回りを固定満期に調整。30年固定満期系列は2002年2月18日廃止、2006年2月9日再開。期間中は米財務省が20年の名目固定満期利回りから30年を推計する調整係数を公表。歴史的係数は財務省金利統計ページ参照。出所は米財務省。
10. 物価連動国債（TIPS）の利回りを固定満期に調整。出所は米財務省。名目・物価連動利回りの詳細は財務省金利統計ページ参照。
11. 残存期間10年超の全TIPSの買い気配利回りを単純平均。

現在・過去のH.15と週次・月次・年次平均はFRBのDDPで取得可能。特記がなければ週次・月次・年次金利は営業日の平均。

米財務省は、非物価連動国債の日次利回り曲線から名目固定満期利回りを補間する。曲線は証券の利回りと残存期間の関係を示し、店頭市場で取引が活発な国債の取引終了時の買い気配利回りに基づく。NY連銀が集めた気配を合成して市場利回りを算出する。曲線から1、3、6か月と1、2、3、5、7、10、20、30年の利回りを読み取る。残存期間がちょうど10年の銘柄がなくても10年利回りを得られる。同様に、米財務省は店頭の物価連動国債の買い気配利回りから固定満期利回りを補間し、5、7、10、20、30年の値を曲線から読み取る。
