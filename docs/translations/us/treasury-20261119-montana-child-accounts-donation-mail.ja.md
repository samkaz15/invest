# モンタナ州の子ども向け投資口座に民間寄付を発表

出典: https://trumpaccounts.gov/

翻訳状態: partial

トランプ・アカウント、スルートマン一家によるモンタナ州の子どもへの寄付を発表

ワシントン発。トランプ・アカウントは本日、ブレンダ・スルートマン氏とフランク・スルートマン氏から、2023年および2024年に生まれたモンタナ州の子ども一人ひとりに1,000ドルを寄付すると発表した。この寄付により、州内の追加の2万2,000人を超える子どものトランプ・アカウントに資金が入り、家族が子どもの将来に向けた経済的基盤を築く助けになるという。

スコット・ベッセント財務長官は「250年にわたり、米国の約束は、それぞれの世代が前の世代より大きな機会を受け継ぐべきだという信念に支えられてきた。トランプ・アカウントはこの建国の理想を力強く表現するものだ。寛大な寄付と、米国の将来に対して私たちができる最大の投資は、その将来を受け継ぐ世代への投資だという信念について、夫妻に感謝する。この贈り物により、モンタナ州の子どもたちは人生の初日から資産を築くためのさらなる支援を得る」と述べた。

内国歳入庁のフランク・J・ビシニャーノ長官は「夫妻はモンタナ州の子どもたちのより明るい未来を築く助けとなっている。この寄付は次世代への直接投資であり、若いモンタナ州民が新たな機会を切り開く経済的基盤を提供する。夫妻のような寛大な寄付者の支援により、トランプ・アカウントは全米の子どもたちにアメリカンドリームへの参加の機会を与えている」と述べた。

トランプ・アカウントは、Working Families Tax Cutsに基づいて設立された、18歳未満の米国の子ども向けの税制優遇付き投資口座である。米財務省は、有効な社会保障番号を持つ適格な子ども全員の口座を開設し、慈善寄付を通じて何百万人もの子どもの将来への投資を可能にしたと説明している。

2025年1月1日から2028年12月31日までに生まれた子どもは、米財務省から一度限りの1,000ドルの初期拠出を受ける資格もある。

保護者または後見人は、口座を管理し、家族・友人・雇用主からの拠出を可能にするため、子どもの口座の管理手続きを行う必要がある。

手続きにはApple App StoreまたはGoogle Playで提供される公式アプリをダウンロードする。保護者または後見人は本人確認と子どもとの関係の確認を行い、子どもの情報を確認して口座規約に同意する。

口座の管理手続き後、友人・家族は年間最大5,000ドルを拠出でき、雇用主は年間最大2,500ドルを拠出できる。雇用主による拠出も年間5,000ドルの上限に含まれる。

詳細は公式サイトを参照。
