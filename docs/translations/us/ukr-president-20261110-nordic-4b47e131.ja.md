# ウクライナ大統領と北欧5か国首相の外交・支援協議

出典: https://www.president.gov.ua/en/news/prezident-obgovoriv-iz-premyer-ministrami-krayin-pivnichnoyi-107241

翻訳状態: partial

ウクライナ大統領府によると、ゼレンスキー大統領はコペンハーゲンでデンマーク、アイスランド、ノルウェー、フィンランド、スウェーデン各首相にアブダビ協議を説明した。大統領府は欧州が交渉に直接参加すべきだとの共通の立場を伝えた。 ゼレンスキー氏はロシアによるエネルギー施設への攻撃で複数地域で停電が続いていると説明し、冬季の追加支援に期待を示した。北欧側の新規予算、交渉参加の正式決定、停戦・捕虜交換の合意や履行は本文に示されていない。
