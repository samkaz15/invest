# フランス外務省がパリG7外相会合の日程とエネルギー議題を公表

出典: https://www.diplomatie.gouv.fr/en/presse-et-ressources/decouvrir-et-informer/actualites/quelles-priorites-pour-la-reunion-des-ministres-des-affaires-etrangeres-du-g7-a-paris

翻訳状態: partial

G7外相は2026年11月9日と10日にパリで会合を開く。フランスのG7議長国の下で開かれる2日間の公式会合では、危機解決などの国際政治上の主要課題について立場を調整し、2026年3月のヴォー・ド・セルネー外相会合以降の進捗を点検する。

外相は、能力・資金・エネルギー面でのウクライナ支援、中東の安定化とエネルギー供給源の多様化・確保をはじめとする紛争・危機を協議する。スーダン、アフリカの角、ベネズエラ、キューバ、ハイチ、法の支配を基礎とする自由で開かれたインド太平洋も議題となる。各国の見解を近づけ、連携した危機対応につなげることを目指す。

ほかの議題は、港湾安全を通じた麻薬取引対策、人道支援の供給網・食料安全保障、AIの安全な開発・運用。港湾ネットワークの初会合はマルセイユで並行開催予定。発行元はフランス欧州・外務省、France Diplomatie、Licence Ouverte 2.0。
