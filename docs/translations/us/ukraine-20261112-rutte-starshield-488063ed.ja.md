# ウクライナ大統領とNATO事務総長の防空協議

出典: https://www.president.gov.ua/en/news/situaciya-z-pereboyami-v-roboti-starshield-i-neobhidnist-pos-107301

翻訳状態: partial

ウクライナ大統領府によると、ゼレンスキー氏はNATOのルッテ事務総長と会談し、前線・一時占領地域のStarshieldの不調が無人機迎撃を難しくしていると伝えた。同氏はロシアのミサイル・誘導爆弾・無人機攻撃に言及し、三者協議が活発化する中でも迎撃能力の確保が必要と訴えた。ルッテ氏がPAC-2・PAC-3迎撃弾への支援に意欲を示したとして謝意を述べた。提供量・契約・引き渡しや通信制限の独立検証は確認できていない。
