# ウクライナ・アゼルバイジャン首脳会談の重要インフラ協議

出典: https://www.president.gov.ua/en/news/prezidenti-ukrayini-j-azerbajdzhanu-obgovorili-dvostoronnyu-107277

翻訳状態: partial

ウクライナ大統領府によると、ダブリンでゼレンスキー氏とアリエフ氏が会談した。無人機分野では契約が締結済みで、両国は発注拡大に向け調整中と説明。冬季に向けた重要インフラと物流の追加支援を要請し、両国の実務担当者に検討を指示した。アゼルバイジャン大統領府も会談を公表し、既往の電気機材支援を挙げた。
