# イラン革命防衛隊海軍、タンカー2隻の停止を主張した11月10日声明

出典: https://sepahnews.ir/fa/news/41406/%D8%A7%D9%86%D9%81%D8%AC%D8%A7%D8%B1-%D8%AF%D9%88-%D9%86%D9%81%D8%AA%DA%A9%D8%B4-%D9%85%D8%AA%D8%AE%D9%84%D9%81-%D8%AF%D8%B1-%D8%AA%D9%86%DA%AF%D9%87-%D9%87%D8%B1%D9%85%D8%B2

翻訳状態: complete

ホルムズ海峡の無許可航路で、違反したタンカー2隻が激しい爆発で停止し、燃えたまま放置されている。

一方は超大型タンカーで、機雷に衝突して爆発した。もう一方は侵略を行う米軍の戦闘機に支援され、無許可航路をひそかに通過しようとして事故に遭い、大きな火災でその場に停止した。

両船は航法・識別装置をすべて切っており、ホルムズ海峡の「火の壁」に遭遇した。海峡の南岸に放置され、燃え続けている。

革命防衛隊海軍は、先に警告したように無許可航路は安全でなく、米軍に協力して同航路を通ろうとする船舶は同じ結末を迎えると改めて警告する。
