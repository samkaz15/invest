# 財務省とIRS、退職年金の自動加入に関する最終規則を公表

出典: https://content.govdelivery.com/accounts/USTREAS/bulletins/4331055

翻訳状態: メール本文完了。規則本文は未取得。

財務省とIRS、米国の働く人々が経済的に安定した老後を築けるよう最終規則を発表

SECURE 2.0の最終規則は職場の退職年金制度への自動加入を拡大する。

ワシントン発――財務省と内国歳入庁（IRS）は本日、職場を通じて退職に向けた貯蓄を行う米国人を増やすための最終規則を発表した。SECURE 2.0法の重要な規定を実施し、一部の401(k)及び403(b)退職年金制度の自動加入について雇用主に明確な指針を示す。拠出額に対する労働者の選択権を維持しながら、退職貯蓄を支援する。

財務省は、自動加入拡大の規定により2023～2032年の退職貯蓄が年平均42億ドル増えると推計している。

ベッセント財務長官は「経済的に安定した老後はアメリカン・ドリームの礎であり、全労働者がそれを実現する機会に値する。本日の規則は、家族や労働者が拠出額の選択権を保ちながら退職貯蓄を築くことを助け、雇用主に従業員の将来への投資に必要な明確さと柔軟性を与える」と述べた。

IRSのビシニャーノ最高経営責任者は「SECURE 2.0の規則により、米国の家族は退職口座への自動加入を通じて貯蓄を増やし、稼いだお金をより多く手元に残すことができる。規則は長期の金融上の意思決定を行う納税者の事務負担を軽減する。さらに、IRSとのやりとりを簡素化し、納税者サービスを改善するという目標を後押しする」と述べた。

米国民の退職貯蓄の強化

最終規則は制度スポンサーの要件を明確化し、一部の加入者向け通知を簡素化することで、SECURE 2.0法の重要な規定を実施する。

対象の退職年金制度は原則として、対象従業員を拠出率3％で自動加入させる。最初の加入期間後、既定の拠出率は原則として毎年少なくとも1ポイント引き上げ、最低10％に達するまで増やす。上限は15％。従業員は加入を辞退し、または異なる拠出率を選択できる。

最終規則は原則として2027年12月31日後に始まる制度年度から適用され、雇用主には必要な事務変更のための時間が与えられる。

最終規則は、適格な小規模・新規事業、政府・教会の制度、SIMPLE 401(k)制度に対する法定例外を明確にし、法定範囲内で自動増額の時期と額に柔軟性を与える。また一部の必要な通知を統合できるようにし、未加入の適格従業員が毎年の通知と請求可能な制度文書を受け取ることを条件に年次通知要件を軽減し、制度合併後の自動加入要件の適用を説明する。

最終規則は連邦官報の事前閲覧ページで入手可能とされる。
