# カリフォルニア州司法長官、郵便投票をめぐる連邦訴訟の取下げを発表

出典: https://oag.ca.gov/news/press-releases/attorney-general-bonta-trump-administration-throws-towel-drops-baseless-lawsuit

翻訳状態: complete

オークランド発。カリフォルニア州のロブ・ボンタ司法長官は本日、トランプ政権が提起した訴訟を取り下げたと発表した。同政権は、米国市民でない可能性が高いと判断した約2万人のリストに載る人が投じた可能性のある郵便投票を、州の選挙当局に分離させ、集計させないことを求めていた。州司法長官の発表によれば、連邦司法省は裁判で4回続けて退けられ、11月13日金曜にデービッド・カーター判事の下で予定されていた、リストの信頼性を検討する証拠審理に臨む前に、自主的取下げを選んだ。ほかの事件でも同様のリストの信頼性に裁判所が疑問を示し、別の事件では連邦司法省の弁護士がリストの誤り率は高いと認めたと州は述べた。

ボンタ司法長官は、翌週に政権は非市民と疑われる人のリストについて厳しい質問を受けるはずだったが、審理を受ける前に取り下げたと述べた。連邦最高裁を含め1週間で4回退けられ、連邦政府が断念したとも述べた。州は立場を貫いて勝利し、全国の選挙結果は米国民が政権の反民主主義的な方針を圧倒的に拒絶したことを示すと主張し、民主主義と法の支配を守る姿勢を表明した。

州司法長官は、選挙の時期、場所、方法を規制する権限を米国憲法が州と連邦議会に与えていると説明し、次の経過を挙げた。

- 10月26日（月）。連邦政府が地裁を経ずに申し立てた最初の緊急上訴を、第9巡回区連邦控訴裁判所が退けた。
- 10月28日（水）。カリフォルニア州中央地区連邦地裁が、政権の一時的差止命令の申立てを却下した。
- 10月30日（金）。第9巡回区は、上訴中の緊急差止めの申立てを却下した。
- 11月2日（月）。連邦最高裁は、争われた郵便投票を州当局に分離させ、集計させないよう求めた政権の緊急申立てを却下した。
