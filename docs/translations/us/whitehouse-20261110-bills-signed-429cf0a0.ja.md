# ホワイトハウスが4法案への大統領署名を公表

出典: https://www.whitehouse.gov/briefings-statements/2026/11/congressional-bills-h-r-997-h-r-1703-h-r-1945-and-h-r-7730-signed-into-law/

翻訳状態: complete

H.R. 997、H.R. 1703、H.R. 1945、H.R. 7730への大統領署名
ホワイトハウス　2026年11月10日

2026年11月10日（火）、大統領は次の法案に署名し、法律として成立させた。

- H.R. 997「2025年全国納税者擁護官権限強化法」。全国納税者擁護官に、自身またはその委任を受けた者に直接報告する法律顧問を同官の事務所内に任命する権限を与え、納税者擁護サービスの職員に関して人事措置を行う権限も拡大する。
- H.R. 1703「2026年移動手段の選択肢拡大法」。一定の車いすに関するメディケアの支払規則を変更する。
- H.R. 1945「米国国立チャーチル博物館の国定歴史建造物指定法」。ミズーリ州フルトンの同博物館を国定歴史建造物に指定する。
- H.R. 7730「破産債務上限調整法」。小規模事業者の第11章手続きと消費者の第13章破産手続きの債務上限を恒久的に引き上げる。
