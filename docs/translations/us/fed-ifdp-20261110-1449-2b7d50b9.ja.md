# 貿易転換と米国関税の第三国輸入価格への波及

出典: https://www.federalreserve.gov/econres/ifdp/trade-deflection-the-spillover-effects-of-us-tariffs-on-import-prices-in-bystander-countries.htm

翻訳状態: partial

抄録の短い抜粋訳。米国の関税対象となった中国製品は、第三国で輸入価格の持続的な低下を示した。

本文要約。FRB掲載IFDP 1449は、2017〜2021年の貿易データを使った著者の推計で、2018〜19年の米対中関税対象品の第三国での輸入単価は、2021年までに非対象品対比4.4％低下したと報告。 著者は新興国、特にASEANで低下が大きく持続的と推計。品目の対米輸出依存、仕向地の供給元集中、対中の地政学的近さを異質性の要因として分析した。2025〜26年の関税は対象国と規模が異なり、同じ効果を前提にできないと結論で留保。
