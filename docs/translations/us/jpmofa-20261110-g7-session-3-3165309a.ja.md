# G7外相会合（セッション3：中東の安定）

出典: https://www.mofa.go.jp/mofaj/fp/pc/pageit_000001_00030.html

翻訳状態: complete

現地時間11月10日午前10時50分（日本時間同日午後6時50分）から約70分間、フランス・パリを訪問中の茂木敏充外務大臣は、G7外相会合の「中東の安定」に関するセッションに参加しました（G7各国外相及びEU上級代表並びに招待国であるブラジル、韓国、サウジアラビア及びエジプトの各外相が参加）。
本セッションにおいて、G7各国外相は、招待国と共に、中東情勢及びこれをめぐる対応について議論を行いました。
茂木大臣は、イエメン情勢の悪化が継続していることに強い懸念を表明した上で、バブ・エル・マンデブ海峡における自由で安全な航行の確保等に国際社会全体で連携して取り組んでいきたい旨述べました。また、日本がホーシー派に対し最大限の自制を繰り返し求めてきている旨述べ、紛争の政治的解決を実現することの必要性を強調しました。
さらに、茂木大臣は、米イラン間の協議の早期再開を支持し、イランへの働きかけを継続していくとしつつ、ホルムズ海峡における追加的費用が課されない形での自由で安全な航行が一刻も早く回復しなければならず、今後の同海峡の在り方を全ての関係者で議論することが重要である旨述べました。
各国外相は、ホルムズ海峡及びバブ・エル・マンデブ海峡における自由で安全な航行の重要性を再確認しつつ、ホルムズ海峡の通航に対して課される追加的な費用等に反対することを確認しました。
さらに、各国外相は、イスラエル・パレスチナ、ガザ、シリア、レバノンの情勢等についても議論し、中東地域全体の事態の早期沈静化・安定化に向け、緊密に連携していくことで一致しました。
