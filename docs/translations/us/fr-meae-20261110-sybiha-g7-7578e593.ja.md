# 仏外務省のシビハ・ウクライナ外相との会談発表

出典: https://www.diplomatie.gouv.fr/fr/presse-et-ressources/decouvrir-et-informer/actualites/ministerielle-g7-affaires-etrangeres-entretien-du-ministre-avec-m-andrii-sybiha-ministre-des

翻訳状態: complete

11月10日、仏欧州・外務相はパリのG7外相会合の際にウクライナのアンドリー・シビハ外相と意見交換した。仏議長国の下でG7がウクライナに提供してきた支援の進捗を確認した。

フランスも代表を送っているアブダビで同日新たな協議が始まる中、両外相は交渉を再開し部分的休戦を実現する米国の取り組みを歓迎した。部分的休戦は全面的かつ無条件の停戦への第一歩となるべきである。ジャン＝ノエル・バロ外相は、公正で持続的な和平に至るまでウクライナを揺るぎなく支えると再確認した。

両外相は、2025年2月14日にロシアのドローン攻撃を受けたチョルノービリ原発の封じ込め施設の修復をめぐり、前日にパリで開いた国際会議を振り返った。仏外相は、仏G7議長国の優先課題である同工事のため2億7,800万ユーロを動員したことを歓迎した。また、ロシアによるエネルギー施設への攻撃を受けたウクライナへの支持を表明し、冬を迎える同国を関係国と連携して支える方針を改めて示した。

両外相は黒海の状況も協議した。穀物を運ぶ商船と港湾施設を狙ったロシアの攻撃が、世界の食料安全保障を脅かしているとした。
