# 米仲介のアブダビ協議後のウクライナ代表団長発表

出典: https://t.me/umerov_rustem/607

翻訳状態: partial

アラブ首長国連邦での2日間の協議を終えました。

主な成果は、大規模な捕虜交換で合意できたことです。現在、詳細の調整と実施に向けて作業しています。

私たちの人々を帰国させることは、引き続き最優先事項の一つです。すべてのウクライナ人が一日も早く捕虜の身から帰れるよう、できる限りのことをしています。

ウクライナ・米国・ロシアの三者協議では、和平の実現と戦後復興を話し合いました。その第一歩は、戦争を終わらせ、ウクライナの安全を保証することであるべきです。

この2日間で、各当事者は立場を率直に示しました。その間にはなお大きな隔たりがあります。難しい作業が多く残っていますが、交渉を続ける余地はあります。

協議の準備と実施に積極的に関わった米国に感謝します。スティーブ・ウィトコフ氏とジャレッド・クシュナー氏の直接の関与には、特に感謝します。

協議を受け入れ、その進行を支援したアラブ首長国連邦、そしてアブダビで共に取り組んだ欧州のパートナー、英国、フランス、ドイツ、イタリア、NATOと欧州委員会の代表にも感謝します。
