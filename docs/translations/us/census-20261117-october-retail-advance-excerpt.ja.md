# 2026年10月の米小売・飲食売上高速報

出典: https://www.census.gov/retail/sales.html

翻訳状態: 部分訳。PDFの表・脚注・図表は未完了。

2026年10月の米小売・飲食サービス売上速報は、季節・祝日・営業日数の差を調整し物価変動を調整しない額で7482億ドル。前月比0.2％増（±0.4％）で、前年同月比6.8％増（±0.5％）。2026年8～10月の売上合計は前年同期比6.4％増（±0.5％）。8月から9月への変化率は0.8％増（±0.2％）から改定されなかった。PDFの注記によれば、10月の前月比の90％信頼区間にはゼロが含まれ、実際の変化がゼロと異なると結論する十分な統計的証拠はない。
