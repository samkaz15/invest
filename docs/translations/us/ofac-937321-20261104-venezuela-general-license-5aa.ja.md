# ベネズエラ一般許可5AA：PdVSA社債関連取引の許可開始日を2026年12月18日に設定

出典: https://ofac.treasury.gov/media/937321/download?inline

翻訳状態: unverified

米財務省、ワシントンD.C.、外国資産管理局
ベネズエラ制裁規則、連邦規則集第31編第591部
一般許可第5AA号
2026年12月18日以降の、Petróleos de Venezuela, S.A.の2020年償還・利率8.5%債に関連する一定の取引を許可する

(a) 本一般許可の(b)項に定める場合を除き、2026年12月18日以降、2019年1月25日付大統領令13857によって改正され、ベネズエラ制裁規則（連邦規則集第31編第591部、VSR）に組み込まれた2018年5月21日付大統領令13835の第1条(a)(iii)項によって禁止されることとなる、Petróleos de Venezuela, S.A.の2020年償還・利率8.5%債に関連するすべての取引、同債への資金提供、同債に係るその他の取引を許可する。

(b) 本一般許可は、VSRまたは連邦規則集第31編第V章のその他の部分によって別途禁止される取引・活動を許可するものではない。

(c) 2026年11月4日付で、2026年9月16日付一般許可第5Z号は、本一般許可第5AA号によって全体が置き換えられ、失効する。
